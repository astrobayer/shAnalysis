shLowLevel.version

v2.5.1 Toolbox metadata: name, version, date, root path, provenance.

Syntax

v = shLowLevel.version();
shLowLevel.version                          % print a summary

Description

v = shLowLevel.version() returns the toolbox metadata as a struct. The version string and date are parsed from Contents.m (the MATLAB toolbox convention line % Version x.y.z ... dd-Mmm-yyyy), so there is a single source of truth that is also honoured by MATLAB's own ver('shAnalysis'). Called without an output argument, a short summary is printed instead.

Output Arguments

fieldsize / typedescription
v.Name(1×1) string"shAnalysis"
v.Version(1×1) stringe.g. "2.5.1"
v.Date(1×1) stringrelease date from Contents.m
v.Root(1×1) stringtoolbox root folder
v.Provenance(1×1) stringauthorship line

Examples

v = shLowLevel.version();
fprintf("%s %s (%s)\n", v.Name, v.Version, v.Date)
