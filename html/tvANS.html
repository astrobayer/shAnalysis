tvANS — time-variable anisotropic Wiener filter

The optimal alternative to destripe+Gaussian: a per-month anisotropic non-symmetric Wiener filter Wt = S (S + st N)-1 applied to the residuals about the deterministic (bias/trend/annual/semi-annual) model, which passes through unfiltered. Invoked via shSeries.filter("tvANS", ...).

Components

PieceDefaultNotes
N — noise covariance shapeempirical, per-order/per-parity blocks with shrinkagecaptures the correlated same-parity striping structure; supply a full covariance via NoiseCov when available (SINEX/ITSG reader: roadmap)
st — monthly scaleHelmert VCE over high degreesRobust=true uses a chi²(1)-median estimator
S — signal covarianceiterative, data-drivenSignalMode="isotropic" (degree-wise) or "inhomogeneous" (spatially varying via S = G Siso G')
Constraintsnonehard linear constraints (e.g. ocean-mass conservation): columns of Constraints

One generalized eigendecomposition eig(S, N, 'chol') makes every monthly filter an exact O(P²) update — no per-month solves.

v2.1: block-diagonal fast path and uncertainties

FeatureWhat it does
Blocks="auto"|"on"|"off"With SignalMode="isotropic", empirical noise covariance and no constraints, both S and N are block-diagonal per (order, C/S, degree parity), so the generalized eigendecomposition decouples into O(Lmax²) small blocks. Removes the O(P³) wall and the dense P×P memory footprint: Lmax = 96–120 becomes tractable. Results are identical to the full path (validated to 1.8e-15). "auto" engages it exactly when the conditions hold.
Posterior sigmainfo.sigmaXfres (P×T): per-coefficient/month 1-sigma of the filtered residual, diag((I−Wt)S) = (V.²)·(stλ/(λ+st)) — validated against the direct matrix product to 3.5e-16. Mapped onto the series as tsF.sigmaCs/sigmaSs. With hard constraints (v2.5) the EXACT diagonal of (W−I)S(W−I)' + s·WNW' is used (Python-validated to 2e-15 against the brute-force covariance; the constrained-direction identity Ac'·Cov·Ac = s·Ac'NAc holds exactly). Honest correction: the earlier unconstrained formula UNDERESTIMATED along constrained directions (validation ratios down to ~0.72), not "upper bound" as documented before.
Basin sigmaout.sigma (K×T) from basinAverage(..., Deconvolve=true): cov(c) = st·A⁻¹(Gv'·g²·Gv)A⁻&ᵀ evaluated via the stored eigenfactors (W N W' = V·diag(g²)·V'), Monte-Carlo validated (0.7% at 4·10⁴ samples). Since v2.5 the basin sigma additionally carries the OLS parameter uncertainty of the restored deterministic part (design leverage × per-coefficient residual variance; Monte-Carlo validated: emp/pred 1.18 without the term, 1.00 with it), and with constraints the deconvolution noise covariance uses the exact constrained operator. The deterministic-part errors are correlated across epochs through the shared fit (pointwise sigma reported; documented).

Usage

[tsF, op, info] = dts.filter("tvANS", ...
        SignalMode="inhomogeneous", Robust=true, Nmin=2);
% info.vce   per-month VCE factors s_t
% op         the stored linear operator: needed for deconvolution
avg = tsF.basinAverage(B, Deconvolve=true, Op=op);   % removes attenuation
res = shLowLevel.resolutionMap(op, t, latq, lonq);          % kernel half-widths

Degrees below Nmin (default 2) pass through unfiltered. Basin deconvolution solves (B' Wt B) c = B' x̂f exactly — unbiased without hydrology-model scale factors (use Ridge for near-collinear basin sets).

All formulas (Wiener MSE identity, eigen-trick equivalence, constrained-filter transpose identity, quadrature exactness, unbiased deconvolution) were cross-validated in Python (numpy/scipy) to machine precision before the MATLAB implementation; the MATLAB test suite asserts the same identities.
