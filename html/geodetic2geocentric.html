shLowLevel.geodetic2geocentric / geocentric2geodetic

Latitude conversions between the reference ellipsoid and the sphere.

Syntax

latGC = shLowLevel.geodetic2geocentric(latGD)                  % WGS84 default
latGD = shLowLevel.geocentric2geodetic(latGC, Flattening=1/298.257222101)

Description

tan(latGC) = (1−f)² tan(latGD). All SH routines here operate in geocentric latitude; map/GIS/mascon grids are almost always geodetic. The difference peaks at ~0.19° (~21 km) at 45° — a classic silent error. The synthesis/analysis entry points accept LatType="geodetic" and convert internally. The flattening is an overridable default (WGS84), not baked-in physics.
