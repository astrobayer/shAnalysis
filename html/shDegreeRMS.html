Spectral domain

shDegreeRMS

Compute degree variance, degree RMS, geoid degree amplitude, and (optionally) the formal-error degree amplitude of a set of Stokes coefficients.

Syntax

spec = shDegreeRMS(C, S)
spec = shDegreeRMS(C, S, 'R', R, 'n0', n0, 'sigmaC', sigC, 'sigmaS', sigS)

Description

This is the standard first quantitative look at a spherical harmonic field: how is the signal's power distributed across degree (spatial scale)? Real geophysical signal typically decays smoothly with degree; GRACE/GRACE-FO error grows with degree and eventually dominates -- the degree at which that happens is the natural truncation/filter-radius choice (see shSpectralCrossover).

Input Arguments

ArgumentDescription
C, S(nmax+1)x(nmax+1) fully normalized Stokes coefficient matrices.
'R'Reference radius [m] used to convert degree RMS into geoid-height-equivalent amplitude. Default 6378136.3.
'n0'Lowest degree to include; coefficients below n0 are zeroed first (e.g. N0=2 to drop degree 0/1 translation/scale terms). Default 0.
'sigmaC', 'sigmaS'Formal error matrices, same layout as C, S. If given, an error-spectrum ('errRMS'/'errAmplitude') is also computed.

Output Arguments

ArgumentDescription
spec.degree(nmax+1)x1 vector 0..nmax.
spec.degVarianceSum of Cnm^2+Snm^2 over m, per degree.
spec.degRMSsqrt(degVariance).
spec.degAmplitudeR * degRMS, in the same units as R (typically meters, geoid-height-equivalent).
spec.cumAmplitudeR * sqrt(cumsum(degVariance)) -- cumulative amplitude up to and including degree n.
spec.errRMS, spec.errAmplitudeSame quantities computed from sigmaC/sigmaS, if supplied.

Examples

Basic degree-amplitude spectrum of a monthly gravity change

spec = shDegreeRMS(dC, dS, 'R', m1.R, 'n0', 2);
plotSHSpectrum(spec);

Plots the geoid-height-equivalent degree amplitude in mm on a log-log scale. Degree 0/1 are excluded (N0=2) since they represent geocenter/reference-frame terms, not gravity-change signal.

Including the error spectrum and finding a filter radius

spec = shDegreeRMS(dC, dS, 'R', m1.R, 'n0', 2, 'sigmaC', m2.sigmaC, 'sigmaS', m2.sigmaS);
[nX, nXinterp] = shSpectralCrossover(spec);
fprintf('signal/error crossover near degree %.1f\n', nXinterp);

The crossover degree is a principled starting point for choosing a Gaussian filter radius or hard truncation degree -- filtering should suppress degrees beyond this point.
