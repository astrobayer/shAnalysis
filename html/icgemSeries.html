ICGEM time series — downloading a whole monthly series

The ICGEM temporal catalogue lists roughly seventy monthly series across all centers. Until v3.1.1 you could browse it but had to fetch the files yourself; now a temporal catalogue row is fetchable in one call, and the result folder feeds shSeries.fromFolder and standardChain directly.

The workflow

T  = shLowLevel.listICGEM(Type = "temporal");   % ~70 series, all centers
fs = shLowLevel.fetchICGEM(17, Type = "temporal");
ts = shSeries.fromFolder(fileparts(fs(1)));

Files land in <dataFolder>/icgem/series/<group>_<center>_<series>/. Selection works by index, by name or with "all", and Type= mirrors listICGEM, so the same numeric selection means the same thing on either catalogue.

Mode: one request, not three hundred

ModeWhat happens
"auto" (default)fetch the server's whole-series ZIP in a single request and unpack it; fall back to per-file automatically if the archive is unavailable
"archive"force the ZIP; fail rather than fall back
"files"force file-by-file — resumable, each file verified by parse before it replaces anything
The default is a courtesy requirement, not an optimization. icgem.gfz.de rate-limits: requesting a 283-file series one file at a time earns HTTP 429 and a tarpit, observed in the field as "too many connections". HEAD requests count too. If you must use per-file mode, leave Pause and Retries at their defaults (3 s between requests; 3 attempts with 30/60/120 s backoff).

Subsets, filters and offline mirrors

% only the 2008 months, forced per-file, gentle on the server
fs = shLowLevel.fetchICGEM(17, Type = "temporal", Mode = "files", ...
        Files = "*2008*.gfc", Pause = 3, Retries = 3);

% inject a catalogue instead of querying (mirror, subset, offline test)
F  = shLowLevel.listICGEM(Type = "temporal", Series = "03_other/ITSG/ITSG-Grace2018/monthly");
fs = shLowLevel.fetchICGEM(17, Type = "temporal", FileList = F(1:12, :));

Files= filters by filename; FileList= replaces the catalogue query entirely with a table you supply, which is how the offline tests and local mirrors work. Update=true refreshes existing files with a verified safe swap; without it, present files are skipped.

Knowing what actually happened

info.mode reports the path that ran — "model" (a single static model), "archive", "files", or "present" (everything was already there). A script can therefore tell a fresh download from a no-op, and a fallback from a clean archive fetch. Bulk selections report "M of K selections ok (N files)"; the file outputs of all selections are concatenated, so a multi-series call returns one flat list of paths.

Straight into the standard chain

fs = shLowLevel.fetchICGEM(17, Type = "temporal");
[ts, rep] = shLowLevel.standardChain(fileparts(fs(1)), Filter = "DDK3");
disp(rep.steps')
