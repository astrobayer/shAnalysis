Tutorials — Live Scripts to open and run

The fastest way into the toolbox is to open something that already works and change it. shLowLevel.makeTutorials writes one Live Script per demonstration case into tutorials/:

shLowLevel.makeTutorials();                 % all 16 cases
shLowLevel.makeTutorials(Cases = "core");   % the five headline ones
shLowLevel.makeTutorials(Cases = ["D01" "D05"]);

Each one sets up the path, runs its case with figures visible, and points at the topic page and the workflow guide for what comes next. Open the .mlx in the Live Editor, press Run, then start changing parameters — the demos work offline against the fixtures that ship with the toolbox.

Why they are generated

demo_shAnalysis is the single source of truth for what the toolbox demonstrates. A parallel set of hand-written tutorials would drift from it within a release — and .mlx is a binary zip, so the drift would not even be visible in a diff. Regenerating is cheap; keeping two copies in step by hand is not. Every tutorial says so in its own footer.

The .mlx conversion uses an internal MATLAB API that is not present in every release. If it is unavailable the .m files are still written — they are the useful artefact either way — and a warning explains that they can be converted by hand with Save As in the Live Editor.
