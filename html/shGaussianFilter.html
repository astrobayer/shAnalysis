Filtering

shGaussianFilter

Apply isotropic Gaussian smoothing directly to a set of Stokes coefficients.

Syntax

[Cf, Sf] = shGaussianFilter(C, S, radius_km)
[Cf, Sf, Wn] = shGaussianFilter(C, S, radius_km, R=R_km)

Description

Multiplies every coefficient at degree n by the corresponding Jekeli weight Wn (see shGaussianWeights). This is the standard pre-processing step immediately before spatial synthesis of a GRACE/GRACE-FO mass-change map, applied after destriping.

Input Arguments

ArgumentDescription
C, SStokes coefficient matrices to smooth.
radius_kmGaussian averaging radius [km].
RSphere radius, passed through to shGaussianWeights, default 6378.1363 km.

Output Arguments

ArgumentDescription
Cf, SfSmoothed coefficient matrices, same size as input.
WnThe weight vector applied (for inspection/plotting).

Examples

Standard GRACE-FO post-processing chain

[dCf, dSf] = shDestripe(dC, dS, MinOrder=6, PolyOrder=3);
[dCg, dSg] = shGaussianFilter(dCf, dSf, 300);
[N, lat, lon] = shSynthesis(dCg, dSg, GM, R, -90:1:90, 0:1:359, Quantity= 'geoid');

Destripe first, then smooth, then synthesize -- the order used in most published GRACE mass-change products, though the literature is not fully unanimous on destripe-vs-smooth ordering.
