shLowLevel.shSynthesisDeformation

Elastic load deformation (up / north / east) — the GRACE ↔ GNSS loading comparison.

Syntax

[up, north, east] = shLowLevel.shSynthesisDeformation(C, S, R, lat, lon, ...
    kn=kn, hn=hn, ln=ln)                       % grid
[up, north, east] = g.deformation(latSta, lonSta, kn=kn, hn=hn, ln=ln, ...
    Mode="points", LatType="geodetic")         % GNSS stations

Description

Synthesizes the three components of elastic surface deformation caused by the load in the (residual) Stokes coefficients (Wahr et al. 1998):

up    = R Σ h'n/(1+k'n) ΔC Ybar
north = R Σ l'n/(1+k'n) ∂Ybar/∂φ
east  = R Σ l'n/(1+k'n) (1/cosφ) ∂Ybar/∂λ

The vertical is a pure degree factor (also available as Quantity="deformation_up" in every synthesis entry point); the horizontals need the exact SH gradient. shLowLevel.legendreALFDeriv supplies dPbar/dφ via a frozen identity, calibrated per (n,m) against numerical differentiation and validated to the finite-difference floor (~1e-9); north/east match brute-force gradients to ~5e-10.

Arguments

NameType / sizeDescription
C, S(n1,n1) doubleRESIDUAL coefficients (mean removed) — deformation from the static field is not meaningful
kn, hn, ln(≥n1,1) doubleload Love numbers k', h', l' — user-supplied, from ONE consistent loading model and degree-1 frame (CF/CE)
nmin (1)doubledegree 0 carries no deformation; include degree 1 only with consistent geocenter handling
Mode"grid" | "points"outer-product grid, or pairwise station list
up, north, east[m]east is NaN at |lat| = 90 (undefined direction)
Workflow (guide, G7): monthly residual series → tvANS → per-month g.deformation(staLat, staLon, Mode="points", LatType="geodetic") → compare against GNSS displacement time series.
