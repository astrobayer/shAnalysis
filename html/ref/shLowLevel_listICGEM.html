shLowLevel.listICGEM

List gravity field models available at ICGEM (GFZ).

Syntax

[T, info] = shLowLevel.listICGEM()[T, info] = shLowLevel.listICGEM(Type="static", Series="", Source="", ...)

Description

T = shLowLevel.listICGEM() returns a table of the STATIC global models from https://icgem.gfz.de/tom_longtime (name, year, max degree, data sources, direct .gfc download URL) - feed a row's name into shLowLevel.fetchICGEM to download.

Examples

Runnable (docs/apiExamples.json)
T = shLowLevel.listICGEM(Type = "temporal", Series = "ITSG-Grace2018");

Input Arguments

None.

Name-Value Arguments

NameSizeTypeDefaultDescription
Type1 x 1string"static""static" | "temporal"
Series1 x 1string""temporal only: catalogue path of one series to list its individual files (see above)
Source1 x 1string""local HTML file instead of the live page (offline/testing; the parsers are fixture-tested)
Timeout1 x 1double60per-request timeout [s]

Output Arguments

NameDescription
Ttable: static: name, year, degree, data, url temporal: group, center, series, path, url, zip temporal+Series: name, url
info(1,1) struct fields source (1,1) string where the catalogue came from retrieved (1,1) string when it was read note (1,1) string what the listing covers

Error Identifiers

IdentifierRaised when
