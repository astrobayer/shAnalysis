shLowLevel.fetchICGEM

Download a static gravity field model from ICGEM.

Syntax

[file, info] = shLowLevel.fetchICGEM(model)[file, info] = shLowLevel.fetchICGEM(model, Dest="", Timeout=300, List=table(), ...)

Description

FILE = shLowLevel.fetchICGEM("EGM2008") resolves the model name against shLowLevel.listICGEM (case-insensitive exact match, else unique prefix) and downloads the .gfc into <dataFolder>/icgem. Existing files are skipped. Load with shCoefficients.read(FILE).

Examples

Runnable (docs/apiExamples.json)
f = shLowLevel.fetchICGEM("GOCO06s");        % static model by name

Input Arguments

NameSizeTypeDefaultDescription
modeln x m-requiredICGEM model name as listed by shLowLevel.listICGEM

Name-Value Arguments

NameSizeTypeDefaultDescription
Dest1 x 1string"""" = the v3.16 layout: static models under dataFolder/static, series under dataFolder/series/<group_center_series>
Timeout1 x 1double300,
Listn x mtabletable()) ([]) pass a pre-fetched listICGEM table (avoids re-listing in loops / enables the offline fixture in tests)
Proxy1 x 1string""per-call proxy URL, e.g. "http://proxy:8080" (empty: MATLAB Web Preferences)
Update1 x 1logicalfalserefresh existing files (safe swap: verified before replacing)
Quiet1 x 1logicalfalsesuppress progress output ([k/K] counter, per-file timing, failure summary)
Pause1 x 1double3seconds between models in bulk mode - the ICGEM server RATE-LIMITS rapid requests (HTTP 429), which looks like a stall
Retries1 x 1double3retry attempts on 429/timeout, with 30/60/120 second backoff
Type1 x 1string"static""static" | "temporal": which catalogue numeric selections and names resolve against (mirrors shLowLevel.listICGEM)
Files1 x 1string"*.gfc*"filename filter in series mode
Mode1 x 1string"auto"series download strategy: "auto" fetches the server's whole-series ZIP in ONE request (the rate limiter punishes hundreds of per-file requests) and falls back to file-by-file on failure; "archive" | "files" force either. Per-file is resumable with every file verified before the swap.
FileListn x mtabletable()) series mode: use this file table (from listICGEM(Series=...)) instead of querying - for subsetting or offline mirrors

Output Arguments

NameDescription
filestring local path(s): one per model, or every file of the series in temporal mode (bulk selections are concatenated)
info(1,1) struct fields url (1,:) string the URL(s) used skipped (1,1) logical the file was already present updated (1,:) string files replaced by a newer copy failed (1,1) logical the download did not complete mode (1,1) string which path actually ran: "model" (single static model) | "archive" (whole series as one ZIP) | "files" (per-file fallback) | "present" (nothing to do). A script tells a fresh download from a no-op by this field

IdentifierRaised when
