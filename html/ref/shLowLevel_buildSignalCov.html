shLowLevel.buildSignalCov

Iterative, data-driven signal covariance.

Syntax

[S, info] = shLowLevel.buildSignalCov(Xres, N, idx)[S, info] = shLowLevel.buildSignalCov(Xres, N, idx, Mode='isotropic', NIter=3, FloorRel=1e-8, ...)

Description

[S, info] = shLowLevel.buildSignalCov(Xres, N, idx) estimates the signal covariance from the residual series itself - no hydrology prior.

Examples

Runnable (docs/apiExamples.json)
S = shLowLevel.buildSignalCov(Xres, N, idx, Mode = "isotropic");

Input Arguments

NameSizeTypeDefaultDescription
XresP x Tdoublerequireddouble residual coefficient vectors (shIndex ordering)
NP x P-requireddouble or (1,1) struct noise covariance, dense or the block container from buildNoiseCov(Assemble='blocks'); the block form supports Mode='isotropic' only
idx1 x 1structrequiredstruct shLowLevel.shIndex matching Xres

Name-Value Arguments

NameSizeTypeDefaultDescription
Moden x m-'isotropic''isotropic' | 'inhomogeneous' signal model
NIter1 x 1double3(1 x 1) double re-estimation iterations
FloorRel1 x 1double1e-8(1 x 1) double relative variance floor
MapSmooth1 x 1logicaltrue(1 x 1) logical cap the variance map dynamic range to [0.1, 10] before renormalizing it

Output Arguments

NameDescription
S(P x P) double signal covariance in idx ordering; sparse diagonal when N is the block container
info(1,1) struct fields c (P x NIter+1) double per-coefficient variances, column 1 the initialization, one column per iteration varMap (Ngrid x 1) double spatial variance map, weighted global mean 1; Mode='inhomogeneous' only
