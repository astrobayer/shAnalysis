shSeries.disp

Compact display: months, span, gaps, processing history.

Syntax

shSeries.disp(obj)

Description

disp(TS) prints the product type, the number of epochs, the maximum degree and the covered epoch range, followed by the processing history. Called automatically when an shSeries object is shown without a semicolon.

Examples

From the help block
    ts = shSeries.read("ITSG-Grace2018_n60_*.gfc");
    disp(ts)
Runnable (docs/apiExamples.json)
disp(ts)
