shCoefficients.analysis

Spherical harmonic analysis: gridded/scattered data ->

Syntax

[obj, info] = shCoefficients.analysis(grid, latVec, lonVec, nmax)[obj, info] = shCoefficients.analysis(grid, latVec, lonVec, nmax, Quantity="geoid", Method="auto", Weights="none", ...)

Description

Stokes coefficients (the inverse of synthesis).

Examples

Runnable (docs/apiExamples.json)
g2 = shCoefficients.analysis(grid, lat, lon, 10, Kaula = 1e-10);

Input Arguments

NameSizeTypeDefaultDescription
gridn x mdoublerequiredfield values on the (lat, lon) grid
latVecn x mdoublerequiredgeocentric latitude vector of the grid [deg]
lonVecn x mdoublerequiredlongitude vector of the grid [deg], [0, 360)
nmax1 x 1doublerequiredmaximum spherical harmonic degree

Name-Value Arguments

NameSizeTypeDefaultDescription
Quantity1 x 1string"geoid"physical quantity of the grid values; its kernel is divided out, see shLowLevel.kernelFactors
Method1 x 1string"auto""auto" | "rings" | "ls", see shAnalysisGrid
Weights1 x 1string"none"("none" | "coslat") latitude weighting
Kaula1 x 1double0(1 x 1) Kaula regularization for "ls"
knn x mdouble[]load Love numbers, degrees 0..nmax, required for Quantity="ewh" (user-supplied, never hardcoded)
hnn x mdouble[]vertical-deformation Love numbers, degrees 0..nmax
rho_ave1 x 1double5517mean Earth density [kg/m^3] in the EWH kernel
rho_water1 x 1double1000water density [kg/m^3] in the EWH kernel
GM1 x 1double3.986004415e14, R (6378136.3), Epoch (NaN) stored on the returned object
R1 x 1double6378136.3reference radius [m] (default 6378136.3, overridable)
Epoch1 x 1doubleNaNepoch [decimal years]
Name1 x 1string"analysis"(1 x 1) string stored as the object name
LatType1 x 1string"geocentric""geocentric" | "geodetic": how latVec is interpreted; geodetic values are converted with Flattening before evaluation
Flattening1 x 1double1/298.257223563flattening of the reference ellipsoid for that conversion (WGS84; overridable, never silently assumed)
Fill1 x 1doubleNaNthe value that replaces NaN in GRID - e.g. 0 where a land-only grid has no ocean value. NaN, the default, refuses a grid that holds NaN: what the gaps mean is the caller's call, and NaN would otherwise reach every coefficient without an error (v5.8.0)

Output Arguments

NameDescription
obj(1 x 1) shCoefficients Stokes coefficients estimated from the grid (exact on ring grids; Kaula for scattered points)
info(1,1) struct the estimation diagnostics, as returned by shLowLevel.shAnalysisGrid

Error Identifiers
