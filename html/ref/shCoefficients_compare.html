shCoefficients.compare

Full comparison against another solution (v2.6.0).

Syntax

[rep, h] = shCoefficients.compare(obj, other, varargin)

Description

REP = g.compare(G2, ...) delegates to shLowLevel.compareSolutions with OBJ as the first solution; all options pass through (Plot=true for the 4-panel figure).

Examples

Runnable (docs/apiExamples.json)
rep = g.compare(gF, Names = ["raw", "G350"]);

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
rep(1,1) struct as returned by shLowLevel.compareSolutions, which documents every field
h(1 x 1) graphics handle figure (Plot = true)

Error Identifiers

None documented in the help block. Argument validation raises the MATLAB:* identifiers of the arguments block.
