shCoefficients.destripe

Swenson & Wahr (2006) / P3M6 decorrelation.

Syntax

out = shCoefficients.destripe(obj)out = shCoefficients.destripe(obj, MinOrder=6, PolyOrder=3, WindowLength=[])

Description

OUT = obj.destripe(MinOrder=6, PolyOrder=3, WindowLength=[]) Formal errors are passed through UNCHANGED (the destriping operator is data-dependent; rigorous error propagation is not defined for it - use the tvANS filter on an shSeries for a filter with proper covariance semantics).

Examples

Runnable (docs/apiExamples.json)
g = g.destripe(MinOrder = 6);
