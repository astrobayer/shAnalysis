shLowLevel.synthesisMatrix

Dense SH synthesis matrix on a Gauss-Legendre grid.

Syntax

[Y, w, grid] = shLowLevel.synthesisMatrix(idx)[Y, w, grid] = shLowLevel.synthesisMatrix(idx, NLat=idx.Lmax + 1, NLon=2*idx.Lmax + 2, GridOnly=false)

Description

[Y, W, GRID] = shLowLevel.synthesisMatrix(IDX) returns Y (Ngrid x P) with f = Y*x for coefficient vectors x in IDX ordering (shLowLevel.shIndex), and quadrature weights W (Ngrid x 1), normalized such that the discrete analysis A = Y' * diag(W) is EXACT for band-limited fields: A*Y = eye(P) to machine precision (asserted in the test suite).

Examples

Runnable (docs/apiExamples.json)
[Y, w] = shLowLevel.synthesisMatrix(idx);    % quadrature-consistent pair
