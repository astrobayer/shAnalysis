shLowLevel.buildNoiseCov

Monthly-solution noise covariance (shape matrix).

Syntax

[N, info] = shLowLevel.buildNoiseCov(Xres, idx)[N, info] = shLowLevel.buildNoiseCov(Xres, idx, Mode='empirical', FullCov=[], Shrinkage=0.1, ...)

Description

[N, info] = shLowLevel.buildNoiseCov(Xres, idx) estimates the noise covariance from the residual coefficient series Xres (P x T, residuals about the deterministic model). Two modes:

Examples

Runnable (docs/apiExamples.json)
N = shLowLevel.buildNoiseCov(Xres, idx);          % empirical order/parity blocks

NameSizeTypeDefaultDescription

Output Arguments

NameDescription

info(1,1) struct which fields are present depends on the path taken, fields mode (1,:) char 'empirical' | 'full' | 'full-blocks' nBlocks (1,1) double number of (order, C/S, parity) blocks; absent for mode 'full' T (1,1) double epochs used; mode 'empirical' only shrinkage (1,1) double the gamma applied; 'empirical' only
