shCoefficients.regionalBasis

A local basis for a region, at this field's degree.

Syntax

B = shCoefficients.regionalBasis(obj, region)B = shCoefficients.regionalBasis(obj, region, Nmin=..., Type=..., BufferKm=..., ...)

Description

B = g.regionalBasis(REGION) is shLowLevel.regionalBasis(shLowLevel.shIndex(g.nmax), REGION): radial basis functions, Slepian tapers or the SH basis for a basin or region, built for the degree this field carries, so that g.regionalProject(B) cannot meet an index of another size. That function documents the bases and the projector.

Examples

From the help block
    B = g.regionalBasis("Elbe", Type = "slepian");
    a = g.regionalProject(B);
