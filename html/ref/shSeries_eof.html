shSeries.eof

Empirical orthogonal functions of the series.

Syntax

[modes, pcs, varExplained, info] = shSeries.eof(obj)[modes, pcs, varExplained, info] = shSeries.eof(obj, NModes=..., Center=...)

Description

[MODES, PCS, VE, INFO] = ts.eof() decomposes the series into spatial modes and unit-variance principal components by an SVD of the time-centred coefficient stack - shLowLevel.eofAnalysis, which documents the scaling: MODES{k} times PCS(:,k) reconstructs mode k's contribution exactly. It is usually run on a residual, after ts.climatology. The options go to shLowLevel.eofAnalysis only when given; "(lane default)" is that function's.

Examples

From the help block
    [~, resid] = ts.climatology();
    [modes, pcs, ve] = resid.eof(NModes = 3);
