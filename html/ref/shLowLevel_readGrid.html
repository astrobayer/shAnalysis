shLowLevel.readGrid

Read a gridded field or stack from a CF netCDF file.

Syntax

[grid, latDeg, lonDeg, info] = shLowLevel.readGrid(filename)[grid, latDeg, lonDeg, info] = shLowLevel.readGrid(filename, Var="")

Description

[GRID, LAT, LON, INFO] = shLowLevel.readGrid(FILE) reads the one latitude-longitude field in FILE - a 2-D grid, or a 3-D stack with a time axis - and returns it in the toolbox's layout: GRID is (nlat x nlon) or (nlat x nlon x T), LAT and LON are column vectors [deg], and INFO.epochs holds the epochs as decimal years. It is the inverse of shLowLevel.writeGrid, and it reads CF grids from elsewhere too - hydrological models, GravIS Level-3 grids - so that they can enter shCoefficients.analysis. [...] = shLowLevel.readGrid(FILE, Var = NAME) names the variable when the file holds several on the grid, as GravIS grids do (tws, std_tws, leakage, model_atmosphere).

Examples

From the help block
    f = fullfile(getpref('shAnalysis', 'GravisFolder'), ...
        'GRAVIS-3_GFZOP_0600_TWS_GRID_GFZ_0006.nc');
    [tws, lat, lon, info] = shLowLevel.readGrid(f, Var = "tws");  % cm
    g = shCoefficients.analysis(tws(:, :, 1) / 100, lat, lon, 60, ...
        Quantity = "ewh", kn = kn, LatType = "geodetic", Fill = 0);

  See also shLowLevel.writeGrid, shLowLevel.readMascon,
  shCoefficients.analysis.

Output Arguments

NameDescription

latDeg(nlat,1) double latitudes [deg], in the file's order
lonDeg(nlon,1) double longitudes [deg], 0..360, ascending
info(1,1) struct fields var (1,1) string the variable read units (1,1) string its units attribute ("" if none) longName (1,1) string its long_name attribute ("" if none) latType (1,1) string the lat_type attribute writeGrid stores; "" when the file does not say epochs (T,1) double epochs [decimal years]; [] for a 2-D grid timeUnits (1,1) string the time axis' units; "" for 2-D calendar (1,1) string its calendar attribute ("" if none) conventions (1,1) string the global Conventions attribute title (1,1) string the global title attribute file (1,1) string the file read
