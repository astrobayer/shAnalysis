shLowLevel.readDDK

Load a DDK (Kusche) anisotropic decorrelation filter.

Syntax

W = shLowLevel.readDDK(source)W = shLowLevel.readDDK(source, Nmax=[])

Description

W = shLowLevel.readDDK(SOURCE) loads a DDK filter into the toolbox's order-block container, ready for shLowLevel.applyDDK / g.applyDDK / ts.applyDDK. The DDK filters (Kusche 2007; Kusche et al. 2009, DDK1..DDK8) are the standard published anisotropic alternative to Gaussian smoothing and the usual benchmark against tvANS.

Examples

Runnable (docs/apiExamples.json)
W = shLowLevel.readDDK("DDK3");   % DDK3 ships with the toolbox; others via shLowLevel.fetchDDK

Input Arguments

NameSizeTypeDefaultDescription
sourcen x m-requireda DDK name ("DDK3"), a filter file (binary, .mat or ASCII) or a W struct; a folder is not accepted

Name-Value Arguments

NameSizeTypeDefaultDescription
Nmaxn x mdouble[]truncate the filter to degrees <= Nmax (leading submatrix per block - identical to the reference filterSH behavior for inputs with nmax below the filter's Lmax). Required to apply an Lmax-120 DDK to n96 series without an nmaxMismatch error.

Output Arguments

NameDescription
W(1,1) struct fields nmax (1,1) double maximum degree the filter covers name (1,1) string the path of the file read (for a name form, the file it resolved to); a W struct keeps its own blocks (1 x K) struct array one per (order, cs) block (241 for the Lmax-120 binary files), each with m (1,1 double), cs (1,1 double, 0 for C and 1 for S), n (1,B double, the degrees) and M (B x B double, the square block matrix)

Error Identifiers

IdentifierRaised when
shLowLevel:readDDK:badBinarythe GROOPS binary is not a readable block-diagonal matrix: the endian marker, the matrix type, the Lmax metadata, a block size or the pack-vector length disagrees with the header
shLowLevel:readDDK:badContainerthe W struct lacks nmax or blocks(m, cs, n, M)
shLowLevel:readDDK:badLinean ASCII block header is not "block m cs n1 n2"
shLowLevel:readDDK:badMatrixRowan ASCII block row does not have the block's number of values
shLowLevel:readDDK:badSourceSOURCE is neither a W struct, a .mat file nor an ASCII file
shLowLevel:readDDK:emptyMatthe .mat file holds no variable
shLowLevel:readDDK:fileNotFoundthe file does not exist or cannot be opened
shLowLevel:readDDK:noDatathe ASCII file holds no block
shLowLevel:readDDK:notFetchedthe named DDK file is in neither the data folder nor the shipped test data - run shLowLevel.fetchDDK first
