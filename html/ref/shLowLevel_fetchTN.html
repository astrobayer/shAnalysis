shLowLevel.fetchTN

Download the TN-13/TN-14 low-degree completion files on demand.

Syntax

[files, info] = shLowLevel.fetchTN()[files, info] = shLowLevel.fetchTN(Providers=["GFZ", "CSR", "JPL"], TN14=true, Release="RL06.3", ...)

Description

FILES = shLowLevel.fetchTN() fetches the GRACE/GRACE-FO technical notes that complete the standard processing chain into <dataFolder>/TN: TN-14 GSFC SLR C20/C30 replacement (shLowLevel.readTN14/applyTN14) TN-13 geocenter (degree 1) per provider (shLowLevel.readTN13/addDegree1) Source: the GFZ ISDC open document server (URLs verified 2026-08-07). No TN file is tracked in the repository: CI checks the test copies out of the fixtures tag into tests/test_data, so offline use needs this fetch (or BaseURL pointing at a local mirror folder) once.

Examples

From the help block
    shLowLevel.fetchTN(Update = true);            % monthly refresh, safe swap
    tn13 = shLowLevel.readTN13(fullfile(shLowLevel.dataFolder(), "TN", ...
               "TN-13_GEOC_CSR_RL06.3.txt"));
    g1 = g.applyTN14(tn14).addDegree1(tn13);

Proxy1 x 1string""per-call proxy, e.g. "http://proxy.uni.de:8080" (websave otherwise honours MATLAB Web Preferences)
Timeout1 x 1double60, Quiet (false)
Quiet1 x 1logicalfalsesuppress progress output
MaxTries1 x 1double-(1,1) double attempts httpFetch makes per download on a transient failure (429, 5xx, a network error), with exponential backoff between them; not forwarded when omitted, so httpFetch's default is the only one. The Proxy path makes one attempt
BaseDelay1 x 1double-(1,1) double [s] first backoff wait; after failed attempt k (k < MaxTries) httpFetch waits BaseDelay 2^(k-1) plus up to 25% jitter, and none after the last. A failing download costs about BaseDelay (2^(MaxTries-1) - 1) seconds of waiting - 14 s at the defaults (up to 17.5 s with jitter), which is what offline tests pay unless they pass MaxTries = 1
