shLowLevel.shSynthesisGradientTensor

Full gravity gradient tensor in the local NEU frame.

Syntax

[comps, info] = shLowLevel.shSynthesisGradientTensor(C, S, GM, R, latDeg, lonDeg)[comps, info] = shLowLevel.shSynthesisGradientTensor(C, S, GM, R, latDeg, lonDeg, Height=250e3, Nmin=2)

Description

[COMPS, INFO] = shLowLevel.shSynthesisGradientTensor(C, S, GM, R, LAT, LON, Height (250e3)=250e3) synthesizes all six independent components of the disturbing gravity gradient tensor (GOCE-style diagnostics) in the local north-east-up frame at radius r = R + Height:

Examples

Runnable (docs/apiExamples.json)
T = shLowLevel.shSynthesisGradientTensor(g.C, g.S, g.GM, g.R, lat, lon, Height = 450e3);
