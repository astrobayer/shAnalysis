shCoefficients.read

Read an ICGEM .gfc/.gfct/.gfc.gz file into an shCoefficients.

Syntax

obj = shCoefficients.read(filename)obj = shCoefficients.read(filename, Epoch=NaN, ProductType="")

Description

G = shCoefficients.read(FILE) parses product type and mid-epoch from standard GRACE L2 filenames (GSM/GAA/GAB/GAC/GAD-2_...); override with Epoch (NaN)=..., ProductType ("")=... when needed.

Examples

Runnable (docs/apiExamples.json)
g = shCoefficients.read("ITSG-Grace2018_n60_2008-04.gfc", Epoch = 2008.29);
