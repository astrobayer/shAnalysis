shLowLevel.shDegreeRMS

Spectral (degree-domain) analysis of spherical harmonic coefficients.

Syntax

spec = shLowLevel.shDegreeRMS(C, S)spec = shLowLevel.shDegreeRMS(C, S, R=6378136.3, Nmin=0, SigmaC=[], ...)

Description

SPEC = SHDEGREERMS(C, S) computes, per degree n = 0..nmax: .degVariance(n+1) = sum_m (Cnm^2 + Snm^2) .degRMS(n+1) = sqrt(degVariance) .degAmplitude(n+1) = R * degRMS [geoid-height-equivalent, m] .cumAmplitude(n+1) = R * sqrt(cumsum(degVariance)) [cumulative, m]

Examples

Runnable (docs/apiExamples.json)
spec = shLowLevel.shDegreeRMS(g.C, g.S);          % degree-amplitude spectrum struct
