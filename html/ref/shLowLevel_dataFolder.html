shLowLevel.dataFolder

Get or set the data folder of the toolbox, in the data pool.

Syntax

folder = shLowLevel.dataFolder(newFolder)folder = shLowLevel.dataFolder(newFolder, Probe=false)

Description

F = shLowLevel.dataFolder() returns the current data folder (created on demand), resolved in this order (the data-pool contract, v6.0.0): 1. the stored preference getpref('shAnalysis','dataFolder'), set by PATH below or by setup_shAnalysis(DataFolder = PATH) 2. <getenv("DATAPOOL")>/GravityField 3. <getenv("READING_DATA_POOL")>/GravityField (the older name, still honoured) 4. otherwise it REFUSES with shLowLevel:dataFolder:noDataPool. There is no <toolbox root>/data default any more: nothing downloaded lands in the toolbox folder. F = shLowLevel.dataFolder(PATH) sets and persists a user folder (MATLAB preference, survives sessions: setpref('shAnalysis','dataFolder')). F = shLowLevel.dataFolder("reset") removes the preference and returns what the pool resolves to now ("" when neither variable is set); it neither refuses nor creates a folder. F = shLowLevel.dataFolder(Probe = true) the same lookup with no side effect: no folder is created, and "" is returned instead of either refusal. For lookups that have a fallback (readDDK's "DDK<n>", twsChain, the demos, setup_shAnalysis' summary).

Examples

From the help block
    setenv("DATAPOOL", "D:/DATAPOOL");      % normally done by startup.m
    f = shLowLevel.dataFolder()             % -> D:/DATAPOOL/GravityField
Runnable (docs/apiExamples.json)
shLowLevel.dataFolder("D:/grace_data")      % shared download location
