shLowLevel.regionalBasis

A local basis for a region, as a linear map to SH coefficients.

Syntax

B = shLowLevel.regionalBasis(idx, region)B = shLowLevel.regionalBasis(idx, region, Type="rbf", BufferKm=600, Grid="icosahedral", ...)

Description

B = shLowLevel.regionalBasis(IDX, REGION) builds a set of K space-localising basis functions for REGION and returns them as the matrix B.T (P x K) that maps basis coefficients a to spherical-harmonic coefficients in IDX ordering, x = B.T * a, band-limited at IDX.Lmax. Every basis enters the rest of the toolbox through T alone: an SH solution or normal equation becomes T' N T and T' b, a grid or point functional A_SH T, and a model series becomes basis coefficients through the projector B.Proj (K x P). This is the state of the regional Kalman filter of CLAUDE.md WP8 (Kurtenbach 2012, C-683, outlook; Woehnke et al. 2025; Steffen et al. 2026).

Examples

From the help block
    idx = shLowLevel.shIndex(60);
    B = shLowLevel.regionalBasis(idx, "Elbe");            % RBF, Kaula
    a = shLowLevel.regionalProject(ts.Cs, ts.Ss, B);      % K x T
    S = shLowLevel.regionalBasis(idx, "Elbe", Type = "slepian", ...
                                 Threshold = 0.5);
    M = shLowLevel.regionalBasis(idx, "Elbe", Type = "mascon", kn = kn);
    ewh = M.Proj * [C; S];      % cap EWH [m] of a field (C, S stacked
                                % in idx order, as regionalProject does)
