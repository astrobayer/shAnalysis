shSeries.kalman

Kalman-smoothed series (Kurtenbach/Kvas), solution mode.

Syntax

[out, rep] = shSeries.kalman(obj)[out, rep] = shSeries.kalman(obj, ModelSeries=..., Order=..., Structure=..., ...)

Description

[TSK, REP] = ts.kalman(ModelSeries = TSM) runs shLowLevel.kalmanChain with TS as the observations: the VAR process model is estimated from TSM, every epoch of TS is one observation weighted by its formal sigmas (or NoiseCov), and a forward Kalman filter plus an RTS smoother return the smoothed series. shLowLevel.kalmanChain documents the chain, its references and its memory cost.

Examples

From the help block
    [tsk, rep] = ts.kalman(ModelSeries = tsm, Order = 1);
    % bridge the 2017-18 gap with an HLSST series
    [tsb, rep] = ts.kalman(ModelSeries = tsm, SecondSeries = hl);
