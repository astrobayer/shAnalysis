shSeries.read

Read a series of gfc files (pattern or list), sorted by epoch.

Syntax

obj = shSeries.read(files)obj = shSeries.read(files, Truncate=NaN)

Description

TS = shSeries.read("GSM-2_*.gfc") or shSeries.read(fileList).

Examples

Runnable (docs/apiExamples.json)
ts2 = shSeries.read("ITSG-Grace*_n60_*.gfc");   % wildcard, epoch-sorted

Input Arguments

NameSizeTypeDefaultDescription
filesn x m-requiredglob pattern (containing * or ?) or string array of .gfc file paths; for a folder use shSeries.fromFolder

Name-Value Arguments

NameSizeTypeDefaultDescription
Truncate1 x 1doubleNaNtruncate every field to this nmax while reading (NaN: keep the file resolution)

Output Arguments

NameDescription
obj(1 x 1) shSeries wildcard-read, epoch-sorted stack

Error Identifiers
