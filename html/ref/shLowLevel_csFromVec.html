shLowLevel.csFromVec

Unpack a shLowLevel vector into lower-triangular Cnm/Snm matrices.

Syntax

[cnm, snm] = shLowLevel.csFromVec(x, idx)

Description

[cnm, snm] = shLowLevel.csFromVec(x, idx). Coefficients outside the index range (n < Nmin) are zero.

Examples

Runnable (docs/apiExamples.json)
[C, S] = shLowLevel.csFromVec(x, idx);           % vector -> triangle matrices

Input Arguments

NameSizeTypeDefaultDescription
x: x 1doublerequiredcoefficient stack, (P x T) in index ordering
idx1 x 1structrequiredindex struct from shLowLevel.shIndex (fields n, m, cs, P, Lmax, minDegree, pos)

Name-Value Arguments

None.

Output Arguments

NameDescription
cnm(nmax+1 x nmax+1) double cosine coefficients, C(n+1, m+1)
snm(nmax+1 x nmax+1) double sine coefficients, S(:, 1) = 0
