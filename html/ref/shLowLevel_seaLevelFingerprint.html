shLowLevel.seaLevelFingerprint

Elastic sea-level fingerprint (sea-level equation).

Syntax

[S, grid, info] = shLowLevel.seaLevelFingerprint(loadRegion, ocean, idx)[S, grid, info] = shLowLevel.seaLevelFingerprint(loadRegion, ocean, idx, kn=..., hn=..., LoadValue=1, ...)

Description

[S, GRID, INFO] = shLowLevel.seaLevelFingerprint(LOADREGION, OCEAN, IDX, kn ("")=kn, hn ("")=hn) solves the elastic sea-level equation for a land load: the ocean does NOT rise uniformly - it follows the perturbed geoid minus the deformed crust under global mass conservation (Farrell & Clark 1976, elastic limit):

Examples

Runnable (docs/apiExamples.json)
S = shLowLevel.seaLevelFingerprint(gLoad, oceanMask, idx, kn = LN.kn, hn = LN.hn);

Input Arguments

NameSizeTypeDefaultDescription
loadRegionn x m-requiredhandle f(latDeg,lonDeg) -> surface density CHANGE [kg/m^2] (negative = mass loss), polygon (Kx2 with opts.LoadValue (1)), or Ngrid x 1 values on the solver grid
oceann x m-requiredocean region: handle | polygon | mask (shLowLevel.evalMask forms). The load is restricted to land (1 - ocean).
idx1 x 1structrequiredshLowLevel.shIndex(Lmax, Nmin = 0) - Nmin MUST be 0 (mass conservation lives in degree 0/1) kn, hn (REQUIRED) load Love numbers k'_n, h'_n (user-supplied)

Name-Value Arguments

NameSizeTypeDefaultDescription
knn x mdouble-load Love numbers, (degree, kn) table or column vector - always user-supplied, no reference frame is assumed

LoadValue1 x 1double1kg/m^2 for polygon loads
rho_water1 x 1double1000, rho_ave (5517), R (6378136.3)
rho_ave1 x 1double5517mean Earth density [kg/m^3] (default 5517, overridable)

MaxIter1 x 1double50maximum sea-level-equation iterations
Tol1 x 1double1e-8convergence threshold on max|dS|, RELATIVE to |eustatic| (the absolute bound is Tol * |eustatic|)

Output Arguments

NameDescription
S(Ngrid,1) double relative sea-level change over the ocean [m per unit load], 0 on land
grid(1,1) struct the solver grid, as returned by shLowLevel.synthesisMatrix (latDeg/lonDeg rings)
info(1,1) struct fields iterations (1,1) double sweeps of the sea-level equation actually run dS (1,1) double last change in the solution converged (1,1) logical dS fell below the tolerance massResidual (1,1) double [kg/m^2 sphere mean] - the conservation check eustatic (1,1) double uniform equivalent rise [m] kappa (1,1) double the rotational feedback factor applied areaFractionOcean (1,1) double ocean area / sphere area S2D (nlat x nlon) double the sea-level change field
