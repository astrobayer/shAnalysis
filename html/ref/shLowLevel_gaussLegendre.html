shLowLevel.gaussLegendre

Gauss-Legendre nodes and weights on [-1, 1].

Syntax

[x, w] = shLowLevel.gaussLegendre(n)

Description

[X, W] = shLowLevel.gaussLegendre(N) via Golub-Welsch (symmetric eigenvalue problem of the Jacobi matrix). Exact for polynomials up to degree 2N-1: integral f(t) dt = sum(W .* f(X)).

Examples

Runnable (docs/apiExamples.json)
[xNodes, w] = shLowLevel.gaussLegendre(61);   % quadrature nodes/weights
