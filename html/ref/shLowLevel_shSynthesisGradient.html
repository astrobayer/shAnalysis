shLowLevel.shSynthesisGradient

North/east/up gradient of any synthesized quantity.

Syntax

[dq, info] = shLowLevel.shSynthesisGradient(C, S, GM, R, latDeg, lonDeg)[dq, info] = shLowLevel.shSynthesisGradient(C, S, GM, R, latDeg, lonDeg, Quantity="geoid", kn=[], hn=[], ...)

Description

[DQ, INFO] = shLowLevel.shSynthesisGradient(C, S, GM, R, LAT, LON, Quantity=..., Units=..., Mode=...) returns the spatial gradient of the field that shLowLevel.shSynthesis would produce from the SAME coefficients and the SAME options, resolved in the local north-east-up frame:

Examples

From the help block
    % a zonal degree-2 pattern: the east gradient must vanish exactly
    C = zeros(3); S = zeros(3); C(3,1) = 1;              % C_20
    lat = -80:10:80; lon = 0:20:340;
    dq = shLowLevel.shSynthesisGradient(C, S, 3.986004415e14, ...
            6378136.3, lat, lon, Quantity = "none", Units = "perRadian");
    max(abs(dq.east(:)))            % 0
    quiver(lon, lat, dq.east, dq.north)

  References
    Wahr, Molenaar & Bryan (1998), JGR 103(B12) - the degree factors.
    Holmes & Featherstone (2002), J Geod 76 - the Legendre recursion
    whose exact latitude derivative shLowLevel.legendreALFDeriv carries.

  Python-validated before implementation (tools/dev/validate_gradient.py):
  all three components against 5-point finite differences of an
  independent scalar synthesis at 1e-12 (the difference floor), the
  radial identities d(potential)/dr = -gravity_disturbance and
  d(gravity_disturbance)/dr = -gravity_gradient_rr at 4e-16, and
  single-coefficient closed forms at 2e-16.

  See also shLowLevel.shSynthesis, shLowLevel.shSynthesisDeformation,
  shLowLevel.shSynthesisGradientTensor, shLowLevel.kernelFactors,
  shLowLevel.legendreALFDeriv.

The components stay in the local SPHERICAL frame at the point: "up" is radial, not the ellipsoid normal, which differs from it by the geodetic- geocentric latitude difference (up to 0.19 deg)
SemiMajorAxis1 x 1double6378137ellipsoid semi-major axis [m], WGS84; used only with Surface = "ellipsoid"
Flattening1 x 1double1/298.257223563ellipsoid flattening, WGS84; used only with Surface = "ellipsoid"
rho_ave1 x 1double5517mean Earth density [kg/m^3] (mass kernels)
rho_water1 x 1double1000water density [kg/m^3] (ewh kernel)
Mode1 x 1string"grid""grid" evaluates the nlat x nlon outer product; "points" takes equal-length LAT/LON and evaluates pairwise - the mode a particle advection needs when it steps tracers at their own positions. NOTE the cost: "points" pays a Legendre recursion per point, so a per-frame call for 10^4 tracers is far slower than one grid call plus interpolation. Grid-and- interpolate is the right pattern for animation; "points" is for when the exact value at a station matters
Units1 x 1string"perMeter""perMeter" is the true gradient [Q]/m. "perRadian" multiplies every component by r, giving dQ/dphi, (1/cos phi) dQ/dlambda and dQ/d(ln r) - the form a lat/lon advection step wants, since dphi/dt is then G.north/r directly
MaxMemGB1 x 1double4memory budget [GB] for the Legendre stack; latitudes are processed in bands so nmax is not limited by it

Output Arguments

NameDescription
dq(1,1) struct each field is (nlat x nlon) double for Mode="grid" or (npts x 1) double for "points". Fields north the north component of the gradient east the east component. info(1,1) struct fields quantity (1,1) string what was differentiated units (1,1) string the units of dq r (1,nr) double evaluation radius [m]: nr = 1 on the sphere; on the ellipsoid one radius per latitude (Mode="grid") or per point (Mode="points") surface (1,1) string "sphere" | "ellipsoid", as used nmin, nmax (1,1) double the degree range used hasUp (1,1) logical whether dq.up is filled lat (1 x nlat) double latitudes actually used lon (1 x nlon) double longitudes actually used latType (1,1) string always "geocentric" here: the latitudes this function takes are geocentric, and Surface moves the radius, not the latitude. shCoefficients.gradient overwrites lat and latType when it was handed geodetic input, so the convention travels with the numbers instead of being remembered by the caller
