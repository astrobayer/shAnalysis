shLowLevel.fetchITSGBackground

Download ITSG monthly-mean background models.

Syntax

[files, info] = shLowLevel.fetchITSGBackground(months)[files, info] = shLowLevel.fetchITSGBackground(months, Products="dealiasing", Dest="", Release="", ...)

Description

FILES = shLowLevel.fetchITSGBackground("2018-06") downloads the monthly means of the background models the ITSG processing reduced from the observations, as .gfc (about 1 MB each): "dealiasing" (atmosphere + ocean - the ITSG counterpart of restoring AOD), "oceanTide", "earthTide", "poleTide" and "oceanPoleTide". Release routing follows fetchITSG: months before 2017-07 from ITSG-Grace2018, from 2018-06 on from ITSG-Grace_operational.

Examples

From the help block
    f = shLowLevel.fetchITSGBackground(["2018-06", "2018-07"]);
    g = shCoefficients.read(f(1));   % plain gfc, C(n+1, m+1)

Name-Value Arguments
