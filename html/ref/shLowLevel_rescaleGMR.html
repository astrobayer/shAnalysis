shLowLevel.rescaleGMR

Convert Stokes coefficients between (GM, R) reference values.

Syntax

[C2, S2, sig] = shLowLevel.rescaleGMR(C, S, GM1, R1, GM2, R2, sigmaC, sigmaS)

Description

[C2, S2] = shLowLevel.rescaleGMR(C, S, GM1, R1, GM2, R2) re-expresses coefficients given w.r.t. (GM1, R1) in the reference (GM2, R2):

Examples

Runnable (docs/apiExamples.json)
[C2, S2] = shLowLevel.rescaleGMR(g.C, g.S, g.GM, g.R, GMref, Rref);

Input Arguments

NameSizeTypeDefaultDescription
Cn x mdoublerequiredcosine Stokes coefficients, C(n+1, m+1) indexing
Sn x mdoublerequiredsine Stokes coefficients, S(n+1, m+1) indexing
GM11 x 1doublerequiredGM the coefficients are currently scaled to [m^3/s^2]
R11 x 1doublerequiredR the coefficients are currently scaled to [m]
GM21 x 1doublerequiredtarget GM [m^3/s^2]
R21 x 1doublerequiredtarget R [m]
sigmaCn x mdouble[]1-sigma uncertainties of C, same indexing
sigmaSn x mdouble[]1-sigma uncertainties of S, same indexing

Name-Value Arguments

None.

Output Arguments

NameDescription
C2, S2(n1,n1) double coefficients w.r.t. (GM2, R2)
sig(1,1) struct fields C (n1,n1) double or [] rescaled cosine sigmas, empty when sigmaC was not supplied S (n1,n1) double or [] rescaled sine sigmas, empty when sigmaS was not supplied
