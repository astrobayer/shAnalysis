shLowLevel.applyDDK

Apply an order-block-diagonal (DDK-style) filter to coefficients.

Syntax

[Cf, Sf] = shLowLevel.applyDDK(C, S, W)

Description

[CF, SF] = shLowLevel.applyDDK(C, S, W) applies the filter container from shLowLevel.readDDK: within each (order m, cs) block, the degree vector c(n1..n2) is replaced by W.blocks(k).M * c. Degrees present in C but not covered by any block pass through UNCHANGED (typically n < 2). User-facing wrappers: g.applyDDK(W), ts.applyDDK(W).

Examples

Runnable (docs/apiExamples.json)
W = shLowLevel.readDDK("DDK3", Nmax = 60);
[Cf, Sf] = shLowLevel.applyDDK(g.C, g.S, W);
