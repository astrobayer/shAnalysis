shLowLevel.vceRescale

Per-month variance factors for the noise covariance shape.

Syntax

s = shLowLevel.vceRescale(N, Xres, idx)s = shLowLevel.vceRescale(N, Xres, idx, Nmin=round(2/3 * idx.Lmax), Rows=true(0, 1))

Description

s = shLowLevel.vceRescale(N, Xres, idx) estimates one variance factor per month such that N_t = s(t) * N. The factor is the robust (median-based, chi-square(1) corrected) ratio between the observed squared residuals and the formal variances, evaluated over noise-dominated coefficients (n >= Nmin, default round(2/3 * idx.Lmax)). This is the single-component Helmert VCE specialization; it absorbs the month-to-month noise level changes (orbit geometry, beta-prime angle, instrument state) that a stationary filter ignores.

Examples

Runnable (docs/apiExamples.json)
s = shLowLevel.vceRescale(N, Xres, idx);          % monthly noise factors
