shCoefficients.errorMap

Formal-error map of a synthesized quantity.

Syntax

[sig, latDeg, lonDeg] = shCoefficients.errorMap(obj, latDeg, lonDeg)[sig, latDeg, lonDeg] = shCoefficients.errorMap(obj, latDeg, lonDeg, Covariance=[], Index=[], Quantity=..., ...)

Description

SIG = g.errorMap(LAT, LON) is the pointwise 1-sigma of what g.synthesis returns on the grid LAT x LON, propagated from G's own formal sigmas (sigmaC, sigmaS) taken as a DIAGONAL covariance. SIG = g.errorMap(LAT, LON, Covariance = M, Index = IDX) propagates a full P x P covariance in IDX ordering instead, e.g. from shLowLevel.readSINEX(..., Output = "covariance"). Either way it is shLowLevel.errorMap with G's GM and R filled in. Quantity, kn, hn and Height go to shLowLevel.errorMap only when given, so their defaults live there and nowhere else: "(lane default)" below means that function's.

Examples

From the help block
    sig = g.errorMap(-89:2:89, 0:2:358, Quantity = "ewh", kn = kn);
