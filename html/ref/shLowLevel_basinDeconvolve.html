shLowLevel.basinDeconvolve

Unbiased basin averages by exact operator deconvolution.

Syntax

[avgHat, out] = shLowLevel.basinDeconvolve(B, op)[avgHat, out] = shLowLevel.basinDeconvolve(B, op, Ridge=0)

Description

[avgHat, out] = shLowLevel.basinDeconvolve(B, op) removes filter attenuation and inter-basin leakage from basin averages, exploiting that W_t is a KNOWN linear operator (no hydrology-model scale factors).

Examples

Runnable (docs/apiExamples.json)
[avg, out] = shLowLevel.basinDeconvolve(B, op);   % op from ts.filter("tvANS")
errorbar(op.tYears, avg(1,:), out.sigma(1,:))

Input Arguments

NameSizeTypeDefaultDescription
Bn x mdoublerequiredbasin-kernel coefficient vector from basinKernel
op1 x 1structrequiredlinear operator/kernel the map is derived from

Name-Value Arguments

NameSizeTypeDefaultDescription
Ridge1 x 1double0Tikhonov parameter for ill-conditioned basin sets, RELATIVE to the spectral norm of A (v2.1): c = (A'A + lam^2 I) \ (A' v) with lam = Ridge*||A||_2. An absolute ridge is silently absorbed by floating-point addition whenever ||A'A|| >> ridge^2, leaving the system exactly singular; the relative form is scale-invariant. 0 disables. The posterior covariance uses the same regularized inverse.

Output Arguments

NameDescription
avgHat(K x T) double deconvolved basin averages, ((B'B)*c + B'model) ./ diag(B'B)
out(1,1) struct fields c (K x T) double span coefficients sigma (K x T) double 1-sigma of avgHat, deterministic term included (v2.5) avgNaive (K x T) double naive averages of the filtered field (attenuated and leaky) for comparison attn (K x T) double diag(A_t) ./ diag(B'B) attenuation factors condA (T x 1) double cond(A_t) per month

Error Identifiers

IdentifierRaised when
shLowLevel:basinDeconvolve:nonFiniteAB'W_t B is non-finite at one month - the damping s(t) or the gain g went non-finite
shLowLevel:basinDeconvolve:nonFiniteOperatora field of the filter operator holds non-finite entries; the operator is corrupt and would poison every epoch
shLowLevel:basinDeconvolve:zeroAB'W_t B vanished at one month: the filter removed the whole basin signal, so there is nothing left to deconvolve
