shSeries.signalVarianceKaula

The VDK signal model of this series.

Syntax

[ab, info] = shSeries.signalVarianceKaula(obj)[ab, info] = shSeries.signalVarianceKaula(obj, LRange=...)

Description

[AB, INFO] = ts.signalVarianceKaula() is shLowLevel.signalVarianceKaula(ts.Cs, ts.Ss, ts.epochs): the Kaula-type signal sigma a * l^b per calendar month, the input g.vdkApply takes as SIGM. Feed a pre-filtered series; that function documents why, and the bias correction.

Examples

From the help block
    ab = ts.applyDDK(W4).signalVarianceKaula();
    gf = ts.at(k).vdkApply(N, ab(mo, :), Index = idx);
