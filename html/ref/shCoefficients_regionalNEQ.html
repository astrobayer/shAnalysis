shCoefficients.regionalNEQ

This field as an observation in a regional basis.

Syntax

[rec, info] = shCoefficients.regionalNEQ(obj, B)[rec, info] = shCoefficients.regionalNEQ(obj, B, Cov=[], Name=...)

Description

[REC, INFO] = g.regionalNEQ(B) is shLowLevel.regionalNEQ(B, "solution", ...) with this field's coefficients in B.idx order as the data and their formal sigmas, squared, as the diagonal covariance: one GRACE solution as a normal equation in the basis B of g.regionalBasis, ready for shLowLevel.neqCombine and the regional Kalman filter. Cov replaces the formal sigmas, e.g. with the full covariance of a SINEX file.

Examples

From the help block
    B = g.regionalBasis("Elbe");
    rec = g.regionalNEQ(B);
