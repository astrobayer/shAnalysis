shLowLevel.normalFieldCS

Even zonal harmonics of an ellipsoidal normal field.

Syntax

[Cn, info] = shLowLevel.normalFieldCS(nmax)[Cn, info] = shLowLevel.normalFieldCS(nmax, System="WGS84", GM=NaN, a=NaN, ...)

Description

[CN, INFO] = shLowLevel.normalFieldCS(NMAX, System="WGS84") returns the fully normalized even zonal coefficients Cbar_{2n,0} of the normal gravity field, COMPUTED from the defining constants (GM (NaN), a (NaN), f (NaN), omega (NaN)) via the closed-form theory (Heiskanen & Moritz 1967, sect. 2-9) - no coefficient tables anywhere:

Examples

Runnable (docs/apiExamples.json)
[Cn, info] = shLowLevel.normalFieldCS(96, System = "WGS84");

Output Arguments

NameDescription
Cn(nmax+1,1) double Cbar_{n,0} (zero at odd/omitted degrees; Cn(1) = 1 represents the central GM/r term - subtract it ONLY together with a matching degree-0 of the model, see subtractNormalField)
info(1,1) struct the defining constants actually used, fields GM (1,1) double geocentric gravitational constant a (1,1) double semi-major axis [m] f (1,1) double flattening omega (1,1) double angular velocity [rad/s] J2 (1,1) double dynamic form factor, COMPUTED from the four above, not tabulated e2 (1,1) double first eccentricity squared m (1,1) double omega^2 a^2 b / GM q0 (1,1) double the auxiliary Somigliana quantity system (1,1) string "WGS84" | "GRS80"
