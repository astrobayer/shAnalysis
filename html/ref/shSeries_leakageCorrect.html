shSeries.leakageCorrect

Forward-model leakage correction of every epoch.

Syntax

[mCorr, info] = shSeries.leakageCorrect(obj, latDeg, lonDeg)[mCorr, info] = shSeries.leakageCorrect(obj, latDeg, lonDeg, Filter=..., Quantity="ewh", kn=[], ...)

Description

[M, INFO] = ts.leakageCorrect(LAT, LON, Filter = F, kn = KN) synthesizes each epoch on the grid (g.synthesis, geocentric, Quantity "ewh" unless told otherwise) and runs shLowLevel.leakageCorrect on it with the series' GM and R: the iterative forward model that finds the field which, pushed through the chain the data saw, reproduces the filtered field. M is the corrected stack, page k for epoch k. shLowLevel.leakageCorrect documents the method, its stopping rule, and why the MASK MUST COVER EVERY REGION THAT CAN HOLD MASS, not only the one you measure.

Examples

From the help block
    [m, info] = ts.leakageCorrect(-89:89, 0:359, Filter = "gauss300", ...
        kn = kn, Mask = unionMask, Quiet = true);
