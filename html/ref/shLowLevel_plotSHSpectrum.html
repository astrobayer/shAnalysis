shLowLevel.plotSHSpectrum

Degree-amplitude spectrum plot (linear x, log y).

Syntax

h = shLowLevel.plotSHSpectrum(specs)h = shLowLevel.plotSHSpectrum(specs, Names={}, Units='mm', Field='', ...)

Description

PLOTSHSPECTRUM(SPEC) plots SPEC.degree vs SPEC.degAmplitude (from SHDEGREERMS) on a log y-axis over a linear degree axis, in mm geoid-height-equivalent.

Examples

Runnable (docs/apiExamples.json)
spec = shLowLevel.shDegreeRMS(g.C, g.S);
shLowLevel.plotSHSpectrum(spec, Kaula = true, MarkCrossover = true);

Input Arguments

NameSizeTypeDefaultDescription
specsn x m-requiredstruct, struct array or cell array of structs spectrum struct(s) from shLowLevel.shDegreeRMS; several are overlaid

Name-Value Arguments

NameSizeTypeDefaultDescription
Namesn x m-{}cell array of legend labels
Unitsn x m-'mm''mm' or 'm' for the y-axis
Fieldn x m-''LEGACY override: plot this spec field directly and ignore Quantity. Empty means "not supplied" - the sentinel that replaces inputParser's UsingDefaults. (also accepts 'errAmplitude' to overlay error spectra)
Axn x m-[]axes handle to plot into; empty uses the current axes
Kaulan x m-[]scalar K: overlay the Kaula-rule reference degree amplitude R*sqrt(2n+1)*K/n^2 (typical K ~ 1e-5) as a dotted grey line - the sanity yardstick for signal decay
MarkCrossoverfalse-falsewith exactly TWO spectra, mark the signal/error crossover degree found by shLowLevel.shSpectralCrossover with a vertical line
Quantityn x m-'amplitude'"amplitude" ([m]) | "rms" | "variance" | "cumamplitude" | "cumrms" | "cumvariance" - which spectral quantity to draw; error overlays ride along when the spec carries the matching err* field

Output Arguments

NameDescription
h(1 x 1) graphics handle spectrum axes (log y)

Error Identifiers

IdentifierRaised when
shLowLevel:plotSHSpectrum:badQuantityQuantity is not one of the supported spectrum quantities

shLowLevel:plotSHSpectrum:missingFielda spectrum has no field for the chosen Quantity - it probably came from the other domain
shLowLevel:plotSHSpectrum:mixedDomainsthe spectra do not all share one domain (degree or order)
