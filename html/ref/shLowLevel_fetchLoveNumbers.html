shLowLevel.fetchLoveNumbers

Download load/deformation Love number files (GROOPS set).

Syntax

[files, info] = shLowLevel.fetchLoveNumbers(names)[files, info] = shLowLevel.fetchLoveNumbers(names, Dest="", BaseURL="https://ftp.tugraz.at/pub/ITSG/groops/data/loading", Timeout=30, ...)

Description

FILES = shLowLevel.fetchLoveNumbers() downloads the standard load Love number file (Gegout97, kn for degrees 0..1024) from the GROOPS data collection hosted by TU Graz into <dataFolder>/loveNumbers, with the usual safe-swap semantics. The toolbox deliberately never hardcodes Love numbers - this fetcher automates obtaining a PUBLISHED set, which you then pass explicitly (kn = ...) where required.

Examples

From the help block
    [f, inf] = shLowLevel.fetchLoveNumbers();
    kn = inf.parsed(1).kn(1:61);        % degrees 0..60 for an n60 field
