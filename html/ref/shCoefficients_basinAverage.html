shCoefficients.basinAverage

Basin averages of one field from basin kernels.

Syntax

avg = shCoefficients.basinAverage(obj, B)

Description

AVG = g.basinAverage(B) is the naive basin average B'*x ./ diag(B'*B), one value per basin, with x the coefficient vector of G. It is the one-epoch case of shSeries.basinAverage and delegates to it, so the two cannot disagree. The exact deconvolution (Deconvolve = true) needs the stored operator of a filtered SERIES, so it stays on shSeries.

Examples

From the help block
    avg = g.basinAverage(B);   % B: P x K, as for ts.basinAverage
