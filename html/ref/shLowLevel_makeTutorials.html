shLowLevel.makeTutorials

Generate Live Script tutorials from the demo registry.

Syntax

out = shLowLevel.makeTutorials()out = shLowLevel.makeTutorials(Dest="", Cases="all", Convert=true, ...)

Description

OUT = shLowLevel.makeTutorials() writes one tutorial per demo case into tutorials/ as a plain .m script with Live Editor section markers, and converts each to .mlx when the converter is available. OUT.files lists the .m files written.

Examples

From the help block
    shLowLevel.makeTutorials(Cases = ["D01" "D05"]);
    edit(fullfile("tutorials", "T_D01_read_and_spectra.m"))

  See also demo_shAnalysis, shLowLevel.version.
Runnable (docs/apiExamples.json)
shLowLevel.makeTutorials(Cases = ["D01" "D05"]);
edit(fullfile("tutorials", "T_D01_read_spectral_diagnostics.m"))

Input Arguments

None.

Name-Value Arguments

NameSizeTypeDefaultDescription
Dest1 x 1string""(fullfile(shLowLevel.version().Root, "tutorials")) output folder; created if absent
Cases1 x :string"all"which demo cases to write ("all", "core", or an array of ids such as ["D01" "D05"])
Convert1 x 1logicaltruealso write .mlx. The converter is an internal MATLAB API and is not present in every release, so a failure is reported and the .m files are kept: those are the useful artefact either way, and they are the ones worth putting under version control
Quiet1 x 1logicalfalsesuppress progress output

Output Arguments

NameDescription
out(1,1) struct fields files (1,N) string the .m files written mlx (1,M) string the .mlx files written; empty when Convert is false or the conversion is unavailable dest (1,1) string the folder written to converted (1,1) logical whether the .mlx conversion ran
