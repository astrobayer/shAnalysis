shLowLevel.shDestripe

Remove correlated (north-south striping) noise from Stokes

Syntax

[Cf, Sf] = shLowLevel.shDestripe(C, S)[Cf, Sf] = shLowLevel.shDestripe(C, S, MinOrder=6, PolyOrder=3, WindowLength=[])

Description

coefficients, following Swenson & Wahr (2006).

Examples

Runnable (docs/apiExamples.json)
[Cf, Sf] = shLowLevel.shDestripe(g.C, g.S, MinOrder = 6);

Input Arguments

NameSizeTypeDefaultDescription
Cn x mdoublerequiredcosine Stokes coefficients, C(n+1, m+1) indexing
Sn x mdoublerequiredsine Stokes coefficients, S(n+1, m+1) indexing

Name-Value Arguments

NameSizeTypeDefaultDescription
MinOrder1 x 1double6lowest order to filter (below this, real signal dominates and destriping mostly removes signal; the value is model/application dependent -- verify against your own signal-to-noise spectrum, cf. plotSHSpectrum's degree-amplitude vs. error-amplitude)
PolyOrder1 x 1double3polynomial order fit and removed per order/parity (the classic Swenson & Wahr cubic fit)
WindowLengthn x mdouble[]if empty, fit a single polynomial over the full available degree range per order/parity (the original Swenson & Wahr formulation). If set to an odd integer >= PolyOrder+2, use a centered moving window instead (Duan et al. 2009 / "P3M6"-style windowed variant, e.g. WindowLength=6 with PolyOrder=3 is the commonly used "P3M6" filter).

Output Arguments

NameDescription
Cf(nmax+1 x nmax+1) double destriped cosine coefficients
Sf(nmax+1 x nmax+1) double destriped sine coefficients
