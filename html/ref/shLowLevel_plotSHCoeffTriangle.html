shLowLevel.plotSHCoeffTriangle

Coefficient-triangle diagnostic plot.

Syntax

h = shLowLevel.plotSHCoeffTriangle(C, S)h = shLowLevel.plotSHCoeffTriangle(C, S, Nmax=size(C,1)-1, CLim=[], Ax=[], ...)

Description

PLOTSHCOEFFTRIANGLE(C, S) shows |Snm| (left half) and |Cnm| (right half) as a single degree/order "butterfly" triangle image on a log color scale -- the standard first diagnostic for spotting striping, leakage, or bad coefficients before spectral/spatial analysis. x-axis: order m (mirrored: Snm on the LEFT, Cnm on the RIGHT), y-axis: degree n with the apex (n=0) at the TOP - the triangle's peak points upwards. The data aspect ratio is fixed to 1:1, so the axes box is 2:1 (x spans 2*nmax+1 units, y spans nmax+1) and every imagesc cell renders square (v2.3.1).

Examples

Runnable (docs/apiExamples.json)
shLowLevel.plotSHCoeffTriangle(g.C, g.S);
shLowLevel.plotSHCoeffTriangle(gF.C, gF.S, RefC = g.C, RefS = g.S);   % signed diff
