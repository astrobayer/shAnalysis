shClimatology.disp

Compact display: fitted components, reference epoch, note.

Syntax

shClimatology.disp(obj)

Description

disp(CLIM) prints the maximum degree and the reference epoch t0, the list of fitted components (bias, trend, annual and semi-annual cosine/sine, plus any extra Periods) and the processing history including the GIA note. Called automatically when an shClimatology object is shown without a semicolon.

Examples

From the help block
    clim = ts.climatology();
    disp(clim)
Runnable (docs/apiExamples.json)
