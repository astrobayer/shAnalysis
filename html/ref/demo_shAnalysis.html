demo_shAnalysis

Selectable demonstrations of every toolbox capability.

Syntax

reg = demo_shAnalysis(cases)reg = demo_shAnalysis(cases, Visible=true, OutDir=string(tempdir), StopOnError=false)

Description

demo_shAnalysis runs the "core" set (D01 D02 D04 D05 D15) demo_shAnalysis("all") runs every case demo_shAnalysis("list") prints the case table, returns registry demo_shAnalysis(["D04","D15"]) runs selected cases demo_shAnalysis(..., Visible (true)=false) hidden figures (CI/smoke tests) demo_shAnalysis(..., OutDir (string(tempdir))=tempdir) target for D16 file exports demo_shAnalysis(..., StopOnError (false)=true) rethrow instead of the default fail-and-continue (each case runs in try/catch; a summary lists ok/failed cases at the end)

Examples

Runnable (docs/apiExamples.json)
demo_shAnalysis(["D01", "D06"])   % run selected demos, fail-and-continue

Input Arguments

NameSizeTypeDefaultDescription
cases1 x :string"core"string demo IDs to run, e.g. "D01" or ["D01" "D13"]; "core" expands to the curated smoke set, "all" runs the full registry in order

Name-Value Arguments

NameSizeTypeDefaultDescription
Visible1 x 1logicaltruelogical show figures (false keeps them off-screen for batch/CI runs)
OutDir1 x 1stringstring(tempdir)string output folder for exported files; "" = a fresh folder under tempdir
StopOnError1 x 1logicalfalselogical true stops at the first failing case; false (default) prints FAILED and continues - the fail-and-continue contract the suite exercises

Output Arguments

NameDescription
reg(D x 3) table demo registry: id, title, exercised API

Error Identifiers

IdentifierRaised when
shAnalysis:demo:casesFailedwarning - one or more cases failed and the run continued. Raised only when nargout == 0; ask for the report struct, or set StopOnError=true, to handle failures yourself
shAnalysis:demo:unknownCasethe requested case id is not in the registry; demo_shAnalysis("list") names them
