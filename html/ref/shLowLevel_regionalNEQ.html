shLowLevel.regionalNEQ

Gravity information of any level as a normal equation in a basis.

Syntax

[rec, info] = shLowLevel.regionalNEQ(B, kind)[rec, info] = shLowLevel.regionalNEQ(B, kind, Solution=[], Cov=[], NEQ=struct([]), ...)

Description

[REC, INFO] = shLowLevel.regionalNEQ(B, KIND, ...) turns one epoch of gravity information into a normal equation in the coefficients a of the regional basis B of shLowLevel.regionalBasis - the observation adapter of the regional Kalman filter (Kurtenbach 2012, C-683, Sec. 3.3; NEQ-form update P+ = (P-^-1 + N)^-1). Every kind reduces to one design A in the basis and one covariance C of the data y: N = A' C^-1 A, b = A' C^-1 y, ltpl = y' C^-1 y, formed through C's Cholesky factor (or 1/sqrt of a diagonal), never through an inverse. REC is a contribution in the format of shLowLevel.neqCombine (N, b, ltpl, nobs, name), so several kinds of one epoch combine there - with variance components - and the result updates shLowLevel.kalmanFilter in its normal-equation mode.

Examples

From the help block
    B = shLowLevel.regionalBasis(shLowLevel.shIndex(60), "Elbe");
    r1 = shLowLevel.regionalNEQ(B, "solution", Solution = l, Cov = sig.^2);
    r2 = shLowLevel.regionalNEQ(B, "points", Values = ewh, ...
        LatDeg = lat, LonDeg = lon, Cov = 0.02^2, kn = kn);
    [a, out] = shLowLevel.neqCombine([r1, r2]);     % VCE of the two
