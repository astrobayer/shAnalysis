shSeries.basinKernel

A basin kernel in the index basinAverage reads.

Syntax

[b, info] = shSeries.basinKernel(obj, region)[b, info] = shSeries.basinKernel(obj, region, BufferKm=..., TaperKm=..., R=..., ...)

Description

[B, INFO] = ts.basinKernel(REGION) is shLowLevel.basinKernel(shLowLevel.shIndex(ts.nmax), REGION): the band-limited indicator of REGION in the ordering ts.basinAverage and g.basinAverage require, so a kernel built here cannot meet them in another. That function documents the quadrature, the buffer and the taper.

Examples

From the help block
    b = ts.basinKernel([-10 100; -10 140; 25 140; 25 100]);
    avg = ts.basinAverage(b);
