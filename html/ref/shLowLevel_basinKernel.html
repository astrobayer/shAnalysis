shLowLevel.basinKernel

Band-limited basin kernel(s) from a region definition.

Syntax

[b, info] = shLowLevel.basinKernel(idx, region)[b, info] = shLowLevel.basinKernel(idx, region, BufferKm=0, TaperKm=0, R=6378136.3, ...)

Description

[B, INFO] = shLowLevel.basinKernel(IDX, REGION) builds the SH coefficient vector of the band-limited indicator function of REGION by exact Gauss-Legendre quadrature, b = Y' * (w .* mask), ready for shSeries.basinAverage / shLowLevel.basinDeconvolve (P x 1, IDX ordering). Replaces the error-prone manual Y'*(w.*mask) construction.

Examples

Runnable (docs/apiExamples.json)
b = shLowLevel.basinKernel(idx, maskAmazon, TaperKm = 200);

Input Arguments

NameSizeTypeDefaultDescription
idx1 x 1structrequiredindex struct from shLowLevel.shIndex (fields n, m, cs, P, Lmax, minDegree, pos)
regionn x m-requiredregion as polygon [lat lon] deg, mask, or @(lat, lon) handle (see evalMask)

Name-Value Arguments

NameSizeTypeDefaultDescription
BufferKm1 x 1double0grow (>0) / shrink (<0) the region by great-circle distance before quadrature - counters leakage by matching the kernel to the filter's resolution
TaperKm1 x 1double0>0: multiply the kernel spectrally by Jekeli Gaussian weights of this radius (shLowLevel.shGaussianWeights) - soft edges reduce ringing/leakage of the truncated indicator (best practice: Taper ~ filter half-width)
R1 x 1double6378136.3sphere radius [m] for the km conversions
OverSample1 x 1double2quadrature refinement factor: indicator masks are not band-limited; the default doubles the ring/ meridian count to tame edge quantization (~18% cap- area error at factor 1 and Lmax 20, ~5% at factor 2)

Output Arguments

NameDescription
b(P,1) double kernel in IDX ordering
info(1,1) struct fields areaFraction (1,1) double quadrature area of the mask / 4pi nGridPoints (1,1) double grid points the mask was evaluated on buffered (1,1) logical BufferKm was non-zero tapered (1,1) logical TaperKm was positive

Error Identifiers

IdentifierRaised when
shLowLevel:basinKernel:zeroAreawarning - the region has zero area on the sphere, so the kernel is 0 and a basin average built from it divides by nothing
