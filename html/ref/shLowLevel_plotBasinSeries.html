shLowLevel.plotBasinSeries

Basin time series with 1-sigma band, gaps, trend.

Syntax

h = shLowLevel.plotBasinSeries(tYears, c, sigma)h = shLowLevel.plotBasinSeries(tYears, c, sigma, Label="basin average", Units="", GapThreshold=0.3, ...)

Description

H = shLowLevel.plotBasinSeries(TYEARS, C, SIGMA) draws the standard basin- average figure: shaded 1-sigma band (fill), data line, the GRACE <-> GRACE-FO gap (or any gap > GapThreshold years) shaded light grey, and an annotated trend fitted with the toolbox climatology design (bias/ trend/annual/semi-annual, AR(1)-corrected sigma).

Examples

Runnable (docs/apiExamples.json)
shLowLevel.plotBasinSeries(op.tYears, avg(1,:).', out.sigma(1,:).', Units = "m EWH");
