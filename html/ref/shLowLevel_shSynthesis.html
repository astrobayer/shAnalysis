shLowLevel.shSynthesis

Spherical harmonic synthesis of a global/regional grid.

Syntax

[grid, lat, lon, P] = shLowLevel.shSynthesis(C, S, GM, R, latVec, lonVec, varargin)

Description

[GRID, LAT, LON] = SHSYNTHESIS(C, S, GM, R, LATVEC, LONVEC) synthesizes the disturbing-potential-derived quantity (default: geoid height) on the grid LATVEC x LONVEC (degrees) from fully normalized (ICGEM) Stokes coefficients C, S at the reference sphere r = R.

Examples

Runnable (docs/apiExamples.json)
grid = shLowLevel.shSynthesis(g.C, g.S, g.GM, g.R, -89:89, 0:359);

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
grid(nlat x nlon) double synthesized field in the units of the requested quantity
lat(1 x nlat) double geocentric latitude grid used [deg]
lon(1 x nlon) double longitude grid used [deg]
P(nmax+1 x nmax+1 x nlat) double Legendre array as returned by LEGENDREALF; pass it back via 'P' to skip the recursion. EMPTY in latitude-banded mode (MaxMemGB exceeded): the blocks are streamed and discarded, so request the 4th output only with a memory budget that fits the full array.
