shLowLevel.resolutionMap

Filter-kernel half-widths: per-point, per-azimuth resolution.

Syntax

res = shLowLevel.resolutionMap(op, t, latDeg, lonDeg)res = shLowLevel.resolutionMap(op, t, latDeg, lonDeg, NAz=8, PsiMax=20, NPsi=120, ...)

Description

RES = shLowLevel.resolutionMap(OP, T, LATDEG, LONDEG) evaluates, for each query point, the effective smoothing kernel of month T: xf(P) = y_P' * W_t * x => kernel coefficients k = W_t' * y_P and finds the great-circle distance psi_1/2 at which the kernel drops to half its peak, along NAz (8) azimuths. Replaces the single "equivalent Gaussian radius" with a spatially and azimuthally resolved resolution product (N-S vs E-W half-width ratio = striping fingerprint). All transect evaluations per query point run through ONE vectorized shLowLevel.ylm call.

Examples

Runnable (docs/apiExamples.json)
res = shLowLevel.resolutionMap(op, 1, -60:30:60, 0:60:300);   % epoch 1

Name-Value Arguments

NameSizeTypeDefaultDescription
NAz1 x 1double8azimuth count, default 8
PsiMax1 x 1double20radial search range [deg], default 20
NPsi1 x 1double120radial samples, default 120
RadiusKm1 x 1double6371(1,1) sphere radius used to turn the half-width from degrees into kilometres [km]. The default is the MEAN Earth radius, which is the right choice for a great-circle distance and is deliberately NOT the reference radius R of the coefficients (6378.1363 km); pass that instead if you want the half-widths on the reference sphere. Overridable so the constant is a choice, not a hidden assumption.
