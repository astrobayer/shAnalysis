shLowLevel.obpChain

Ocean-bottom-pressure fields (GravIS Level-3 OBP recipe).

Syntax

[out, rep] = shLowLevel.obpChain(folder)[out, rep] = shLowLevel.obpChain(folder, kn=[], OceanMask=[], GADFolder="", ...)

Description

[OUT, REP] = shLowLevel.obpChain(FOLDER, kn = KN, OceanMask = OC, GADFolder = GAD) produces gridded ocean-bottom-pressure anomalies in EWH following the GravIS/GFZ Level-3 OBP definition: gravisL2B corrections (C20/C30/C21/S21, degree 1, minus NFIL mean, GIA) -> GAD added back on the coefficient level -> filter (AFTER the GAD addition - the GravIS order) -> EWH synthesis -> anomalies against the mean over RefPeriod, land set to NaN.

Examples

From the help block
    kn = readmatrix("loadLoveNumbers_Gegout97.txt", FileType = "text", ...
        NumHeaderLines = 2);
    [out, rep] = shLowLevel.obpChain(serFolder, kn = kn, ...
        OceanMask = oc, GADFolder = "E:/DATAPOOL/GravityField/GAX/GAD");
    imagesc(out.lon, out.lat, out.grid(:, :, end)); axis xy
