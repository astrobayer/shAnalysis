shLowLevel.neqClimatology

Climatology estimated from every month's normal equation.

Syntax

[clim, info] = shLowLevel.neqClimatology(neqs)[clim, info] = shLowLevel.neqClimatology(neqs, Nmax=[], DeviationCov=[], T0=NaN, ...)

Description

CLIM = shLowLevel.neqClimatology(NEQS) estimates the six climatology terms of shClimatology - bias, trend, annual and semi-annual cos/sin - for every coefficient from the monthly normal equations themselves, instead of fitting them to filtered solutions. Month t's normal equation N_t x = b_t observes x_t = (d_t' kron I) theta + delta_t, delta_t ~ N(0, Sigma_d), with d_t the six time functions at t (around T0) and delta_t the month's deviation from the climatology. Reducing delta_t leaves the month's contribution W_t = (I + N_t Sigma_d)^-1 N_t, r_t = (I + N_t Sigma_d)^-1 b_t, which never inverts N_t, so a rank-deficient month enters as it is, and which is (N_t^-1 + Sigma_d)^-1 where N_t is regular. Then N_theta = sum_t (d_t d_t') kron W_t, b_theta = sum_t d_t kron r_t, theta = N_theta^-1 b_theta, Cov(theta) = N_theta^-1. With DeviationCov = [] (Sigma_d = 0) this is the generalized least- squares fit of the solutions x_t = N_t^-1 b_t with their full covariances; with Sigma_d it is the Schur reduction of the joint normal equation in theta and every delta_t (tools/dev/validate_neq_climatology.py CLAIMs 1-3, 1.0e-15 to 1.8e-14 relative).

Examples

From the help block
    [clim, info] = shLowLevel.neqClimatology(itsgFolder, Nmax = 40, ...
        DeviationCov = sigd .^ 2);
    tr = clim.trend;                  % per year, with tr.sigmaC

Input Arguments

NameSizeTypeDefaultDescription
neqs1 x n-requiredstring | (1,T) struct a SINEX folder, or several, or a list of SINEX files, each read with shLowLevel.readSINEX and required to carry a normal-equation block (kind 'NEQ', b = M x); or records with fields N (P x P), b (P x 1) and epoch (1,1) [decimal years] in shLowLevel.shIndex(Nmax) order

Name-Value Arguments

NameSizeTypeDefaultDescription
Nmaxn x mdouble[](1,1) double the degree the coefficients are truncated to; [] takes it from the first file, and is required for records
DeviationCovn x mdouble[](P x 1) | (P x P) double Sigma_d, the covariance of a month's deviation from the climatology, in shIndex(Nmax) order; [] is Sigma_d = 0 (the months are taken to lie on the climatology, and the sigmas are then too small). The signal covariance of a model series' residuals (shLowLevel.buildSignalCov) is one source
T01 x 1doubleNaN(1,1) double reference epoch of the terms [decimal years]; NaN takes the mean epoch
GM1 x 1double3.986004415e14(1,1) double constant of the output
R1 x 1double6378136.3(1,1) double constant of the output [m]
Pattern1 x 1string"*.snx*"(1,1) string file pattern inside a folder
MaxMemGB1 x 1double8(1,1) double refuse when the three (6P x 6P) matrices of the solve would need more [GB]

Output Arguments

NameDescription
clim(1,1) shClimatology the six terms, with their 1-sigma in coefSigma (so clim.trend.sigmaC is the trend's sigma)
info(1,1) struct fields epochs (T,1) double the months used, sorted nEpochs (1,1) double their number t0 (1,1) double the reference epoch nmax (1,1) double the degree P (1,1) double coefficients per term memGB (1,1) double memory of the three matrices of the solve [GB] singular (1,T) logical months whose normal equation is not positive definite (they still enter, as they are)
