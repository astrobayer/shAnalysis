shCoefficients.synthesisPoints

Field values at scattered 3-D points.

Syntax

val = shCoefficients.synthesisPoints(obj, latDeg, lonDeg, r)val = shCoefficients.synthesisPoints(obj, latDeg, lonDeg, r, Quantity=..., Nmin=..., Method=..., ...)

Description

VAL = g.synthesisPoints(LAT, LON, RGEO) evaluates G pointwise at equal-length vectors of geocentric latitude and longitude [deg] and geocentric radius [m] - stations, satellite positions, profiles - with the upward continuation (R/r)^n that a grid on the sphere cannot give. It is shLowLevel.synthesisPoints with G's coefficients, GM and R; that function documents the quantities, the two summations and why "auto" means "clenshaw". Its options go there only when given, so "(lane default)" below is that function's. For points on the reference ellipsoid pass RGEO = shLowLevel.ellipsoidRadius(LAT) + h.

Examples

From the help block
    r = shLowLevel.ellipsoidRadius(lat) + 450e3;
    dg = g.synthesisPoints(lat, lon, r, Quantity = "disturbance");
