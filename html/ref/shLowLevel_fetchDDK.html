shLowLevel.fetchDDK

Download DDK filter matrices (Wbd binaries) on demand.

Syntax

[files, info] = shLowLevel.fetchDDK(which)[files, info] = shLowLevel.fetchDDK(which, Dest="", Timeout=120, Proxy="", ...)

Description

FILES = shLowLevel.fetchDDK(1:8) fetches the released anisotropic DDK decorrelation filters DDK1..DDK8 (Kusche 2007; Kusche et al. 2009; ~9.8 MB each) from the MIT-licensed strawpants/GRACE-filter repository into <dataFolder>/DDK. Existing files are skipped unless Update=true, which re-downloads them with a safe swap (the fresh file is parse-verified by shLowLevel.readDDK before replacing the old one). No Wbd file is tracked in the repository: CI checks a DDK3 copy out of the fixtures tag into tests/test_data (see shLowLevel.testDataDir); without that checkout DDK3 is fetched like the others.

Examples

Runnable (docs/apiExamples.json)
shLowLevel.fetchDDK(1:8);                    % ~80 MB, skips existing
