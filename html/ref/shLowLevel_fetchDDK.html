shLowLevel.fetchDDK

Download DDK filter matrices (Wbd binaries) on demand.

Syntax

[files, info] = shLowLevel.fetchDDK(which)[files, info] = shLowLevel.fetchDDK(which, Dest="", Timeout=120, Proxy="", ...)

Description

FILES = shLowLevel.fetchDDK(1:8) fetches the released anisotropic DDK decorrelation filters DDK1..DDK8 (Kusche 2007; Kusche et al. 2009; ~9.8 MB each) from the MIT-licensed strawpants/GRACE-filter repository into <dataFolder>/DDK. Existing files are skipped unless Update (false)=true, which re-downloads them with a safe swap (the fresh file is parse-verified by shLowLevel.readDDK before replacing the old one). DDK3 additionally ships as a toolbox sample (resolved via shLowLevel.testDataDir; CI pulls it from the orphan branch testdata) and never needs fetching.

Examples

Runnable (docs/apiExamples.json)
shLowLevel.fetchDDK(1:8);                    % ~80 MB, skips existing
