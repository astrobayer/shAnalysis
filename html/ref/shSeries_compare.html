shSeries.compare

Temporal comparison against other series (v2.6.0).

Syntax

[rep, h] = shSeries.compare(obj, others, varargin)

Description

REP = ts.compare(TS2) or ts.compare({TS2, TS3, ...}) delegates to shLowLevel.compareSeries with OBJ as the reference; all options pass through (Basin=, Names=, Plot=, ...).

Examples

Runnable (docs/apiExamples.json)
rep = ts.compare({tsGFZ, tsJPL}, Names = ["ref", "GFZ", "JPL"]);

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
rep(1,1) struct as returned by shLowLevel.compareSeries, which documents every field
h(1 x 1) graphics handle figure (Plot = true)

Error Identifiers

None documented in the help block. Argument validation raises the MATLAB:* identifiers of the arguments block.
