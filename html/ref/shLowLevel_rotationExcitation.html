shLowLevel.rotationExcitation

Earth-rotation excitation of the degree-2 coefficients.

Syntax

[chi, info] = shLowLevel.rotationExcitation(C21, S21)[chi, info] = shLowLevel.rotationExcitation(C21, S21, Earth="IERS2010", kn=[], C20=[], ...)

Description

CHI = shLowLevel.rotationExcitation(C21, S21, kn = KN) is the mass-load excitation of polar motion that a series of degree-2, order-1 Stokes coefficients carries. It is Chen & Wilson (2003) eq. (1) solved for the excitation:

Examples

From the help block
    chi = shLowLevel.rotationExcitation(squeeze(ts.Cs(3, 2, :)), ...
        squeeze(ts.Ss(3, 2, :)), kn = kn, C20 = tn14C20);

Input Arguments

NameSizeTypeDefaultDescription
C21: x 1doublerequireddouble C21 at each epoch, 4-pi normalised
S21: x 1doublerequireddouble S21 at each epoch

Name-Value Arguments

NameSizeTypeDefaultDescription
Earthn x m-"IERS2010""IERS2010", or a struct with fields M [kg], R [m], and C and A [kg m^2] - the Earth's mass, radius and two principal moments of inertia
knn x mdouble[]REQUIRED: load Love numbers, kn(1) degree 0; only kn(3), the degree-2 value, is used (readLoveNumbers)
C20: x 1double[](T,1) double C20 at each epoch; gives chi3 and dLOD. Pass the SLR value (TN-14), not GRACE's own
Reference1 x 1string"mean""mean" | "none": remove each coefficient's mean over the series, or take the input as changes
PolarFactor1 x 1double1.098the factor in the first two lines of eq. (1)
AxialFactor1 x 1double0.753the factor in the third line of eq. (1)
Omega1 x 1double7.292115e-5the Earth's mean angular velocity [rad/s], as in ESMGFZ's Table 2.1; dLOD scales with 2 pi / Omega

Output Arguments

NameDescription
chi(1,1) struct the excitation, fields chi1 (T,1) double polar-motion excitation along x [mas] chi2 (T,1) double along y, towards 90 E [mas] chi3 (T,1) double axial excitation, dimensionless; empty without C20 dLOD (T,1) double change in the length of day [ms]; empty without C20
info(1,1) struct fields k2 (1,1) double the load Love number used, kn(3) polarScale (1,1) double chi1 [mas] per unit dC21 (and chi2 per unit dS21) axialScale (1,1) double chi3 per unit dC20 lodScale (1,1) double dLOD [ms] per unit chi3, 2 pi / Omega removedMean (1,3) double the means of C21, S21 and C20 that were removed: zeros with Reference = "none", NaN for C20 when it was not given earth (1,1) struct the constants used: M [kg], R [m], C and A [kg m^2]

IdentifierRaised when
