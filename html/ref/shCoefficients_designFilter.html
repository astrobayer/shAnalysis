shCoefficients.designFilter

A DDK-class filter built from this field's own errors.

Syntax

[W, info] = shCoefficients.designFilter(obj)[W, info] = shCoefficients.designFilter(obj, Alpha=..., Kaula=..., DegVar=..., ...)

Description

[W, INFO] = g.designFilter() is shLowLevel.designFilter(g.sigmaC, g.sigmaS): the Wiener-type decorrelation filter from G's formal sigmas, in the block format g.applyDDK takes. With Noise (and Idx) a full covariance is used instead and the sigmas are not read. That function documents the construction. A field without formal sigmas passes NaN, which the lane refuses unless Noise is given.

Examples

From the help block
    W = g.designFilter(Alpha = 1);
    gF = g.applyDDK(W);
