shClimatology.withNote

Append a provenance note to the history (v2.2).

Syntax

obj = shClimatology.withNote(obj, txt)

Description

OBJ = clim.withNote(TXT) - the only supported way to annotate from outside the class (history is SetAccess=private).

Examples

Runnable (docs/apiExamples.json)
clim = clim.withNote("GIA: ICE-6G_D removed");

Input Arguments

NameSizeTypeDefaultDescription
objn x m-requiredthe object the method is called on
txtn x m-requiredfree-text provenance note appended to the history

Name-Value Arguments

None.

Output Arguments
