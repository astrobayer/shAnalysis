shSeries.restore

Add a background (GAA/GAB/GAC/GAD) series, epoch-matched.

Syntax

out = shSeries.restore(obj, gax)out = shSeries.restore(obj, gax, Tolerance=0.05, AllowMissing=false)

Description

OUT = ts.restore(GAXSERIES, Tolerance=0.05, AllowMissing=false) Each epoch of OBJ is matched to the nearest GAX epoch within Tolerance [yr]. Missing matches error (or, with AllowMissing=true, leave those epochs unchanged with a note).

Examples

Runnable (docs/apiExamples.json)
ts = ts.restore(tsGAD);                % GSM + GAD, epoch-matched
