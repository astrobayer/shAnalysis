shCoefficients.mcPropagate

Monte-Carlo uncertainty of any functional of this field.

Syntax

out = shCoefficients.mcPropagate(obj, fun)out = shCoefficients.mcPropagate(obj, fun, N=..., Cov=..., Idx=..., ...)

Description

OUT = g.mcPropagate(FUN) is shLowLevel.mcPropagate(FUN, g): it draws samples of G consistent with its formal sigmas (or with Cov in Idx ordering), pushes each through FUN and returns the sample mean and sigma. That function documents the sampling models.

Examples

From the help block
    b = g.basinKernel([-10 100; -10 140; 25 140; 25 100]);
    out = g.mcPropagate(@(gs) gs.basinAverage(b), N = 500, Seed = 1);
