shLowLevel.requireGeoMap

Assert that geoMap is on the path; say where it is.

Syntax

loc = shLowLevel.requireGeoMap()

Description

LOC = shLowLevel.requireGeoMap() returns the path of geo.map, or raises shLowLevel:requireGeoMap:geoMapRequired with a message that says what to do instead of reporting an undefined function three frames deeper.

Examples

From the help block
    loc = shLowLevel.requireGeoMap();   % errors if geoMap is absent

  See also shCoefficients.map, shCoefficients.toGrid, shLowLevel.writeAnimation.
