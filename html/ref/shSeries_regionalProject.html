shSeries.regionalProject

Every epoch in a regional basis, and back.

Syntax

[a, rec] = shSeries.regionalProject(obj, B)

Description

[A, REC] = ts.regionalProject(B) is shLowLevel.regionalProject(ts.Cs, ts.Ss, B): A holds the coefficients in the basis B of ts.regionalBasis per epoch, REC the series rebuilt from them.

Examples

From the help block
    B = ts.regionalBasis("Elbe");
    [a, rec] = ts.regionalProject(B);

Input Arguments

NameSizeTypeDefaultDescription
objn x m-requiredthe object the method is called on
B1 x 1structrequiredstruct a basis from regionalBasis

Name-Value Arguments

None.

Output Arguments

NameDescription
a(K,T) double basis coefficients
rec(1,1) struct as returned by shLowLevel.regionalProject, which documents every field

Error Identifiers
