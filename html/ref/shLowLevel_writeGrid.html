shLowLevel.writeGrid

Export gridded fields to CF-style netCDF (base MATLAB).

Syntax

shLowLevel.writeGrid(filename, grid, latDeg, lonDeg)shLowLevel.writeGrid(filename, grid, latDeg, lonDeg, Name="field", Units="", Epochs=[], ...)

Description

shLowLevel.writeGrid('ewh.nc', GRID, LAT, LON, Name="lwe_thickness", Units="m") writes a 2-D field or a 3-D stack (nlat x nlon x T with Epochs=) using nccreate/ncwrite - a stack is directly readable back by shLowLevel.readMascon (roundtrip-tested), by GMT, panoply, xarray, etc. Time is stored as "days since 2002-01-01" like the mascon products. A 2-D field gets a time axis of length 1 when one epoch is given (Epochs = 2010.29), and none without (before v5.23.4 its epoch was dropped silently).

Examples

Runnable (docs/apiExamples.json)
shLowLevel.writeGrid("ewh.nc", grid, lat, lon);   % netCDF/geotiff/ascii
