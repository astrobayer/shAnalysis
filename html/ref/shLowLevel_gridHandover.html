shLowLevel.gridHandover

Assemble the metadata that travels with a synthesized grid.

Syntax

b = shLowLevel.gridHandover(Z, lat, lon, units, latType, quantity, productType, name, epoch, c00, history, nmax, nmin)

Description

B = shLowLevel.gridHandover(Z, LAT, LON, UNITS, LATTYPE, QUANTITY, PRODUCTTYPE, NAME, EPOCH, C00, HISTORY, NMAX, NMIN) packs a synthesized field together with what it is, for handover to a cartographic toolbox. Called by shCoefficients.toGrid and shSeries.toGrid; it exists so the two bridges cannot describe the same field differently, which is the failure they were built to prevent in the first place.

Examples

From the help block
    b = shLowLevel.gridHandover(Z, lat, lon, "m", "geodetic", "ewh", ...
            "GSM", "ITSG-Grace2018", 2008.29, 0, string.empty(0,1), 60, 0);
    b.FieldKind        % "anomaly"

  See also SHCOEFFICIENTS/TOGRID, SHSERIES/TOGRID, KERNELFACTORS.
