shCoefficients.poleTideConvert

Move C21/S21 to another mean-pole convention.

Syntax

out = shCoefficients.poleTideConvert(obj)out = shCoefficients.poleTideConvert(obj, From=..., To=..., Mode=..., ...)

Description

OUT = g.poleTideConvert(From = "IERS2010", To = "IERS2018") is shLowLevel.poleTideConvert(g, ...): it moves C21 and S21 from the mean-pole model the processing centre removed the pole tide with to another, at the field's own epoch. That function documents the two models and the adjustment.

Examples

From the help block
    g18 = g.poleTideConvert(From = "IERS2010", To = "IERS2018");
