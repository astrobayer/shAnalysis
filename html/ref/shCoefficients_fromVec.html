shCoefficients.fromVec

Unpack a shLowLevel.shIndex-ordered vector into an shCoefficients.

Syntax

obj = shCoefficients.fromVec(x, idx, like)

Description

G = shCoefficients.fromVec(X, IDX, LIKE) copies GM/R and other metadata from the template LIKE (an shCoefficients).

Examples

Runnable (docs/apiExamples.json)
g2 = shCoefficients.fromVec(x, idx, g10);   % sizes/GM/R from template

Input Arguments

NameSizeTypeDefaultDescription
x: x 1doublerequiredcoefficient stack, (P x T) in index ordering
idx1 x 1structrequiredindex struct from shLowLevel.shIndex (fields n, m, cs, P, Lmax, minDegree, pos)
like1 x 1shCoefficientsrequiredtemplate shCoefficients supplying GM, R and metadata

Name-Value Arguments

None.

Output Arguments

NameDescription
obj(1 x 1) shCoefficients rebuilt from x; the size comes from IDX; GM, R, epoch, productType, tideSystem, name (+ "_fromVec") and history come from LIKE; its sigmas, header and variableTerms are NOT copied

Error Identifiers

None documented in the help block. Argument validation raises the MATLAB:* identifiers of the arguments block.
