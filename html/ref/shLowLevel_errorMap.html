shLowLevel.errorMap

Analytic formal-error maps from a full coefficient covariance.

Syntax

[sig, latDeg, lonDeg] = shLowLevel.errorMap(M, idx, latDeg, lonDeg)[sig, latDeg, lonDeg] = shLowLevel.errorMap(M, idx, latDeg, lonDeg, Quantity="geoid", kn=[], hn=[], ...)

Description

[SIG, LAT, LON] = shLowLevel.errorMap(M, IDX, LAT, LON, Quantity ("geoid")="ewh", kn ([])=kn) computes the pointwise 1-sigma of a synthesized field from a full P x P covariance (e.g. shLowLevel.readSINEX(..., Output="covariance").M, reordered via Index=idx).

Examples

Runnable (docs/apiExamples.json)
sig = shLowLevel.errorMap(M, idx, -89:4:89, 0:4:356, Quantity = "ewh", kn = kn);
