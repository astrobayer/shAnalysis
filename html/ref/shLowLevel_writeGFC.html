shLowLevel.writeGFC

Write Stokes coefficients to an ICGEM ASCII .gfc file.

Syntax

shLowLevel.writeGFC(filename, C, S, GM, R)shLowLevel.writeGFC(filename, C, S, GM, R, SigmaC=[], SigmaS=[], ModelName="shAnalysis_export", ...)

Description

shLowLevel.writeGFC(FILENAME, C, S, GM, R) writes a static ICGEM-format gravity field file readable by shLowLevel.shReadGFC (round-trip tested to full double precision: coefficients are written with %22.14e).

Examples

Runnable (docs/apiExamples.json)
shLowLevel.writeGFC("out.gfc", g.C, g.S, g.GM, g.R, Comment = "DDK3 filtered");
