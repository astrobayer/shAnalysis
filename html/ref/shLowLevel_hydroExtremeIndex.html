shLowLevel.hydroExtremeIndex

Flood/drought indices per grid cell or basin.

Syntax

[Z, info] = shLowLevel.hydroExtremeIndex(X, epochs)[Z, info] = shLowLevel.hydroExtremeIndex(X, epochs, Mode="DSI", Detrend="default", Sigma="std", ...)

Description

[Z, INFO] = shLowLevel.hydroExtremeIndex(X, EPOCHS) turns a TWS anomaly stack (grid cells, basin series, or a single series) into a standardized hydrological-extreme index. Three published modes:

Examples

From the help block
    [tws, rep] = shLowLevel.twsChain(ser, kn = kn);       % fields
    [Z, inf1] = shLowLevel.hydroExtremeIndex(tws.grid, tws.epochs);
    imagesc(inf1.category(:, :, end))    % current drought map

Input Arguments

NameSizeTypeDefaultDescription
Xn x mdoublerequired(nLat x nLon x T | K x T | T x 1) double TWS anomalies [any unit]; grids as from twsChain, basins from shSeries.basinAverage
epochs: x 1doublerequireddouble decimal years

Name-Value Arguments

NameSizeTypeDefaultDescription
Mode1 x 1string"DSI""DSI" | "WSDI" | "StorageDeficit"
Detrend1 x 1string"default""linear" | "none" | "default"; "default" resolves to "linear" for DSI/WSDI and to "none" for StorageDeficit (the physical Reager convention)
Sigma1 x 1string"std""std" | "robust" (1.4826 * MAD - one bad month corrupts std by 6x, MAD by nothing: measured in the pre-validation)
MinYears1 x 1double5(1 x 1) calendar months sampled by fewer years get NaN and a warning, never a quietly unstable sigma
PrecipGridn x mdouble[]same shape as X [same unit]: enables the full FPI in StorageDeficit mode
Climatology1 x 1string"auto""monthly" | "doy" | "auto" (daily data - median epoch spacing < 20 days - selects "doy"). The DOY mode is stage 2: daily Kalman solutions (fetchITSG Product="daily") track short-lived floods that monthly solutions miss (Gouweleeuw et al. 2018, Ganges-Brahmaputra). Two-stage construction, Python-prevalidated: climatology per EXACT day-of-year, sigma from the RESIDUALS in a circular +-WindowDays/2 window (wraps Dec-Jan) with the sqrt(n/(n-1)) correction for the estimated-mean variance loss - window sigma on raw values leaks seasonality (measured: 1.99 instead of 1.5 at W=31)
WindowDays1 x 1double31(1 x 1) circular DOY window width [days]

Output Arguments

NameDescription
Zsame shape as X the index (DSI/WSDI z-scores; Sdef in the unit of X; FPI dimensionless in [-inf, 1] when PrecipGrid) info (1 x 1) struct mode, detrended, clim (12 x cells, DSI), sigma, trendPerYr, category (same shape as Z, int8 -5..+5, DSI only; edges [-2 -1.6 -1.3 -0.8 -0.5 .5 .8 1.3 1.6 2]), categoryNames (11 x 1 string, "D4".."W4"), nPerMonth
