shSeries.select

Subset the series by index, mask, or time range.

Syntax

out = shSeries.select(obj, which)out = shSeries.select(obj, which, Range=[])

Description

OUT = ts.select(WHICH) with WHICH one of logical (1,T) keep masked epochs indices keep listed epochs (in the given order) [tMin tMax] keep epochs with tMin <= t <= tMax

Examples

From the help block
    tsFO = ts.select(ts.epochs > 2018.5);
    tsB  = ts.select(Range = [2004 2010]);
Runnable (docs/apiExamples.json)
ts = ts.select(ts.epochs > 2018.5);    % GRACE-FO era only

Input Arguments

whichn x 1-[]logical | double mask, index list, or [tMin tMax]; omit it when passing Range

Name-Value Arguments

Output Arguments

NameDescription

Error Identifiers

IdentifierRaised when
shSeries:select:ambiguousRangewarning - a two-element WHICH was read as INDICES although both values also fall inside the epoch span; pass Range= to mean years
shSeries:select:badInputWHICH and Range= were both given, a logical mask has the wrong length, indices are not integers in 1..nEpochs, or neither was given
shSeries:range:badRangeRange= is not [t1 t2] with t2 > t1 (decimal years or datetime)
