shLowLevel.opApply

Apply the month-t filter operator W_t (or W_t') to columns of Z.

Syntax

Yout = shLowLevel.opApply(op, Z, t, mode)

Description

Yout = shLowLevel.opApply(op, Z, t) computes W_t * Z Yout = shLowLevel.opApply(op, Z, t, 'transp') computes W_t' * Z

Examples

Runnable (docs/apiExamples.json)
xf = shLowLevel.opApply(op, op.Xres(:, 1), 1);   % W_1 * x without the P x P matrix

Input Arguments

t1 x 1doublerequiredtarget point or epoch of the evaluation
mode1 x n-'forward'char 'forward' (default) | 'transp' - forward or transposed operator action

Name-Value Arguments

None.

Output Arguments
