shLowLevel.kalmanChain

Kalman-smoothed SH series in one call (Kurtenbach/Kvas).

Syntax

[ts, rep] = shLowLevel.kalmanChain(obsIn)[ts, rep] = shLowLevel.kalmanChain(obsIn, ModelSeries=..., Order=1, Shrink=0, ...)

Description

[TS, REP] = shLowLevel.kalmanChain(OBSIN, ModelSeries=TSM) is the single point of access to the Kalman/VAR module: it turns noisy per-epoch gravity information plus a geophysical model series into a temporally smoothed shSeries, encoding the correctly ordered chain of Kurtenbach (2012) and Kvas (2019): 1. reduce the model series TSM by its own climatology (mean, trend, annual, semi-annual) - the residual approximates the short-term process (Kurtenbach eq. 3.81) 2. estimate the VAR(Order) process model from the residuals (shLowLevel.estimateVAR; Order=1 is Kurtenbach's B/Q) 3. build one observation record per requested epoch: a solution with noise covariance, a SINEX normal equation, or a gap 4. forward Kalman filter with stationary initialization (shLowLevel.kalmanFilter) 5. RTS smoother (shLowLevel.rtsSmoother) - with step 4 exactly the joint adjustment over all epochs (Kvas Sec. 2.3) 6. repack into an shSeries with formal sigmas; in solution mode the observation climatology removed in step 3 is restored, so TS is directly comparable to the input series

Examples

From the help block
    tsm = shSeries.fromFolder(gaxFolder).truncate(40);
    [ts, rep] = shLowLevel.kalmanChain(tsObs, ModelSeries=tsm, Order=1);

  Memory: the smoother stores two full (pP x pP) covariances per
  epoch: n40/p1/T365 ~ 16 GB. For long daily series run in windows
  or set Smoother=false; REP.memGB reports the actual footprint.

  Reference: Kurtenbach, DGK C-683 (2012); Kvas, TU Graz PhD thesis
  (2019). Numerics pre-validated in Python
  (tools/dev/validate_kalman.py).

NoiseCovn x mdouble[]solution mode: (P x P) double full R, (P x 1) double diagonal, or (P x T) double per-epoch diagonals; [] derives diagonals from the series' formal sigmas
Climatology1 x 1logicaltruesolution mode: reduce OBSIN by its own climatology before filtering and restore it afterwards
FitClimatology1 x 1string"observations""observations" | "filtered" what that climatology is fitted to. "observations" fits it to OBSIN itself, so the noise of the fit is restored unfiltered in every epoch (A34). "filtered" runs the chain once with Climatology = false, fits the climatology to that smoothed series at the output epochs, removes it from OBSIN, filters the residual and restores it - twice the cost. In the 8e closed loop (noise rising to 3 cm per coefficient at degree 30) the grid RMS is 14.5 cm with "observations", 0.89-1.96 cm with "filtered" and 0.90-2.02 cm with Climatology = false; "filtered" is the better of the last two once the climatology is strong (tools/dev/validate_climatology_restore.py). With noise below the signal the two fits differ little. Ignored when Climatology = false and in neq mode.
Smoother1 x 1logicaltruerun the RTS pass (false: filter only, e.g. for NRT-style one-way runs a la Kvas Ch. 3; then the internal filter stores only diagonals and memory stays flat)
QC1 x 1string"none""none" | "flag" | "reject": innovation-based per-epoch quality control (Kvas Sec. 3.3; see kalmanFilter). "reject" keeps blunder epochs out of the recursion - they become prediction-only and are counted in REP.nRejected
QCAlpha1 x 1double1e-3false-alarm level of the test
StoreCov1 x 1string"auto"where the filter keeps the full covariances the smoother needs: "auto" = "full" (RAM) with the smoother, "diag" without; "matfile" streams them through a v7.3 MAT on disk instead - RAM stays flat for long daily runs, results identical to the last bit. The file is deleted after smoothing (it is chain-internal); REP.memGB then reports the DISK footprint
Pattern1 x 1string"*.snx*"neq mode: file pattern inside the folder(s)
NeqWeights: x 1double[]multi-center neq mode: (F x 1) double fixed weights per center (skips per-epoch VCE); [] runs VCE, which requires STATISTICS on every file and errors loudly otherwise (neqCombine contract)
SecondSeries1 x 1shSeries-shSeries a second, noisier series of the same field at the same nmax, GM and R, observing every epoch it has (above); solution mode only. Not given: the chain is unchanged, bitwise
SecondNoisen x m-"overlap""overlap" | (nmax+1 x 1) double the noise sigma_n of SecondSeries per degree: calibrated on the overlap, or given; the offset and scale are calibrated either way
SecondScale1 x 1logicaltruecalibrate the per-degree scale s_n; false fixes s_n = 1. In the closed loop the scale wins in 19 of 20 seeds (gap error 0.34 against 0.35 of the signal)
SecondTolerance1 x 1double0.05(1 x 1) double [yr] an epoch of SecondSeries matches an OBSIN epoch, and a grid epoch, when they differ by less; one month's products sit within it
MinOverlap1 x 1double24the fewest matched months the calibration accepts
