shSeries.buildCondFun

The CondFun conditioner for this series' index.

Syntax

[f, info] = shSeries.buildCondFun(obj)[f, info] = shSeries.buildCondFun(obj, kn=..., Psi0Km=..., Regions=..., ...)

Description

[F, INFO] = tsModel.buildCondFun(kn = KN) is shLowLevel.buildCondFun(shLowLevel.shIndex(tsModel.nmax), kn = KN, GM = tsModel.GM, R = tsModel.R): Kvas' covariance conditioning in the EWH domain, in the index ts.kalman and ts.regionalKalman build their process model on. Call it on the MODEL series and pass F as CondFun. That function documents the conditioner and INFO.

Examples

From the help block
    cf = tsModel.buildCondFun(kn = kn, Psi0Km = 2000);
    tsK = tsObs.kalman(ModelSeries = tsModel, CondFun = cf);
