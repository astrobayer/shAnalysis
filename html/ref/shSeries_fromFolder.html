shSeries.fromFolder

Read every matching gfc file in a folder as a series.

Syntax

obj = shSeries.fromFolder(folder)obj = shSeries.fromFolder(folder, Pattern="*.gfc*", Truncate=NaN)

Description

TS = shSeries.fromFolder("itsg_series") TS = shSeries.fromFolder(dest, Pattern="*n96*.gfc*", Truncate (NaN)=60) Convenience wrapper around shSeries.read (sorted by epoch); pairs with shLowLevel.fetchITSG, which downloads ITSG monthly solutions into tests/test_data/itsg_series on demand.

Examples

Runnable (docs/apiExamples.json)
ts = shSeries.fromFolder(shLowLevel.dataFolder() + "/itsg_series");
