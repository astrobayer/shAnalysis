shSeries.trendBreaks

Piecewise-linear trends with break significance.

Syntax

out = shSeries.trendBreaks(obj)out = shSeries.trendBreaks(obj, Breaks=..., Periods=double.empty(1,0), T0=NaN, ...)

Description

OUT = ts.trendBreaks(Breaks=[2016.0], Periods (double.empty(1,0))=[], T0 (NaN)=, ARCorrect (false)=false) fits the standard climatology design PLUS hinge terms max(0, t - tb) per break epoch (continuous piecewise-linear trend) to every coefficient, and tests the break's significance with an F-test against the no-break model (p-values via betainc - base MATLAB, no toolbox). Python-validated: 5.1% null rejection at the 5% level; F = 23 for a 0.02/yr break in 0.05-sigma noise (T = 120).

Examples

Runnable (docs/apiExamples.json)
out = ts.trendBreaks(Breaks = 2021.0); % F-test on the hinge
