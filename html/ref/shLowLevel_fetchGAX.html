shLowLevel.fetchGAX

Download AOD1B GAX monthly means (GAA/GAB/GAC/GAD) from ICGEM.

Syntax

[files, info] = shLowLevel.fetchGAX(dest)[files, info] = shLowLevel.fetchGAX(dest, Products=["GAD", "GAA"], Series=["01_GRACE/GFZ/GFZ Release 06", "01_GRACE/GFZ/GFZ Release 06.3 (GFO)"], Update=false, ...)

Description

FILES = shLowLevel.fetchGAX(DEST) downloads the monthly-mean dealiasing products needed for full ocean-mass restoration (Chambers & Willis 2010) as ICGEM-converted .gfc files into DEST/<PRODUCT>/. The AOD1B products are identical across processing centres, so the GFZ series pages (which carry all four products from 2002 on) serve every GSM series including COST-G. Listing and download go through the toolbox's Retry-After-aware fetch layer; files already present are skipped unless Update = true.

Examples

From the help block
    f = shLowLevel.fetchGAX("E:/DATAPOOL/GravityField/GAX");
    [out, rep] = shLowLevel.oceanChain(ser, kn = kn, OceanMask = oc, ...
        GADFolder = "E:/DATAPOOL/GravityField/GAX/GAD", ...
        GAAFolder = "E:/DATAPOOL/GravityField/GAX/GAA");

  See fetchITSGSINEX and fetchITSGBackground for the ITSG-side products;
  the ITSG background models are per-release means, NOT the AOD1B
  GAX split.

Input Arguments

NameSizeTypeDefaultDescription
dest1 x 1string""string destination folder ("" = the v3.16 default dataFolder/series/GAX); product subfolders are created as needed

Name-Value Arguments

NameSizeTypeDefaultDescription
Products1 x :string["GAD", "GAA"](1 x k string) any of GAA/GAB/GAC/GAD; GAD restores the model ocean signal, the ocean mean of GAA removes the atmospheric land-ocean mass term
Series1 x :string["01_GRACE/GFZ/GFZ Release 06", "01_GRACE/GFZ/GFZ Release 06.3 (GFO)"](["01_GRACE/GFZ/GFZ Release 06", "01_GRACE/GFZ/GFZ Release 06.3 (GFO)"]) (1 x s string) ICGEM catalogue paths "group/center/series" fed to shLowLevel.listICGEM
Update1 x 1logicalfalse(1 x 1) re-download files that already exist
MaxFiles1 x 1doubleInf(1 x 1) stop after this many downloads per product - bounded acceptance runs, not a user knob
Downloader1 x 1string"websave"(1 x 1) "websave" (webread network stack, matches listICGEM) or "httpFetch" (matlab.net.http with Retry-After support); the stacks differ in proxy/TLS behaviour, websave is the robust default for ICGEM
BudgetSec1 x 1doubleInf(1 x 1) wall-clock budget; on expiry the fetch stops CLEANLY, keeps what it has, and reports the remainder (info.nRemaining) - never a hung call
MaxFailures1 x 1double5(1 x 1) consecutive-failure cap per product; on hitting it the product loop stops with a warning instead of failing every remaining file one by one
PauseSec1 x 1double1.5(1 x 1) polite pause between downloads [s] - the ICGEM server rate-limits bursts (HTTP 429; observed live)
RetryAfterCap1 x 1double30(1 x 1) on a 429 the download is retried ONCE after this wait [s]; a second 429 counts as a failure (websave does not expose the Retry-After header, so a fixed cap replaces server-driven waits)
Quiet1 x 1logicalfalse(1 x 1) suppress progress output

Output Arguments

NameDescription
info(1,1) struct fields products (1 x nProducts) struct array, one per product, with nListed, nDownloaded, nSkipped, nFailed and nRemaining (what the budget cut off) series (1,:) string the series actually used
