shCoefficients.gradient

North/east/up gradient of a synthesized quantity.

Syntax

[dq, info] = shCoefficients.gradient(obj, latDeg, lonDeg)[dq, info] = shCoefficients.gradient(obj, latDeg, lonDeg, Quantity="geoid", kn=[], hn=[], ...)

Description

[DQ, INFO] = g.gradient(LAT, LON, Quantity ("geoid")=..., Units ("perMeter")=..., Mode ("grid")=...) is the exact spatial derivative of what g.synthesis would return under the SAME options - the vector field to draw over a scalar map, or to advect tracers through. DQ.up is EMPTY for surface quantities (ewh, geoid, surface_density, bottom_pressure, deformation_up, none), which have no radial law; INFO.hasUp says so. See shLowLevel.shSynthesisGradient for the formulas, the validation, and why this is NOT g.deformation's horizontal pair (those carry l'_n, these carry the quantity's own kernel).

Examples

From the help block
    lat = -89:2:89; lon = 0:2:358;
    [dq, info] = g.gradient(lat, lon, Quantity = "ewh", kn = kn);
    info.hasUp        % false - EWH is a surface quantity
