shLowLevel.shAnalysisGrid

Spherical harmonic analysis: estimate Stokes coefficients

Syntax

[C, S, info] = shLowLevel.shAnalysisGrid(grid, latVec, lonVec, nmax)[C, S, info] = shLowLevel.shAnalysisGrid(grid, latVec, lonVec, nmax, Method="auto", Quantity='geoid', GM=3.986004415e14, ...)

Description

from gridded or scattered data (the inverse of shLowLevel.shSynthesis).

Examples

Runnable (docs/apiExamples.json)
g2 = shLowLevel.shAnalysisGrid(grid, lat, lon, 10);   % exact on ring grids

Input Arguments

NameSizeTypeDefaultDescription
gridn x mdoublerequiredfield values on the (lat, lon) grid
latVecn x mdoublerequiredgeocentric latitude vector of the grid [deg]
lonVecn x mdoublerequiredlongitude vector of the grid [deg], [0, 360)
nmax1 x 1doublerequiredmaximum spherical harmonic degree

Name-Value Arguments

NameSizeTypeDefaultDescription
Method1 x 1string"auto""auto" (default) | "rings" | "ls"
Quantityn x m-'geoid''geoid' (default) | 'potential' | 'gravity_anomaly' | 'gravity_disturbance' | 'ewh' - the grid's physical Quantity; the degree-dependent kernel (shLowLevel.kernelFactors) is divided out so C,S are Stokes coefficients. Degrees with zero kernel (e.g. n=0,1 for gravity_anomaly) are unobservable and returned as 0 (listed in INFO). GM, R defaults 3.986004415e14, 6378136.3 (only used via kernel)
GM1 x 1double3.986004415e14gravitational constant times Earth mass [m^3/s^2] (default 3.986004415e14, overridable)
R1 x 1double6378136.3reference radius [m] (default 6378136.3, overridable)
knn x mdouble[]load Love numbers, required for Quantity='ewh' rho_ave, rho_water EWH densities (5517, 1000)
hnn x mdouble[]vertical-deformation Love numbers, degrees 0..nmax (user-supplied; only reached through kernelFactors)
rho_ave1 x 1double5517mean Earth density [kg/m^3] (default 5517, overridable)
rho_water1 x 1double1000water density [kg/m^3] (default 1000, overridable)
Weights1 x 1string"none""none" (default) | "coslat" - area weighting of rings/ points (recommended for equiangular ring grids: rows are scaled by sqrt(cos lat), a diagonal approximation of the area weight; for complete ring systems the LS solution is weight-independent, weighting matters when redundant/noisy)
Kaula1 x 1double00 (default: off). If > 0, Tikhonov regularization toward 0 with per-degree standard deviation Kaula*1e-5/n^2 (Kaula's rule; Kaula=1 is the classic value). REQUIRED when the sampling underdetermines the coefficients; without it, rank deficiency raises shLowLevel:shAnalysisGrid:rankDeficient.
ChunkSize1 x 1double2000points per accumulation chunk for "ls" (default 2000)
LatType1 x 1string"geocentric""geocentric" (default) | "geodetic": how LATVEC is interpreted; geodetic values are converted with Flattening before evaluation
Flattening1 x 1double1/298.257223563flattening of the reference ellipsoid for that conversion (WGS84; overridable, never silently assumed)

Output Arguments

NameDescription
C(nmax+1 x nmax+1) double estimated cosine coefficients
S(nmax+1 x nmax+1) double estimated sine coefficients
info(1,1) struct fields method (1,:) char operator actually used, 'rings' or 'ls' nPoints (1,1) double observations entering the estimate unobservedDegrees (1,:) double degrees with a zero kernel, returned as 0 in C and S regularized (1,1) logical whether Kaula > 0 was applied condEst (1,1) double condition estimate of the system (worst per-order value for 'rings') residRMS (1,1) double RMS of the post-fit residuals in the units of the input grid

Error Identifiers

IdentifierRaised when
shLowLevel:shAnalysisGrid:badGridthe rings method needs a uniform full-circle longitude vector with nlon > 2*nmax, or the orders alias
shLowLevel:shAnalysisGrid:badInputGRID is neither numel(lat) x numel(lon) nor a vector matching the lat/lon point lists; Method="rings" got a scattered set; or Method="ls" got nmax = 0
shLowLevel:shAnalysisGrid:rankDeficientthe sampling does not determine all coefficients: the normal equations are singular or numerically so. Reduce nmax or set Kaula > 0
