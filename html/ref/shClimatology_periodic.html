shClimatology.periodic

Cos/sin components of the k-th extra period (v2.1).

Syntax

[gc, gs] = shClimatology.periodic(obj, k)

Description

[GC, GS] = clim.periodic(K) returns shCoefficients for the cos and sin terms of period obj.periods(K) [yr] - e.g. the S2/K2/K1 tidal alias terms when fitted via ts.climatology(Periods=[161/365.25, 3.66, 7.48]).

Examples

Runnable (docs/apiExamples.json)
[gc, gs] = clim.periodic(1);           % extra Periods= component
