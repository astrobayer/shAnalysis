shLowLevel.effectiveCorr

Correlation with AR(1)-corrected significance.

Syntax

out = shLowLevel.effectiveCorr(x, y)

Description

OUT = shLowLevel.effectiveCorr(X, Y) computes the Pearson correlation of two time series together with a significance test that accounts for serial correlation: monthly GRACE series are strongly autocorrelated, so the effective sample size Neff = T*(1-r1*r2)/(1+r1*r2) (r1, r2 = lag-1 autocorrelations) is well below T, and the naive t-test badly over-states significance (Monte-Carlo: ~30% false positives at phi = 0.7 vs ~6% corrected; validated in Python). The two-sided p-value uses the incomplete beta function (base MATLAB betainc), no Statistics Toolbox required.

Examples

From the help block
    ec = shLowLevel.effectiveCorr(avg(1,:)', avg(2,:)');   % two basin series
    fprintf("r = %.3f (p = %.3g, Neff = %.0f)\n", ec.r, ec.p, ec.neff)
