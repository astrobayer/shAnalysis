shLowLevel.regionalProject

Coefficient sets in a regional basis, and back.

Syntax

[a, rec] = shLowLevel.regionalProject(Cs, Ss, B)

Description

[A, REC] = shLowLevel.regionalProject(CS, SS, B) gives one or many coefficient sets their coefficients in the regional basis B of shLowLevel.regionalBasis, A = B.Proj * X, where X stacks the (C, S) coefficients in B.idx ordering: the region-weighted least-squares fit B.regionalBasis documents. REC returns the fit rebuilt in SH, B.T * A, repacked to (C, S) arrays for direct synthesis - inside the region it reproduces the field up to what the basis cannot represent, outside it is whatever the basis functions carry there.

Examples

From the help block
    B = shLowLevel.regionalBasis(shLowLevel.shIndex(60), "Elbe");
    [a, rec] = shLowLevel.regionalProject(ts.Cs, ts.Ss, B);

Input Arguments

NameSizeTypeDefaultDescription
Csn+1 x n+1 x Tdoublerequireddouble cosine coefficients, n >= B.idx.Lmax (T = 1 for a single set)
Ssn+1 x n+1 x Tdoublerequireddouble sine coefficients, the same size
B1 x 1structrequiredstruct a basis from shLowLevel.regionalBasis

Name-Value Arguments

None.

Output Arguments

NameDescription
a(K,T) double basis coefficients, one column per set
rec(1,1) struct the fit rebuilt in SH, fields Cs (n+1,n+1,T) double cosine coefficients of B.T * a Ss (n+1,n+1,T) double sine coefficients of B.T * a

Error Identifiers

IdentifierRaised when
shLowLevel:regionalProject:sizeMismatchthe coefficient arrays reach a lower degree than B.idx.Lmax, or Cs and Ss differ in size
shLowLevel:regionalProject:badBasisB is not a basis from shLowLevel.regionalBasis
