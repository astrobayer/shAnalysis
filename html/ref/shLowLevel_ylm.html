shLowLevel.ylm

4-pi normalized SH basis vectors at arbitrary points.

Syntax

Y = shLowLevel.ylm(latRad, lonRad, idx)

Description

Y = shLowLevel.ylm(LATRAD, LONRAD, IDX) evaluates the basis at nPts points (geocentric latitude/longitude in radians, equal-length vectors), so that f(points) = Y * x for a coefficient vector x in IDX ordering. Vectorized over points via one shLowLevel.legendreALF call.

Examples

Runnable (docs/apiExamples.json)
Y = shLowLevel.ylm(deg2rad(latPts), deg2rad(lonPts), idx);   % design rows, idx order
