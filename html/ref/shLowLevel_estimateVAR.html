shLowLevel.estimateVAR

Empirical VAR(p) process model from an SH state series.

Syntax

model = shLowLevel.estimateVAR(X)model = shLowLevel.estimateVAR(X, Order=1, Shrink=0, CondFun=[], ...)

Description

MODEL = shLowLevel.estimateVAR(X) estimates the stochastic process model of Kurtenbach et al. (2012) from a centred state realization: the vector autoregressive model x_t = Phi_1 x_{t-1} + ... + Phi_p x_{t-p} + w, w ~ N(0, Q) determined by the Yule-Walker equations from the empirical (cross-)covariances Sigma(h) = 1/(T-h) sum x_i x_{i-h}' of the series (Kvas 2019, Sec. 2.4). For Order = 1 this is EXACTLY the closed form of Kurtenbach (2012), eqs. (3.84)-(3.85): B = Sigma(1) Sigma(0)^-1, Q = Sigma(0) - B Sigma(0) B' (unit-tested against it). The realization X is typically a geophysical model series (AOD1B/GAX, ESA ESM, hydrology) reduced by mean, trend and (semi-)annual cycle - shSeries.climatology does that reduction; the state ordering is shLowLevel.shIndex.

Examples

From the help block
    [~, resid] = tsModel.climatology;              % reduce long-term parts
    idx = shLowLevel.shIndex(tsModel.nmax);
    X = zeros(idx.P, resid.nEpochs);
    for k = 1:resid.nEpochs
        g = resid.at(k);
        X(:, k) = shLowLevel.vecFromCS(g.C, g.S, idx);
    end
    model = shLowLevel.estimateVAR(X, Order=1);

  Reference: Kurtenbach, DGK C-683 (2012), Sec. 3.2; Kvas, TU Graz
  PhD thesis (2019), Secs. 2.3-2.4; Luetkepohl (2005).
  Numerics pre-validated in Python (tools/dev/validate_kalman.py).

Name-Value Arguments

NameSizeTypeDefaultDescription
Order1 x 1double1(1 x 1) VAR order p >= 1. Kurtenbach: 1. Higher orders capture longer temporal correlation (Kvas) at p-fold state dimension in the filter.
Shrink1 x 1double0(1 x 1) diagonal loading factor: Sigma(0) + Shrink * trace(Sigma(0))/P * I. Stabilizes the Yule-Walker solve when T is not >> P.
CondFunn x m-[]function handle C -> C applied to every Sigma(h) before the solve, for covariance conditioning a la Kvas Sec. 2.4: land/ocean block masking and the distance-dependent correlation taper exp(-psi/psi0) (his eq. 2.120), built by the caller in the spatial domain. [] leaves the covariances untouched.
Structure1 x 1string"full"coupling structure of the estimate: "full" dense Yule-Walker solve (Kurtenbach/Kvas) - needs T >> P; the right choice for daily sampling with conditioned covariances "diagonal" independent per-coefficient AR(p): Phi_k and Q diagonal - no tuning, immune to short samples "orderblock" block-diagonal per (order m, C/S) block: couples coefficients within an order, none across - the structured middle ground; requires Blocks MEASURED on the live ITSG monthly series through THIS estimator (n40, T = 257, 36-month holdout, one-step RMS, 2026-08-18): climatology-only 4.245e-12; "full" at weak shrink WORSE (4.613e-12 - overfit at T ~ 0.13 P); "diagonal" 3.348e-12 (radius 0.93); "orderblock" with Shrink=1e-2 best at 3.268e-12 (radius 0.96). For monthly series prefer "orderblock" (blocks per (m, C/S) from shIndex) or "diagonal"; "full" remains the default for the daily regime the Kalman module targets.
Blocksn x 1cell{}cell of index vectors partitioning 1:P, required for Structure="orderblock" - e.g. from shIndex: one block per (m, C/S) pair
Sigma0Addn x 1double[](P x P) or (P x 1) double a covariance added to Sigma(0) only, after Shrink and before CondFun: a temporally uncorrelated part of the process - the isotropic ground noise of Kurtenbach (2012, Sec. 4.3.5 and 5.2), which changes the dynamics B as well as Q because Sigma(0) changes. A vector is a diagonal. Shrink is the special case s*trace(Sigma(0))/P * I (bitwise: testEstimateVARSigma0AddGeneralisesShrink).

Output Arguments

NameDescription
model(1,1) struct the process model, fields Phi (1 x p) cell of (P x P) double coefficient matrices Q (P x P) double symmetric PSD process-noise covariance Sigma0 (P x P) double empirical auto-covariance Sigma(0): the stationary state covariance, and the filter's initial covariance order (1,1) double the VAR order p P (1,1) double state dimension specRadius (1,1) double spectral radius of the companion matrix; < 1 is stable, and anything else raises a warning because filtering an unstable model diverges over long gaps
