shLowLevel.eofAnalysis

Empirical orthogonal functions of a coefficient series.

Syntax

[modes, pcs, varExplained, info] = shLowLevel.eofAnalysis(ts)[modes, pcs, varExplained, info] = shLowLevel.eofAnalysis(ts, NModes=6, Center=true)

Description

[MODES, PCS, VAREXPLAINED, INFO] = shLowLevel.eofAnalysis(TS) decomposes the (typically residual) series into spatial modes and principal components via SVD of the flattened, time-centered coefficient stack: X = U S V'; MODES{k} carries U(:,k)*S(k,k)/sqrt(T-1) as an shCoefficients (synthesize for the spatial pattern), PCS(:,k) = sqrt(T-1)*V(:,k) is the unit-variance temporal amplitude, so mode-k field * pc reconstructs the mode's contribution exactly.

Examples

Runnable (docs/apiExamples.json)
[modes, pcs, ve] = shLowLevel.eofAnalysis(resid);
plot(resid.epochs, pcs(:, 1))         % leading principal component
