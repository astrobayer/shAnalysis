shLowLevel.vdkApply

Apply the VDK/VADER decorrelation filter to one solution.

Syntax

[xf, info] = shLowLevel.vdkApply(x, N, degOfPar, sigM)[xf, info] = shLowLevel.vdkApply(x, N, degOfPar, sigM, Alpha=1)

Description

XF = shLowLevel.vdkApply(X, N, DEGOFPAR, SIGM) computes

Examples

From the help block
    idx = shLowLevel.shIndex(96, Nmin = 2);
    snx = shLowLevel.readSINEX(f, Index = idx);
    xf = shLowLevel.vdkApply(snx.x, snx.M, idx.n, ab(mo, :), Alpha = 1);

Input Arguments

NameSizeTypeDefaultDescription
x: x 1doublerequireddouble coefficient vector, same ordering as N
N: x :doublerequireddouble normal-equation matrix (symmetric positive definite)
degOfPar: x 1doublerequireddouble spherical-harmonic degree of every parameter (idx.n from shLowLevel.shIndex)
sigMn x mdoublerequireddouble signal sigma per parameter, OR [a, b] evaluating sigma = a * l^b per parameter (one row of signalVarianceKaula's AB)

Name-Value Arguments

NameSizeTypeDefaultDescription
Alpha1 x 1double1(1 x 1) filter strength; larger = smoother (paper Table 1 maps alpha to mean Gaussian radii for the ITSG-Grace2014 case - the mapping is series-specific)

Output Arguments

NameDescription
xf(P x 1) double filtered coefficient vector info (1 x 1) struct alpha, P, cholOK (true when (N + alpha M) factorized cleanly)

Error Identifiers

IdentifierRaised when
shLowLevel:vdkApply:badSizex, N, degOfPar inconsistent
shLowLevel:vdkApply:notSPD(N + alpha M) not positive definite
