shSeries.shSeries

Construct from an shCoefficients array or raw stacks.

Syntax

obj = shSeries.shSeries(in)obj = shSeries.shSeries(in, Ss=[], Epochs=[], GM=3.986004415e14, ...)

Description

ts = shSeries(objArray) ts = shSeries(Cs, Epochs ([])=..., Ss ([])=...) (raw-stack form via opts)

Examples

Runnable (docs/apiExamples.json)
ts = shSeries(Cs, Ss = Ss, Epochs = tYears);

Input Arguments

NameSizeTypeDefaultDescription
innmax+1 x nmax+1 x T-requireddouble or (1,T) shCoefficients coefficient stacks or object array

Name-Value Arguments

NameSizeTypeDefaultDescription
Ssn x mdouble[]stacked sine coefficients, S(n+1, m+1, T)
Epochs: x 1double[]epochs [decimal years]
GM1 x 1double3.986004415e14gravitational constant times mass [m^3/s^2] of the series (overridable default)
R1 x 1double6378136.3reference radius [m] of the series
ProductType1 x 1string"unknown"provider product code shared by all epochs, e.g. "GSM"
Names: x 1stringstring.empty(0,1)) display labels, one per solution/series
SigmaCsn x mdouble[]formal 1-sigma stack for Cs, same size
SigmaSsn x mdouble[]formal 1-sigma stack for Ss, same size
History1 x 1stringstring.empty(0,1)) initial processing history; every operation appends one line

Output Arguments

NameDescription
obj(1 x 1) shSeries epoch-sorted monthly stack with sigmas and history

Error Identifiers

IdentifierRaised when
shSeries:shSeries:badInputthe raw-stack form needs a square Cs, a matching Ss=, and one Epochs= entry per layer
shSeries:shSeries:constantsMismatchGM or R differ between epochs of the series
shSeries:shSeries:sizeMismatchthe epochs do not all share nmax - truncate first
