shCoefficients.vdkApply

Apply the VDK decorrelation filter with a month's normals.

Syntax

[out, info] = shCoefficients.vdkApply(obj, N, sigM)[out, info] = shCoefficients.vdkApply(obj, N, sigM, Index=[], Alpha=...)

Description

[OUT, INFO] = g.vdkApply(N, SIGM) filters G with its own monthly normal-equation matrix N, xf = (N + alpha M) \ (N x) (Horvath et al. 2018), through shLowLevel.vdkApply, which documents the filter, its relation to tvANS and its cost. G's coefficients are taken in Index ordering - by default shLowLevel.shIndex(nmax, Nmin = 2), the ordering of shLowLevel.readSINEX(..., Index = idx) - filtered, and put back. Coefficients outside Index pass through unchanged. As with g.applyDDK the formal sigmas are NOT propagated through the filter; they become NaN. Alpha goes to shLowLevel.vdkApply only when given, so "(lane default)" below is that function's.

Examples

From the help block
    idx = shLowLevel.shIndex(96, Nmin = 2);
    snx = shLowLevel.readSINEX(f, Index = idx);
    gf = g.vdkApply(snx.M, ab(mo, :), Index = idx, Alpha = 1);
