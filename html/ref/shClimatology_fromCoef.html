shClimatology.fromCoef

Build from shLowLevel.fitDeterministicModel output (internal).

Syntax

obj = shClimatology.fromCoef(coef, t0, series)obj = shClimatology.fromCoef(coef, t0, series, Periods=double.empty(1,0), CoefSigma=[])

Description

OBJ = shClimatology.fromCoef(COEF, T0, SERIES, Periods (double.empty(1,0))=[], CoefSigma=[]) with COEF (6+2K) x (2*Nc) over the flattened [C(:); S(:)] stack of SERIES; rows 7:end are the cos/sin pairs of the K extra Periods [yr].

Examples

Runnable (docs/apiExamples.json)
clim = shClimatology.fromCoef(coef, t0, ts);
