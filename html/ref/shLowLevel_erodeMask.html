shLowLevel.erodeMask

Erode a region mask by a great-circle boundary buffer.

Syntax

[mk2, dmin] = shLowLevel.erodeMask(mk, lat, lon, bufferKm)

Description

MK2 = shLowLevel.erodeMask(MK, LAT, LON, KM) keeps only mask pixels whose great-circle distance to the nearest OUTSIDE pixel exceeds BUFFERKM. Distances are computed against the boundary pixels of the complement only (coast), so the cost is nCoast x nGrid.

Examples

From the help block
    oc = abs(LA) <= 66 & ~landBoxes;              % crude ocean mask
    oc300 = shLowLevel.erodeMask(oc, lat, lon, 300);
    nnz(oc) - nnz(oc300)                          % coast pixels shed

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
mk2(nLat x nLon) logical eroded mask
dmin(nLat x nLon) double distance to the nearest outside coast pixel [km] (Inf where no outside pixel exists)
