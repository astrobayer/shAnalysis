shCoefficients.toReference

Convert to another (GM, R) reference (exact).

Syntax

out = shCoefficients.toReference(obj)out = shCoefficients.toReference(obj, GM=NaN, R=NaN)

Description

OUT = g.toReference(GM=3.986004418e14, R=6378137.0) re-expresses the coefficients via shLowLevel.rescaleGMR; the physical field is invariant (Python-validated). Sigmas rescale identically; GM/R properties are updated.

Examples

Runnable (docs/apiExamples.json)
g = g.toReference(GM = 3.986004415e14, R = 6.3781363e6);
