shLowLevel.vecFromCS

Pack lower-triangular Cnm/Snm matrices into a shLowLevel vector.

Syntax

x = shLowLevel.vecFromCS(cnm, snm, idx)

Description

x = shLowLevel.vecFromCS(cnm, snm, idx) with cnm, snm of size (Lmax+1)x(Lmax+1), cnm(n+1,m+1) = Cnm, snm(n+1,m+1) = Snm.

Examples

Runnable (docs/apiExamples.json)
x = shLowLevel.vecFromCS(g10.C, g10.S, idx);     % triangle -> idx-ordered vector

Input Arguments

NameSizeTypeDefaultDescription
cnmn x mdoublerequiredcosine coefficient matrix, C(n+1, m+1) indexing
snmn x mdoublerequiredsine coefficient matrix, same indexing
idx1 x 1structrequiredindex struct from shLowLevel.shIndex (fields n, m, cs, P, Lmax, minDegree, pos)

Name-Value Arguments

None.

Output Arguments

NameDescription
x(P x 1) double coefficients gathered in idx ordering
