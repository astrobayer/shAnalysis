shLowLevel.gridScaling

Per-pixel leakage/attenuation scaling factors from a model.

Syntax

[k, info] = shLowLevel.gridScaling(model, latDeg, lonDeg)[k, info] = shLowLevel.gridScaling(model, latDeg, lonDeg, Filter="gauss300", Nmax=NaN, MinSignal=1e-3, ...)

Description

[K, INFO] = shLowLevel.gridScaling(MODEL, LATDEG, LONDEG, Filter = ...) computes the classic gridded scaling factors: push a MODEL field series through the SAME processing chain the data saw and regress, per pixel, the true value on the filtered one,

Examples

From the help block
    k = shLowLevel.gridScaling(modelEWH, -89:89, 0:359, ...
            Filter = "gauss300");
    corrected = k .* filteredEWH;      % NaN outside the model's reach

  See also shLowLevel.leakageCorrect, shLowLevel.basinScaling.
Runnable (docs/apiExamples.json)
k = shLowLevel.gridScaling(modelEWH, -89:89, 0:359, Filter = "gauss300");
corrected = k .* filteredEWH;      % NaN where the model is blind

Input Arguments

NameSizeTypeDefaultDescription
modelnLat x nLon x Tdoublerequireddouble UNFILTERED model fields, one slice per epoch, in the same quantity as the data
latDegn x mdoublerequireddouble geocentric latitudes [deg]
lonDegn x mdoublerequireddouble longitudes [deg]

Name-Value Arguments

NameSizeTypeDefaultDescription
Filtern x m-"gauss300"the chain the DATA saw: "none" | "gauss<radiusKm>" | "DDKn" | a W struct from shLowLevel.readDDK / shLowLevel.designFilter
Nmax1 x 1doubleNaNexpansion degree (NaN: floor((nLat - 1) / 2))
MinSignal1 x 1double1e-3threshold as a fraction of the strongest pixel's summed POWER (so 1e-3 is about 3% in amplitude). Pixels below it in filtered power get k = NaN; the same threshold on the MODEL's own power selects the pixels INFO summarises
Clipn x mdouble[](1 x 2) double clamp k to [lo hi] ([]: no clamping). Factors far from 1 usually mean the model does not describe that pixel, not that the signal is huge
GM1 x 1double3.986004415e14reference constants used to convert the grid to coefficients and back. They CANCEL in the chain, so the result does not depend on them; they exist so an unusual pair can be matched to the data
R1 x 1double6378136.3reference radius [m], see GM
Quiet1 x 1logicalfalsesuppress the coverage summary

Output Arguments

NameDescription
k(nLat x nLon) double scaling factors; NaN where the model carries too little signal to define one
info(1,1) struct fields covered (1,1) double fraction of the grid with a finite k kMedian, kMin, kMax (1,1) double over the pixels the MODEL gives mass to - deliberately NOT over all finite pixels, where pure-leakage k = 0 would dominate onSignal (1,1) double how many pixels those are clipped (1,1) double pixels whose k was clamped nmax (1,1) double degree the scaling was built at filter (1,1) string the filter it was built for epochs (1,1) double epochs that entered the regression

Error Identifiers

IdentifierRaised when
shLowLevel:gridScaling:badClipClip is not [lo hi] with lo < hi
shLowLevel:gridScaling:badFilterFilter is refused by shLowLevel.filterSpec: it is not a W struct, "none", "gauss<radiusKm>" or "DDK1" to "DDK8"
shLowLevel:gridScaling:nanInputthe model holds NaN or Inf - fill its gaps first
shLowLevel:gridScaling:badNmaxthe grid supports nmax < 2; give at least 3 latitudes
shLowLevel:gridScaling:badSizemodel is not nLat x nLon x T for the given latDeg and lonDeg
