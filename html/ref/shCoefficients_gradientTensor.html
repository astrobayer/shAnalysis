shCoefficients.gradientTensor

Full gravity gradient tensor in the local NEU frame.

Syntax

[comps, info] = shCoefficients.gradientTensor(obj, latDeg, lonDeg)[comps, info] = shCoefficients.gradientTensor(obj, latDeg, lonDeg, Height=..., Nmin=...)

Description

[COMPS, INFO] = g.gradientTensor(LAT, LON) synthesizes the six independent components of the disturbing gravity gradient tensor - uu, nn, ee, un, ue, ne - the GOCE-style diagnostic. It is shLowLevel.shSynthesisGradientTensor with G's coefficients, GM and R; that function documents the formulas, the Laplace self-check INFO carries, and the validation. Its options go there only when given, so "(lane default)" below is that function's - and its Height defaults to a satellite ALTITUDE, not to the surface.

Examples

From the help block
    [G, info] = g.gradientTensor(-89:89, 0:359, Height = 255e3);
    info.maxTraceResidual     % the Laplace self-check
