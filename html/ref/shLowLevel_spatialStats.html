shLowLevel.spatialStats

Area-weighted spatial comparison of two grids.

Syntax

stats = shLowLevel.spatialStats(A, B, latDeg, lonDeg)stats = shLowLevel.spatialStats(A, B, latDeg, lonDeg, Mask=[], Weights=[])

Description

STATS = shLowLevel.spatialStats(A, B, LATDEG, LONDEG) compares two nlat x nlon grids with proper cos(latitude) area weighting - unweighted RMS on a lat/lon grid over-counts the poles and is simply wrong. Returns bias, RMSD, the CENTERED pattern statistics (centered RMSD, weighted correlation, standard deviations) that feed a Taylor diagram, and verifies the Taylor identity crmsd^2 = stdA^2 + stdB^2 - 2 stdA stdB corr internally.

Examples

From the help block
    A1 = g.synthesis(lat, lon); A2 = gF.synthesis(lat, lon);
    st = shLowLevel.spatialStats(A1, A2, lat, lon);
    fprintf("rmsd %.3g, corr %.3f\n", st.rmsd, st.corr)

Input Arguments

Bn x mdoublerequiredbasin-kernel coefficient vector from basinKernel
latDeg1 x :doublerequiredgeocentric latitudes [deg]
lonDeg1 x :doublerequiredlongitudes [deg], lon in [0, 360)

Name-Value Arguments

NameSizeTypeDefaultDescription
Maskn x m-[]nlat x nlon logical: restrict to a region (e.g. land/ocean); default all points
Weightsn x mdouble[]custom nlat x nlon weights (e.g. quadrature); default cos(latDeg) rings, normalized over the mask

Output Arguments

NameDescription
stats(1,1) struct fields: .bias (1,1) double weighted mean of A - B .rmsd (1,1) double weighted RMS of A - B .crmsd (1,1) double centered (bias-free) RMSD .corr (1,1) double weighted pattern correlation .stdA (1,1) double weighted std of A .stdB (1,1) double weighted std of B .ratio (1,1) double stdB / stdA .nUsed (1,1) double number of grid points used
