shSeries.destripe

Swenson & Wahr / P3M6, applied per epoch.

Syntax

out = shSeries.destripe(obj)out = shSeries.destripe(obj, MinOrder=6, PolyOrder=3, WindowLength=[])

Description

No description beyond the summary line above.

Examples

Runnable (docs/apiExamples.json)
ts = ts.destripe(MinOrder = 6);

Input Arguments

NameSizeTypeDefaultDescription
objn x m-requiredthe object the method is called on

Name-Value Arguments

NameSizeTypeDefaultDescription
MinOrder1 x 1double6lowest order to destripe; coefficients at m < minOrder pass through unchanged (below it the signal is real, not stripes)
PolyOrder1 x 1double3order of the polynomial fitted and removed per order/parity sequence
WindowLengthn x mdouble[][] fits ONE polynomial over the whole sequence; an odd integer >= polyOrder+2 uses a centered moving window instead (WindowLength=6 with PolyOrder=3 is the common "P3M6" variant)

NameDescription
out(1 x 1) shSeries destriped per month
