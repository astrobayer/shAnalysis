shCoefficients.plus

Coefficient addition (e.g. GSM + GAD background restore).

Syntax

out = shCoefficients.plus(a, b)

Description

No description beyond the summary line above.

Examples

Runnable (docs/apiExamples.json)
gsm = g + gad;                        % epoch-checked restore

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
out(1 x 1) shCoefficients sum; sigmas RSS; epochs must match

Error Identifiers

IdentifierRaised when
shCoefficients:operands:badInputthe other operand is not an shCoefficients. The `operands` segment marks a check shared by the binary operators, so it stays stable if the private helper behind it is renamed
shCoefficients:operands:constantsMismatchthe operands differ in GM or R - convert first with toReference(GM=..., R=...)
shCoefficients:operands:epochMismatchthe operand epochs differ by more than 0.02 yr. minus does NOT raise this: a difference has no single epoch, so it sets epoch = NaN instead of checking
shCoefficients:operands:sizeMismatchthe operands differ in nmax - truncate first
