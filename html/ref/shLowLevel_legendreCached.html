shLowLevel.legendreCached

Cached fully normalized Legendre functions.

Syntax

P = shLowLevel.legendreCached(nmax, latRad)

Description

P = shLowLevel.legendreCached(NMAX, LATRAD) returns shLowLevel.legendreALF(NMAX, LATRAD), serving repeated requests for the same (NMAX, LATRAD) from a process-wide cache. Cache hits are verified with an EXACT isequal comparison of the stored latitude vector -- a mismatched latVec can never silently return the wrong P (this removes the documented footgun of shSynthesis' raw 'P' passthrough).

Examples

Runnable (docs/apiExamples.json)
shLowLevel.legendreCached("clear")           % drop the synthesis cache

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments
