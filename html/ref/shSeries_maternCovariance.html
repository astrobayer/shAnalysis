shSeries.maternCovariance

An SPDE-Matern prior covariance for this index.

Syntax

[C, info] = shSeries.maternCovariance(obj)[C, info] = shSeries.maternCovariance(obj, PracticalRangeKm=..., Sigma=..., kn=..., ...)

Description

[C, INFO] = ts.maternCovariance(PracticalRangeKm = RHO) is shLowLevel.maternCovariance(shLowLevel.shIndex(ts.nmax), PracticalRangeKm = RHO, GM = ts.GM, R = ts.R): the covariance of the coefficients of a (non-)stationary Matern field in the index ts.regionalKalman takes as ProcessCov or StartCov. That function documents the SPDE, its discretisation and INFO.

Examples

From the help block
    C = tsModel.maternCovariance(PracticalRangeKm = 500, ...
        Sigma = 0.02, kn = kn);
    tsK = ts.regionalKalman(B, ModelSeries = tsModel, ProcessCov = C);
