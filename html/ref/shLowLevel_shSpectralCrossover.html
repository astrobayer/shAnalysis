shLowLevel.shSpectralCrossover

Degree at which the error spectrum first exceeds the

Syntax

[nCrossover, degreeInterp] = shLowLevel.shSpectralCrossover(spec)

Description

signal (degree-amplitude) spectrum -- a standard guide for choosing a truncation degree or Gaussian filter radius.

Examples

Runnable (docs/apiExamples.json)
spec = shLowLevel.shDegreeRMS(g.C, g.S, 'sigmaC', g.sigmaC, 'sigmaS', g.sigmaS);
nc = shLowLevel.shSpectralCrossover(spec);   % signal/error crossover degree

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
nCrossover(1,1) double first degree with err > signal (NaN if none, or if it is the first degree)
degreeInterp(1,1) double linearly interpolated crossing degree

Error Identifiers

IdentifierRaised when
shLowLevel:shSpectralCrossover:missingFieldSPEC has no errAmplitude field - shDegreeRMS was called without SigmaC/SigmaS
