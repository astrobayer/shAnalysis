shSeries.gradient

North/east/up gradient of every epoch, stacked.

Syntax

[dq, info] = shSeries.gradient(obj, latDeg, lonDeg)[dq, info] = shSeries.gradient(obj, latDeg, lonDeg, Quantity=..., kn=..., hn=..., ...)

Description

[DQ, INFO] = ts.gradient(LAT, LON, ...) is g.gradient of each epoch g = ts.at(k), with DQ.north, DQ.east and DQ.up stacked along the THIRD dimension, page k for epoch k, as ts.toGrid stacks its fields: (nlat x nlon x T) on a grid and (npts x 1 x T) for Mode = "points". DQ.up stays [] for the surface quantities, which have no radial law. INFO is the first epoch's; it depends only on the options, which every epoch shares. The options go to g.gradient only when given, so "(method default)" below is shCoefficients.gradient's.

Examples

From the help block
    [dq, info] = ts.gradient(-89:2:89, 0:2:358, Quantity = "ewh", kn = kn);
    size(dq.north)        % 90 x 180 x T
