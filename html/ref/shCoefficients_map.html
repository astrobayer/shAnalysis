shCoefficients.map

Synthesize and draw in one call, through geoMap.

Syntax

H = shCoefficients.map(obj, latDeg, lonDeg)H = shCoefficients.map(obj, latDeg, lonDeg, Quantity="ewh", kn=[], hn=[], ...)

Description

H = g.map(-89:89, 0:359, Quantity=..., kn=...) builds the handover struct with g.toGrid and hands it to geo.map. It draws NOTHING itself.

Examples

From the help block
    H = g.map(-89.5:89.5, 0.5:359.5, Quantity = "ewh", kn = kn, ...
            CRS = "robinson");
Runnable (docs/apiExamples.json)
g.map(-89:89, 0:359, Quantity = "ewh", kn = kn, CRS = "robinson");   % needs geoMap on the path
