shCoefficients.slepianProject

Project this field onto a Slepian basis, and back.

Syntax

[a, rec] = shCoefficients.slepianProject(obj, G, idx)

Description

[A, REC] = g.slepianProject(G, IDX) is shLowLevel.slepianProject(g.C, g.S, G, IDX), with the tapers G and the index IDX of shLowLevel.slepianBasis. A holds the Slepian coefficients, REC the field rebuilt from them.

Examples

From the help block
    G = shLowLevel.slepianBasis(idx, @(la, lo) double(la > 60));
    a = g.slepianProject(G, idx);

Input Arguments

NameSizeTypeDefaultDescription
objn x m-requiredthe object the method is called on
GP x K-requireddouble Slepian tapers, from shLowLevel.slepianBasis
idx1 x 1-requiredstruct the coefficient index they are ordered by

Name-Value Arguments

None.

Output Arguments

NameDescription
a(K,1) double the Slepian coefficients
rec(1,1) struct as returned by shLowLevel.slepianProject, which documents every field

Error Identifiers

None documented in the help block. Argument validation raises the MATLAB:* identifiers of the arguments block.
