shLowLevel.neqAddCoefficients

Add single-coefficient observations to a normal equation.

Syntax

[neq, idxOut, info] = shLowLevel.neqAddCoefficients(neq, idx, obs)

Description

[NEQ, IDXOUT] = shLowLevel.neqAddCoefficients(NEQ, IDX, OBS) adds independent values of single coefficients - C20 and C30 from SLR (shLowLevel.readTN14), degree 1 from shLowLevel.readTN13 - to a normal equation N x = b as pseudo-observations, so they are estimated JOINTLY with the rest instead of substituted into the solution. Each value v of coefficient p with 1-sigma s adds N(p,p) += 1/s^2, b(p) += v/s^2, ltpl += v^2/s^2, nobs += 1, which is the stacked least-squares problem with the row x_p = v appended (tools/dev/validate_neq_low_degree.py CLAIMs 1-2, 2.2e-15). ltpl and nobs are updated only where NEQ carries them, so the result still enters shLowLevel.neqCombine's variance component estimation.

Examples

From the help block
    tn = shLowLevel.readTN14(tn14File);
    k = find(abs(tn.epoch - snx.epoch) < 1/24, 1);   % the same month
    obs = struct('n', [2; 3], 'm', [0; 0], 'cs', [0; 0], ...
        'value', [tn.C20(k); tn.C30(k)], ...
        'sigma', [tn.sigmaC20(k); tn.sigmaC30(k)]);
    [neq, idx2] = shLowLevel.neqAddCoefficients(snx, idx, obs);
    x = neq.N \ neq.b;                % in shIndex order idx2

Input Arguments

NameSizeTypeDefaultDescription
neq1 x 1structrequiredstruct the normal equation, either with fields N (P x P) and b (P x 1), and optionally ltpl and nobs (1,1); or a shLowLevel.readSINEX result with kind 'NEQ' (N = M, b = M x, ltpl and nobs from its stats where present)
idx1 x 1structrequiredstruct shLowLevel.shIndex of NEQ
obs1 x 1structrequiredstruct the observed coefficients, fields n, m, cs (K x 1, cs 0 for C and 1 for S), value and sigma (K x 1); the same coefficient may appear more than once

Name-Value Arguments

None.

Output Arguments

NameDescription
neq(1,1) struct fields N (Q x Q), b (Q x 1), and ltpl and nobs (1,1) where the input carried them
idxOut(1,1) struct shLowLevel.shIndex of the result: IDX, or IDX extended down to the lowest degree observed
info(1,1) struct fields positions (K x 1) double each observation's position in IDXOUT added (:,1) double positions in IDXOUT of the coefficients the extension added (empty if none) extended (1,1) logical whether the index was extended

Error Identifiers

IdentifierRaised when

shLowLevel:neqAddCoefficients:badObsOBS lacks a field, its fields differ in length, a value is not finite, or an (n, m, cs) is not a coefficient
shLowLevel:neqAddCoefficients:badSigmaa sigma is not finite and positive
shLowLevel:neqAddCoefficients:outOfRangean observed degree is above IDX.Lmax or below 1
shLowLevel:neqAddCoefficients:unobservedthe extension added a coefficient that OBS does not observe
