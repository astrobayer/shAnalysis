shLowLevel.shGaussianFilter

Apply isotropic Gaussian smoothing to Stokes coefficients.

Syntax

[Cf, Sf, Wn] = shLowLevel.shGaussianFilter(C, S, radius_km, varargin)

Description

[CF, SF] = SHGAUSSIANFILTER(C, S, RADIUS_KM) multiplies each degree n row of C, S by the Jekeli (1981) weight Wn(n), see SHGAUSSIANWEIGHTS. Standard pre-processing step for GRACE/GRACE-FO mass-change maps before spatial synthesis, used to suppress high-degree noise.

Examples

Runnable (docs/apiExamples.json)
[Cf, Sf] = shLowLevel.shGaussianFilter(g.C, g.S, 350);

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
Cf(nmax+1 x nmax+1) double smoothed cosine coefficients
Sf(nmax+1 x nmax+1) double smoothed sine coefficients
Wn(nmax+1 x 1) double Jekeli degree weights applied
