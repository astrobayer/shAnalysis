shCoefficients.toGrid

Synthesized field plus the metadata a map needs to draw it.

Syntax

b = shCoefficients.toGrid(obj, latDeg, lonDeg)b = shCoefficients.toGrid(obj, latDeg, lonDeg, Quantity="ewh", kn=[], hn=[], ...)

Description

B = g.toGrid(LAT, LON, Quantity ("ewh")=..., kn ([])=..., LatType ("geodetic")=...) synthesizes exactly as g.synthesis does and returns the values TOGETHER WITH what they are: units, latitude convention, product type, epoch, provenance, and whether the field is a full field or an anomaly.

Examples

From the help block
    b = g.toGrid(-89.5:89.5, 0.5:359.5, Quantity = "ewh", kn = kn);
    b.Units          % "m"
    b.FieldKind      % "anomaly" for a residual field

Output Arguments
