shLowLevel.readTN14

Parse a TN-14 style SLR C20/C30 replacement table.

Syntax

tn = shLowLevel.readTN14(filename)

Description

TN = shLowLevel.readTN14(FILENAME) reads the CSR/GFZ "TN-14" technical-note text format: an arbitrary text header followed by data lines with 10 whitespace-separated numeric columns MJD_begin yearfrac_begin C20 C20-mean*1e10 sigC20*1e10 ... C30 C30-mean*1e10 sigC30*1e10 MJD_end yearfrac_end C30 columns contain 'NaN' for months where no SLR C30 is provided (pre GRACE-FO accelerometer degradation).

Examples

Runnable (docs/apiExamples.json)
tn14 = shLowLevel.readTN14("TN-14_C30_C20_SLR_GSFC.txt");
