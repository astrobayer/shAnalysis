shLowLevel.combineCenters

VCE-weighted combination of multi-center monthly series.

Syntax

[tsComb, info] = shLowLevel.combineCenters(tsCell)[tsComb, info] = shLowLevel.combineCenters(tsCell, Tolerance=0.05, AllowMissing=true, Robust=false, ...)

Description

[TSCOMB, INFO] = shLowLevel.combineCenters({tsITSG, tsCSR, tsGFZ}) combines monthly solutions from several processing centers into one series with one variance factor per (center, month), estimated by Foerstner variance-component iteration with PARTIAL REDUNDANCIES:

Examples

Runnable (docs/apiExamples.json)
tsC = shLowLevel.combineCenters({tsCSR, tsGFZ, tsJPL});   % VCE-weighted

Input Arguments

NameSizeTypeDefaultDescription
tsCell1 x :cellrequired1 x C cell of shSeries, equal nmax, >= 2 centers

Name-Value Arguments

NameSizeTypeDefaultDescription
Tolerance1 x 1double0.05[yr] epoch matching (centers date mid-months slightly differently)
AllowMissing1 x 1logicaltruemonths missing at some centers are combined from the available ones (weights renormalize); false: only fully-covered months are kept
Robust1 x 1logicalfalseper-month factor = median over blocks of the unbiased block estimates q_b/r_b instead of the global ratio (outlier-month protection; Python-validated design)
MaxIter1 x 1double6, Tol (1e-3) VCE iteration control
Tol1 x 1double1e-3convergence tolerance

Output Arguments

NameDescription
tsCombshSeries combined stacks on the reference epochs (first center), sigmaCs/Ss = posterior sqrt(diag(H)) per month, provenance in history
infostruct: s2 (C x T variance factors, NaN where missing), weights (C x T, normalized 1/s2), redundancy (C x T), interCenterCorr (C x C, empirical residual correlation - the honesty diagnostic: VCE assumes independence, GRACE centers share data and background models), nIter, epochs, centers, note
