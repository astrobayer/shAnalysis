shLowLevel.antarcticaChain

The validated GravIS Antarctica ice-trend chain.

Syntax

[gt, rep] = shLowLevel.antarcticaChain(folder, gravisFolder)[gt, rep] = shLowLevel.antarcticaChain(folder, gravisFolder, kn=[], BasinFile="basins_AIS.json", NeighbourBoxes=[], ...)

Description

[GT, REP] = shLowLevel.antarcticaChain(FOLDER, GRAVISFOLDER, kn=KN) runs the same chain as greenlandChain with the 25 GravIS AIS drainage-basin polygons as the mask (guide chapter V7). With the tested defaults and COST-G RL02.1 this returns -125.7 Gt/yr against the AWI joint-inversion -146.9 - read V7 before interpreting the 14%: it is the documented distance between map-based estimators and the Sasgen forward-modelling class (the official TU Dresden kernel grid shows the same per-basin damping, correlation 0.905), and the GIA correction (+52.2 Gt/yr over the AIS) is not optional here. REP.basins reports the per-basin masses over the 25 polygons.

Examples

From the help block
    [gt, rep] = shLowLevel.antarcticaChain("E:/series/COSTG", ...
        "E:/GravIS", kn = kn, OceanMask = @(la,lo) abs(la) < 60);
    rep.basins
Runnable (docs/apiExamples.json)
[gt, rep] = shLowLevel.antarcticaChain("E:/series/COSTG", kn = kn, OceanMask = oc);
disp(rep.basins)                                       % 25 GravIS basins [Gt/yr]
