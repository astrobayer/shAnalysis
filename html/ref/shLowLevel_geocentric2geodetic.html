shLowLevel.geocentric2geodetic

Convert geocentric to geodetic latitude.

Syntax

latGD = shLowLevel.geocentric2geodetic(latGC)latGD = shLowLevel.geocentric2geodetic(latGC, Flattening=1/298.257223563)

Description

LATGD = shLowLevel.geocentric2geodetic(LATGC) inverts shLowLevel.geodetic2geocentric: tan(latGD) = tan(latGC) / (1 - f)^2.

Examples

Runnable (docs/apiExamples.json)
latGd = shLowLevel.geocentric2geodetic(latGc);   % WGS84
