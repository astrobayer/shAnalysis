shLowLevel.fetchITSG

Download ITSG monthly OR daily solutions from TU Graz.

Syntax

[files, info] = shLowLevel.fetchITSG(months)[files, info] = shLowLevel.fetchITSG(months, Dest="", Nmax=NaN, Product="monthly", ...)

Description

The fetch family, one function per source and product: fetchITSG and fetchICGEM for solution series, fetchGAX for the AOD1B GAA/GAB/GAC/GAD monthly means (ICGEM/GFZ pages), fetchITSGSINEX for the ITSG monthly normal-equation SINEX, fetchITSGBackground for the ITSG monthly background models, plus fetchTN, fetchDDK, fetchLoveNumbers for auxiliaries.

Examples

Runnable (docs/apiExamples.json)
shLowLevel.fetchITSG(["2008-04", "2025-12"], Nmax = 96);

BaseURL1 x 1string"https://ftp.tugraz.at/pub/ITSG/GRACE"("https://ftp.tugraz.at/pub/ITSG/GRACE") server base URL, or a local mirror folder for offline use

Error Identifiers
