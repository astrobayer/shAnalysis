shLowLevel.oceanRMS

Open-ocean RMS of a field - the standard GRACE noise metric.

Syntax

[rmsVal, info] = shLowLevel.oceanRMS(grid, latDeg, lonDeg, ocean)[rmsVal, info] = shLowLevel.oceanRMS(grid, latDeg, lonDeg, ocean, MinDistanceKm=1000, Weighted=true, Subsample=1)

Description

RMSVAL = shLowLevel.oceanRMS(GRID, LATDEG, LONDEG, OCEAN) returns the area-weighted RMS of GRID over the OPEN ocean: ocean points more than MinDistanceKm (default 1000) from the nearest non-ocean point.

Examples

From the help block
    isOcean = @(la, lo) ~inpolygon(lo, la, landLon, landLat);
    noise = shLowLevel.oceanRMS(ewh, -89:89, 0:359, isOcean);
    m = shLowLevel.leakageCorrect(ewh, -89:89, 0:359, ...
            Filter = "gauss300", Mask = basin, NoiseLevel = noise);

  See also shLowLevel.leakageCorrect, shLowLevel.spatialStats.
Runnable (docs/apiExamples.json)
noise = shLowLevel.oceanRMS(ewh, -89:89, 0:359, isOcean);   % > 1000 km offshore
m = shLowLevel.leakageCorrect(ewh, -89:89, 0:359, Mask = basin, NoiseLevel = noise);

Input Arguments

NameSizeTypeDefaultDescription
gridnLat x nLondoublerequireddouble the field to measure
latDegn x mdoublerequireddouble geocentric latitudes [deg]
lonDegn x mdoublerequireddouble longitudes [deg]
oceannLat x nLon-requiredlogical, or a function handle f(latDeg, lonDeg) -> logical/[0,1] evaluated on the grid. true = ocean

Name-Value Arguments

NameSizeTypeDefaultDescription
MinDistanceKm1 x 1double1000erode the ocean mask by this great-circle distance, i.e. keep only points farther than this from any non-ocean point. 1000 km is the common convention; 0 uses the whole ocean and will be contaminated by leakage from the continents
Weighted1 x 1logicaltrueweight by cos(latitude). Grid cells are not equal in area, and an unweighted RMS over a lat/lon grid over-counts the polar rows. On white noise the two agree, which is exactly why the difference is easy to miss until the field has structure
Subsample1 x 1double1use every n-th non-ocean point (all of them, not only the coast; column-major order) for the distance computation. The erosion costs O(nOcean x nLand); on fine grids raise this, at the cost of a distance error of order n grid steps

Output Arguments

NameDescription
rmsVal(1,1) double open-ocean RMS, in GRID's units. NaN when the erosion leaves no points
info(1,1) struct fields nPixels (1,1) double points that entered the RMS fractionUsed (1,1) double those as a fraction of the grid mask (nLat x nLon) logical the eroded region - plot it once before trusting the number minDistanceKm (1,1) double erosion distance applied [km] weighted (1,1) logical whether area weights were used
