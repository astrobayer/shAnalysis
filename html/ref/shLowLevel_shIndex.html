shLowLevel.shIndex

Canonical order-major index for SH coefficient vectors.

Syntax

idx = shLowLevel.shIndex(Lmax)idx = shLowLevel.shIndex(Lmax, Nmin=2)

Description

idx = shLowLevel.shIndex(Lmax) builds the index table used by all shLowLevel functions: order-major ordering, C before S per (n,m), degrees n = Nmin..Lmax (default Nmin = 2; degree 0/1 and the SLR-C20 replacement are assumed to be handled upstream).

Examples

Runnable (docs/apiExamples.json)
idx = shLowLevel.shIndex(60);                % Nmin = 2 default
