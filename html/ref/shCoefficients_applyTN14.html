shCoefficients.applyTN14

Replace C20 (and C30 where provided) from a TN-14 table.

Syntax

out = shCoefficients.applyTN14(obj, tn)out = shCoefficients.applyTN14(obj, tn, Tolerance=0.05, ReplaceC30="auto")

Description

OUT = obj.applyTN14(TN) with TN from shLowLevel.readTN14 (or a filename). Requires a finite obj.epoch; the nearest TN epoch within opts.Tolerance (default 0.05 yr) is used.

Examples

Runnable (docs/apiExamples.json)
g = g.applyTN14(tn14);                % C20/C30 replacement
