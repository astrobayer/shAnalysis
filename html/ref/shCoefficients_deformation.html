shCoefficients.deformation

Elastic load deformation up/north/east [m].

Syntax

[up, north, east] = shCoefficients.deformation(obj, latDeg, lonDeg)[up, north, east] = shCoefficients.deformation(obj, latDeg, lonDeg, kn=..., hn=..., ln=..., ...)

Description

[UP, NORTH, EAST] = g.deformation(LAT, LON, kn=, hn=, ln=, Mode ("grid")="grid"|"points", Nmin (1)=1, LatType ("geocentric")="geocentric") from the object's (residual!) coefficients - remove a mean field first. Love numbers are always user-supplied; see shLowLevel.shSynthesisDeformation for formulas and validation.

Examples

Runnable (docs/apiExamples.json)
[up, no, ea] = g.deformation(latPts, lonPts, kn = LN.kn, hn = LN.hn, ...
    ln = LN.ln, Mode = "points");
