shCoefficients

Spherical harmonic (Stokes) coefficient set - single epoch.

Syntax

obj = shCoefficients(...)

Description

The single point of access for one gravity field: a GRACE/GRACE-FO monthly solution (GSM), a dealiasing product (GAA/GAB/GAC/GAD), a static model, or any derived field (difference, filtered, climatology component). Immutable value class: every operation returns a NEW object and appends to .history (full provenance).
