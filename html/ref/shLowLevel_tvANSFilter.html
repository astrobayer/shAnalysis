shLowLevel.tvANSFilter

Time-variable anisotropic Wiener filtering of a SH series.

Syntax

[Xf, op, info] = shLowLevel.tvANSFilter(X, tYears, idx)[Xf, op, info] = shLowLevel.tvANSFilter(X, tYears, idx, NoiseCov=[], Constraints=[], SignalMode='isotropic', ...)

Description

[XF, OP, INFO] = shLowLevel.tvANSFilter(X, TYEARS, IDX) runs the tvANS chain on the coefficient series X (P x T, IDX ordering, shLowLevel.shIndex):

Examples

Runnable (docs/apiExamples.json)
[Xf, op, info] = shLowLevel.tvANSFilter(X, tYears, idx);
sigma = info.sigmaXfres;              % exact posterior (v2.5 incl. constraints)

Name-Value Arguments

NameSizeTypeDefaultDescription
NoiseCovn x mdouble[](P,P) double full covariance ([]: empirical)
Constraintsn x mdouble[](P,q) double constraint kernels
SignalModen x m-'isotropic''isotropic' (default) | 'inhomogeneous'
NIterSignal1 x 1double3double signal-covariance iterations, 3
Robust1 x 1logicalfalselogical robust deterministic fit, false
Shrinkage1 x 1double0.1double empirical noise-cov shrinkage, 0.1
VCEMinDegree1 x 1doubleround(2/3 * idx.Lmax)double default round(2/3 * idx.Lmax)
VCEBands1 x :double[](1,:) double order-band edges, e.g. [0 16 33 61]: one monthly VCE factor per order band instead of a single s(t) for the whole field. Requires the block path (Blocks="on"/"auto"); the edges must be ascending and cover 0..Lmax. [] (default) = one factor per month (v2.2).
Blocksn x m-'auto''auto' (default) | 'on' | 'off' Block-diagonal fast path: with SignalMode='isotropic', no constraints and a noise covariance that is block-diagonal in this partition (the empirical one, or an external NoiseCov that buildNoiseCov verifies to be), both S and N are block- diagonal per (order, C/S, degree parity), so the generalized eigendecomposition decouples into O(Lmax^2) small blocks. This removes the O(P^3) wall and the dense P x P memory footprint, making Lmax = 96-120 tractable. 'auto' engages it exactly when the conditions hold, falling back quietly to the full path for an external NoiseCov that is not block-diagonal; results are IDENTICAL to the full path (validated: 1.8e-15). 'on' errors if conditions are violated.

Fields layout (1,:) char 'full' | 'blocks' - which of the two forms below is filled Ut, V (P x P) double the eigenbasis; layout 'full' blocks (1,K) struct per-block eigenbases; layout 'blocks' sBlocks (K x T) double per-block variance factors; 'blocks' lam (P x 1) double generalized eigenvalues s (T x 1) double per-month variance factors Ac, SA double the constraint operator and its covariance action; empty when unconstrained M double the constraint normal matrix idx (1,1) struct the shIndex ordering everything uses tYears (T x 1) double the epochs model (P x T) double the deterministic part removed Xres (P x T) double the residuals filtered Xfres (P x T) double the filtered residuals, filled by the caller detLeverage, detResVar double the deterministic fit's leverage and residual variance, carried so shLowLevel.basinDeconvolve can form the exact basin sigma
info(1,1) struct noise, signal and VCE diagnostics, fields noise (1,1) struct the buildNoiseCov info signal (1,1) struct the buildSignalCov info vce (T x 1) double the per-month variance factors s lam (P x 1) double the generalized eigenvalues sigmaNote (1,:) char which posterior-sigma formula was used; empty when the filter is unconstrained sigmaXfres (P x T) double 1-sigma posterior uncertainty of the filtered residual per coefficient and month, diag((I-W_t)S) = (V.^2)*(s_t*lam./(lam+s_t)), validated to 3.5e-16 against the direct matrix product. With constraints (v2.5) this is the EXACT diagonal of (W-I)S(W-I)' + s*W*N*W'; the earlier unconstrained formula underestimated along constrained directions
