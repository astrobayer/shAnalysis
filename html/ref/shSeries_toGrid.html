shSeries.toGrid

Synthesize every epoch into one stack, with its metadata.

Syntax

b = shSeries.toGrid(obj, latDeg, lonDeg)b = shSeries.toGrid(obj, latDeg, lonDeg, Quantity="ewh", kn=[], hn=[], ...)

Description

B = ts.toGrid(LAT, LON, Quantity ("ewh")=..., kn ([])=..., LatType ("geodetic")=...) is shCoefficients.toGrid over a whole series: B.Z is (nlat x nlon x nEpochs) and B.Epoch carries the decimal years, so an animation can label its own frames from the data rather than from a filename.

Examples

From the help block
    b = ts.toGrid(-89.5:89.5, 0.5:359.5, Quantity = "ewh", kn = kn);
    size(b.Z)        % [180 360 nEpochs]
