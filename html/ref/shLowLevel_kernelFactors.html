shLowLevel.kernelFactors

Degree-dependent spectral factors for SH synthesis/analysis.

Syntax

[kernel, radialExp, units] = shLowLevel.kernelFactors(quantity, nmax, GM, R)[kernel, radialExp, units] = shLowLevel.kernelFactors(quantity, nmax, GM, R, kn=[], hn=[], rho_ave=5517, ...)

Description

KERNEL = shLowLevel.kernelFactors(QUANTITY, NMAX, GM, R, kn=..., ...) returns the (NMAX+1)x1 factor f_n such that a field of QUANTITY is q(lat,lon) = sum_n f_n * sum_m Pbar_nm (C_nm cos + S_nm sin). Shared by shLowLevel.shSynthesis (multiply) and shLowLevel.shAnalysisGrid (divide); the single source of truth for the quantity definitions.

Examples

Runnable (docs/apiExamples.json)
kf = shLowLevel.kernelFactors("ewh", 60, GM, R, kn = kn);

Input Arguments

NameSizeTypeDefaultDescription
quantityn x m-requiredchar/string see above
nmax1 x 1doublerequireddouble GM, R (1,1) double [m^3/s^2], [m]
GM1 x 1doublerequiredgravitational constant times Earth mass [m^3/s^2] (default 3.986004415e14, overridable)
R1 x 1doublerequiredreference radius [m] (default 6378136.3, overridable)

Name-Value Arguments

NameSizeTypeDefaultDescription
knn x mdouble[](>=nmax+1,1) double load Love numbers k'_n (NEVER hardcoded - user-supplied)
hnn x mdouble[](>=nmax+1,1) double load Love numbers h'_n (deformation_up only; user-supplied)
rho_ave1 x 1double5517double = 5517 [kg/m^3]
rho_water1 x 1double1000double = 1000 [kg/m^3]
Height1 x 1double0double = 0 [m] evaluation height above R: multiplies the potential-type kernels by the upward- continuation attenuation (R/r)^p with r = R+Height (p = n+1 potential/geoid-as-potential-ratio... see below; p = n+2 anomaly/disturbance; p = n+3 T_rr). Python-validated against -d/dr and d2/dr2 of the continued potential (2e-10 / 7e-7 = check's own truncation). Surface quantities (ewh, surface_density, bottom_pressure, deformation_up, geoid) and the passthrough 'none' reject Height (shLowLevel:kernelFactors:heightInvalid) - they have no radial law.

Output Arguments

NameDescription
kernel(nmax+1,1) double (zeros where the quantity carries no information, e.g. n=1 for gravity_anomaly) radialExp (nmax+1,1) double the upward-continuation exponent p_n in f_n(r) = kernel_n (R/r)^p_n, or EMPTY for a quantity that has no radial law (a surface concept). This is the same p_n the Height branch below applies, returned rather than restated: shLowLevel.shSynthesisGradient needs it for d/dr = -(p_n/r) f_n, and a second copy of these exponents would be a fact written twice.
units(1,1) string the SI unit of the quantity ("" for the dimensionless passthrough). Same reason as radialExp: the unit belongs to the quantity, so it is returned from where the quantity is defined rather than restated in every bridge, plot label and export header. Consumed by shCoefficients.toGrid.

Error Identifiers

IdentifierRaised when

shLowLevel:kernelFactors:hnTooShorthn does not cover degrees 0..nmax
