shClimatology.amplitudeMap

Pointwise seasonal amplitude (and phase) map.

Syntax

[A, lat, lon, phase] = shClimatology.amplitudeMap(obj, which, latVec, lonVec)[A, lat, lon, phase] = shClimatology.amplitudeMap(obj, which, latVec, lonVec, Quantity="geoid", kn=[])

Description

[A, LAT, LON, PHASE] = clim.amplitudeMap(WHICH, ... with WHICH "annual" | "semiannual" | k (index into clim.periods, v2.1), LATVEC, LONVEC, Quantity ("geoid")=..., kn ([])=...) synthesizes the cos and sin component fields and combines them pointwise: A = sqrt(fc.^2 + fs.^2) PHASE = atan2(fs, fc) [rad, relative to t0] (amplitude of a harmonic is NOT a linear functional of the coefficients, so it must be formed in the space domain).

Examples

Runnable (docs/apiExamples.json)
[A, lat, lon] = clim.amplitudeMap("annual", -89:89, 0:359, Quantity = "ewh", kn = kn);
