shCoefficients.setCoefficient

Replace a single (n,m) coefficient pair.

Syntax

out = shCoefficients.setCoefficient(obj, n, m, Cval, Sval)out = shCoefficients.setCoefficient(obj, n, m, Cval, Sval, SigmaC=NaN, SigmaS=NaN)

Description

No description beyond the summary line above.

Examples

Runnable (docs/apiExamples.json)
g = g.setCoefficient(2, 0, c20slr);   % SLR C20 by hand

Input Arguments

NameSizeTypeDefaultDescription
objn x m-requiredthe object the method is called on
n1 x 1doublerequiredspherical harmonic degree
m1 x 1doublerequiredspherical harmonic order
Cval1 x 1doublerequireddouble new C(n+1, m+1) value
Sval1 x 1doubleNaNdouble new S(n+1, m+1) value (NaN keeps the current one)

Name-Value Arguments

NameSizeTypeDefaultDescription
SigmaC1 x 1doubleNaNformal 1-sigma for the coefficient being set (NaN leaves the existing sigma untouched)
SigmaS1 x 1doubleNaNsame for the sine coefficient

Output Arguments

NameDescription
out(1 x 1) shCoefficients copy with C/S(n+1, m+1) replaced

Error Identifiers

IdentifierRaised when
