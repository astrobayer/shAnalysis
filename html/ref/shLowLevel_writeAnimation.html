shLowLevel.writeAnimation

Export a series as a map animation, drawn by geoMap.

Syntax

shLowLevel.writeAnimation(ts, filename)shLowLevel.writeAnimation(ts, filename, Quantity="ewh", kn=[], hn=[], ...)

Description

shLowLevel.writeAnimation(TS, 'ewh.avi', Quantity ("ewh")=..., kn ([])=...) synthesizes every epoch of TS onto one grid, draws each frame with geo.map, and writes them to a video container with a provenance sidecar.

Examples

From the help block
    shLowLevel.writeAnimation(ts, fullfile(tempdir, 'ewh.avi'), ...
        Quantity = "ewh", kn = kn, FrameRate = 6);

  See also SHSERIES/TOGRID, SHLOWLEVEL/WRITEFRAMES, REQUIREGEOMAP.
Runnable (docs/apiExamples.json)
shLowLevel.writeAnimation(ts, "ewh.avi", Quantity = "ewh", kn = kn);   % needs geoMap on the path
