shLowLevel.regionalProcessModel

Kurtenbach's process model in a regional basis.

Syntax

[model, info] = shLowLevel.regionalProcessModel(ts, B)[model, info] = shLowLevel.regionalProcessModel(ts, B, Order=1, Shrink=0, Structure="full", ...)

Description

[MODEL, INFO] = shLowLevel.regionalProcessModel(TS, B) estimates the stochastic process model of the regional Kalman filter from a geophysical model series TS - hydrology, ESA ESM, AOD1B errors - in the coefficients of the regional basis B of shLowLevel.regionalBasis, following Kurtenbach (2012, DGK C-683, Sec. 3.2): 1. the climatology of TS (mean, trend, annual, semi-annual; his eq. 3.81) is removed with ts.climatology; 2. every epoch is projected onto the basis, a_t = B.Proj x_t (shLowLevel.regionalProject). The two steps commute - the climatology is a fit along time with one design for every coefficient, the projection a map along the coefficients - so their order does not matter (Python-validated to 6e-16); 3. the VAR(Order) model is estimated from a_t by shLowLevel.estimateVAR; Order = 1 is his eqs. 3.84-3.85, B = Sigma(1) Sigma(0)^-1, Q = Sigma(0) - B Sigma(1)'. MODEL has the fields of estimateVAR's output and drives shLowLevel.kalmanFilter / rtsSmoother with the basis coefficients as the state. On the SH basis (B.T = I) it IS the model kalmanChain builds - bitwise, which is the regional chain's oracle.

Examples

From the help block
    B = tsModel.regionalBasis("Elbe", Type = "slepian", Threshold = 0.5);
    [model, info] = tsModel.regionalProcessModel(B, QScale = 10);
    info.representation, model.specRadius
