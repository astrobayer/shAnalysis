shLowLevel.legendreALFDeriv

Fully normalized ALFs and their latitude derivatives.

Syntax

[P, D, D2] = shLowLevel.legendreALFDeriv(nmax, latRad)

Description

[P, D] = shLowLevel.legendreALFDeriv(NMAX, LATRAD) returns the 4pi-fully- normalized associated Legendre functions P (via shLowLevel.legendreALF, scaled Holmes-Featherstone, stable to degree 2190) and their exact first derivatives with respect to LATITUDE phi,

Examples

Runnable (docs/apiExamples.json)
[P, dP] = shLowLevel.legendreALFDeriv(60, theta);   % for deformation/tensor

Input Arguments

NameSizeTypeDefaultDescription
nmax1 x 1doublerequireddouble maximum degree
latRad1 x :doublerequireddouble [rad] geocentric latitudes

Name-Value Arguments

None.

Output Arguments

NameDescription
P(nmax+1, nmax+1, nlat) double Pbar_nm(sin lat)
D(nmax+1, nmax+1, nlat) double dPbar_nm/dphi [1/rad] D2 (nmax+1, nmax+1, nlat) double d2Pbar_nm/dphi2 [1/rad^2]: the SAME column stencil applied to D - exact, because the first-derivative identity holds degree-wise as a function of phi and differentiates term by term (Python-validated vs numerical second differences, rel ~2e-7 = FD floor; v2.4)
