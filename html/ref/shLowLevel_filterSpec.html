shLowLevel.filterSpec

Read a filter specification - the one parser of the vocabulary.

Syntax

[spec, msg] = shLowLevel.filterSpec(F)[spec, msg] = shLowLevel.filterSpec(F, Allowed=["none", "gauss", "ddk", "W"])

Description

SPEC = shLowLevel.filterSpec(F) reads F, a filter specification in the form every lane with a Filter option takes, and says what it means:

Examples

From the help block
    spec = shLowLevel.filterSpec("gauss300");    % kind "gauss", radiusKm 300
    [s, msg] = shLowLevel.filterSpec("DDK3", Allowed = ["none", "gauss"]);
    % s.kind is "" and msg says why

  See also shLowLevel.shGaussianWeights, shLowLevel.readDDK,
  shLowLevel.ddkNames, shLowLevel.designFilter.

Output Arguments

NameDescription

msg(1,1) string "" when F is accepted, else the reason
