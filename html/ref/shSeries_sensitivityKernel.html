shSeries.sensitivityKernel

A tailored basin kernel in basinAverage's index.

Syntax

[k, info] = shSeries.sensitivityKernel(obj, region)[k, info] = shSeries.sensitivityKernel(obj, region, Alpha=..., Noise=..., FarField=..., ...)

Description

[K, INFO] = ts.sensitivityKernel(REGION) is shLowLevel.sensitivityKernel(shLowLevel.shIndex(ts.nmax), REGION): the Swenson-Wahr kernel that trades leakage against noise, in the ordering ts.basinAverage and g.basinAverage require. That function documents the trade-off, Alpha and INFO. Noise and FarField, when given, are in the same shLowLevel.shIndex(ts.nmax) ordering.

Examples

From the help block
    k = ts.sensitivityKernel([-10 100; -10 140; 25 140; 25 100], ...
        Alpha = 1);
    avg = ts.basinAverage(k);
