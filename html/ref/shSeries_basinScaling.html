shSeries.basinScaling

Basin scaling factor, with this series as the model.

Syntax

[k, info] = shSeries.basinScaling(obj, op, b)[k, info] = shSeries.basinScaling(obj, op, b, Idx=..., TYears=..., PerMonth=...)

Description

[K, INFO] = tsModel.basinScaling(OP, B) is shLowLevel.basinScaling(OP, B, tsModel): the series is pushed through the operator OP that filtered the data, and the true basin average is regressed on the filtered one. That function documents the operator forms, the epoch matching and INFO.

Examples

From the help block
    [k, info] = tsModel.basinScaling(W, b, Idx = idx, TYears = ep);
