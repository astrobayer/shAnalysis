shSeries.applyTN14

Replace C20 (and flagged C30) per month from TN-14.

Syntax

out = shSeries.applyTN14(obj, tn)out = shSeries.applyTN14(obj, tn, Tolerance=0.05, ReplaceC30="auto")

Description

OUT = ts.applyTN14("TN-14.txt") - series-level convenience around shCoefficients.applyTN14 (v2.4.1; the per-month epoch selects the TN entry). All options pass through.

Examples

Runnable (docs/apiExamples.json)
ts = ts.applyTN14(tn14);               % epoch-matched per month
