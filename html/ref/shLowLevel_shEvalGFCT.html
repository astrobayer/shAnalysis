shLowLevel.shEvalGFCT

Evaluate time-variable Stokes coefficients at a given epoch.

Syntax

[Ct, St] = shLowLevel.shEvalGFCT(model, epoch)

Description

[CT, ST] = SHEVALGFCT(MODEL, EPOCH) reconstructs C(t) = C0 + trnd*(t-t0) + sum_k [acos_k*cos(2*pi*(t-t0)) ... + asin_k*sin(2*pi*(t-t0))] (and analogously for S) from MODEL.C / MODEL.S (constant part) and MODEL.variableTerms (from SHREADGFC), at EPOCH (same units/convention as the t0 values in the file -- typically decimal years).

Examples

Runnable (docs/apiExamples.json)
[C, S] = shLowLevel.shEvalGFCT(model, 2015.5);   % piecewise gfct at an epoch

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
Ct(nmax+1 x nmax+1) double cosine coefficients at the epoch
St(nmax+1 x nmax+1) double sine coefficients at the epoch

Error Identifiers

IdentifierRaised when
shLowLevel:shEvalGFCT:staticModelwarning: MODEL carries no time-variable terms, so the static field is returned unchanged
shLowLevel:shEvalGFCT:epochOutsidethe requested epoch lies outside every gfct validity interval
shLowLevel:shEvalGFCT:unknownTypea variable-term type in the file is not recognised
