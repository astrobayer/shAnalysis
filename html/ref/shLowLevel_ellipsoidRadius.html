shLowLevel.ellipsoidRadius

Geocentric radius of a reference ellipsoid at a latitude.

Syntax

r = shLowLevel.ellipsoidRadius(latDeg)r = shLowLevel.ellipsoidRadius(latDeg, SemiMajorAxis=6378137, Flattening=1/298.257223563)

Description

R = shLowLevel.ellipsoidRadius(LATDEG) is the distance from the Earth's centre to the surface of the WGS84 ellipsoid at each GEOCENTRIC latitude in LATDEG:

Examples

From the help block
    % gravity disturbance at stations on the ellipsoid, 150 m up
    r = shLowLevel.ellipsoidRadius(lat) + 150;
    dg = shLowLevel.synthesisPoints(C, S, GM, R, lat, lon, r, ...
        Quantity = "disturbance");

  See also shLowLevel.shSynthesis, shLowLevel.synthesisPoints,
  shLowLevel.geodetic2geocentric, shLowLevel.normalFieldCS.

Input Arguments

NameSizeTypeDefaultDescription
latDegn x mdoublerequireddouble array GEOCENTRIC latitudes in degrees, -90..90

Name-Value Arguments

NameSizeTypeDefaultDescription
SemiMajorAxis1 x 1double6378137semi-major axis a [m]. The WGS84 value - the same a shLowLevel.normalFieldCS uses for its WGS84 system, and a test pins that the two agree. Deliberately NOT the coefficients' reference radius R (6378136.3 for most GRACE products): R belongs to the series, a to the surface, and pairing WGS84's flattening with R would describe an ellipsoid nobody uses
Flattening1 x 1double1/298.257223563flattening f, WGS84 as everywhere else in the toolbox. 0 is allowed and gives a sphere of radius SemiMajorAxis, which is what makes the sphere a special case rather than a separate path

Output Arguments

NameDescription
rdouble array geocentric radius [m], same size as latDeg
