shLowLevel.shReadGFC

Read an ICGEM ASCII .gfc gravity field model file.

Syntax

model = shLowLevel.shReadGFC(filename)

Description

MODEL = SHREADGFC(FILENAME) parses header key:value pairs and the gfc/gfct data block of a standard ICGEM-format file (GRACE/GRACE-FO monthly solutions, static models, GOCE, EGM2008, etc.). Gzip- compressed files (.gfc.gz) are transparently decompressed.

Examples

Runnable (docs/apiExamples.json)
g = shLowLevel.shReadGFC("ITSG-Grace2018_n60_2008-04.gfc");

Input Arguments

None.

Name-Value Arguments

None.

Output Arguments

NameDescription
model(1,1) struct fields C, S, sigmaC, sigmaS (nmax+1 x nmax+1) double coefficients and their formal errors GM, R (1,1) double the file's reference constants; without them in the header, silently 3.986004415e14 and 6378136.3 nmax (1,1) double maximum degree read modelname the header's modelname as parsed (char, or a number when the value is numeric); '' when absent header (1,1) struct the parsed file header, verbatim - this is where the TIDE SYSTEM lives, as header.tide_system when the file declares one. There is no model.tide field; shCoefficients.read lifts it out of the header variableTerms (1,:) struct array trend/annual/semiannual terms; empty when the file carries none
