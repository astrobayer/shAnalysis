shLowLevel.readTN13

Read a GRACE/GRACE-FO TN-13 geocenter (degree-1) file.

Syntax

tn = shLowLevel.readTN13(filename)

Description

TN = shLowLevel.readTN13(FILENAME) parses the official TN-13 product (JPL/CSR/GFZ, e.g. TN-13_GEOC_CSR_RL06.txt): data lines GRCOF2 n m Clm Slm Clm_sig Slm_sig begin end with n=1, m=0/1 and begin/end epochs yyyymmdd.hhmm. Line pairs (m=0, m=1) sharing the same interval are combined into one monthly record with the interval mid-point as epoch.

Examples

Runnable (docs/apiExamples.json)
tn13 = shLowLevel.readTN13("TN-13_GEOC_CSR_RL06.3.txt");
