shLowLevel.shSynthesisDeformation

Elastic load deformation: up / north / east.

Syntax

[up, north, east] = shLowLevel.shSynthesisDeformation(C, S, R, latDeg, lonDeg)[up, north, east] = shLowLevel.shSynthesisDeformation(C, S, R, latDeg, lonDeg, kn=..., hn=..., ln=..., ...)

Description

[UP, NORTH, EAST] = shLowLevel.shSynthesisDeformation(C, S, R, LAT, LON, kn=..., hn=..., ln=...) synthesizes the three components of the elastic surface deformation caused by the load expressed in the (residual) Stokes coefficients C, S (Wahr et al. 1998; Kusche & Schrama 2005 - the GRACE <-> GNSS loading comparison):

Examples

Runnable (docs/apiExamples.json)
[up, no, ea] = shLowLevel.shSynthesisDeformation(g.C, g.S, g.R, latPts, lonPts, kn = LN.kn, hn = LN.hn, ln = LN.ln, Mode = "points");

R1 x 1doublerequireddouble [m]
latDeg1 x :doublerequireddouble [deg] geocentric latitude
lonDeg1 x :doublerequireddouble [deg]

Name-Value Arguments

NameSizeTypeDefaultDescription
knn x mdouble-double load Love numbers k'_n (REQUIRED)
hnn x mdouble-double load Love numbers h'_n (REQUIRED)
lnn x mdouble-double load Love numbers l'_n (REQUIRED)
Nmin1 x 1double1double = 1 degrees below nmin are zeroed (degree 0 carries no deformation; include degree 1 ONLY if your coefficients carry geocenter motion in the CF frame consistently)
Mode1 x 1string"grid""grid"|"points" = "grid" grid: nlat x nlon outer product; points: equal-length LAT/LON vectors evaluated pairwise (GNSS stations)

Output Arguments

NameDescription
up, north, east(nlat,nlon) double for Mode="grid", (np,1) for Mode="points"; vertical, north and east elastic deformation [m]. EAST is NaN at |lat| = 90, where the direction is undefined.
