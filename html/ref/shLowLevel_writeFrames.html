shLowLevel.writeFrames

Write ready-made RGB frames to a video container.

Syntax

shLowLevel.writeFrames(frames, filename)shLowLevel.writeFrames(frames, filename, FrameRate=4, Sidecar=true, SidecarExtra=struct())

Description

shLowLevel.writeFrames(FRAMES, 'out.avi', FrameRate=..., ...) writes an (H x W x 3 x T) uint8 stack to an MPEG-4 or Motion-JPEG AVI file and, by default, a provenance sidecar beside it.

Examples

From the help block
    F = uint8(zeros(120, 240, 3, 5));
    shLowLevel.writeFrames(F, fullfile(tempdir, 'demo.avi'), FrameRate = 2);

  See also shLowLevel.writeAnimation, shSeries.toGrid.
Runnable (docs/apiExamples.json)
shLowLevel.writeFrames(uint8(zeros(60,120,3,3)), fullfile(tempdir,"demo.avi"), FrameRate = 2);
