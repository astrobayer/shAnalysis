shClimatology.removeGIA

Subtract a GIA rate model from the fitted trend.

Syntax

out = shClimatology.removeGIA(obj, gia)

Description

OUT = clim.removeGIA(GIA): GIA is an shCoefficients holding RATE coefficients [1/yr] (user-supplied model file via shCoefficients.read). Only trendC/trendS change; trend sigmas are kept - the model is treated as exact here. To carry a GIA model's own sigma, correct the series before the fit with ts.removeGIA(GIA, Sigma = SIG) (v5.2.0), or add its rate sigma to the trend sigma. GIA model spread often dominates regional trend error budgets - compare several models.

Examples

Runnable (docs/apiExamples.json)
clim = clim.removeGIA(giaModel);
