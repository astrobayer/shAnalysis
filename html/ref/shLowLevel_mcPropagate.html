shLowLevel.mcPropagate

Monte-Carlo uncertainty propagation through arbitrary chains.

Syntax

out = shLowLevel.mcPropagate(fun, g)out = shLowLevel.mcPropagate(fun, g, N=500, Cov=[], Idx=struct([]), ...)

Description

OUT = shLowLevel.mcPropagate(FUN, G) draws coefficient samples consistent with the formal errors of the shCoefficients G, pushes each through FUN, and returns empirical statistics - uncertainty propagation for ANY functional (filtered grids, basin averages, amplitude maps, ...) without deriving analytic formulas, and the standard cross-check for every analytic sigma in this toolbox.

Examples

Runnable (docs/apiExamples.json)
out = shLowLevel.mcPropagate(@(gs) gs.C(3, 1), g, N = 200);   % any functional of g
